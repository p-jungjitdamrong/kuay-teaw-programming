บทที่ 2 · if / else
if ตรวจเงื่อนไข — ทำหรือข้าม
โปรแกรมทำงานตามลำดับบรรทัด แต่ if ทำให้ "เลือก" ได้ว่าจะทำส่วนไหนขึ้นอยู่กับเงื่อนไข
โครงสร้าง if-else
if (เงื่อนไข) { ... }
เงื่อนไขเป็น true (≠0) → ทำ block นั้น
เงื่อนไขเป็น false (=0) → ข้ามไป

else รับ "กรณีที่เหลือทั้งหมด" หลังจาก if ไม่ผ่าน
1
ตรวจ if ก่อนเสมอถ้าจริง ทำแล้วข้ามทุก else ถัดไป
2
else if ตรวจถัดไปตรวจเฉพาะเมื่อ if บนไม่ผ่าน
3
else รับกรณีที่เหลือไม่ต้องเขียนเงื่อนไข — ถ้าถึงตรงนี้แสดงว่าทุก if ข้างบนไม่ผ่านแล้ว
ตัวอย่าง — ตรวจเกรด
int score = 75; if (score >= 80) { printf("Grade: A or B\n"); } else if (score >= 70) { printf("Grade: C\n"); /* ← runs */ } else if (score >= 60) { printf("Grade: D\n"); } else { printf("Grade: F\n"); }
⚠️ = vs ==
if (x = 5) ← กำหนดค่า ผลเป็น true เสมอ (bug!)
if (x == 5) ← เปรียบเทียบ ✅
บทที่ 2 · Logical Operators
เงื่อนไข ซับซ้อน ด้วย && || !
รวมหลายเงื่อนไขเข้าด้วยกันด้วย logical operators — ใช้บ่อยมากใน if
OperatorความหมายTrue เมื่อ
&&ANDทั้งสองเงื่อนไขเป็น true
||ORอย่างน้อยหนึ่งเป็น true
!NOTกลับค่า — true→false, false→true
ตัวอย่างรวมเงื่อนไข
/* ช่วงอายุ 18-60 */ if (age >= 18 && age <= 60) { ... } /* วันหยุด */ if (day == 6 || day == 7) { ... } /* ไม่ใช่ admin */ if (!isAdmin) { ... }
Short-circuit Evaluation
A && B — ถ้า A เป็น false ไม่ตรวจ B เลย

A || B — ถ้า A เป็น true ไม่ตรวจ B เลย

ประโยชน์: ป้องกัน null pointer
if (p != NULL && *p == 5)
ผลลัพธ์ของ if (5 > 3 || 1/0 == 0) คืออะไร? โปรแกรม crash ไหม?
💡 Short-circuit — ถ้าส่วนแรก true แล้ว ส่วนหลังจะถูก evaluate หรือเปล่า?
🏦 Use Case — KTB
ตรวจสอบสิทธิ์กู้เงิน
if (age >= 20 && income >= 15000 && creditScore >= 600) — ต้องผ่านทุกเงื่อนไขพร้อมกันจึงอนุมัติสินเชื่อ
บทที่ 2 · Nested Conditions
if ซ้อน if — เงื่อนไขหลายชั้น
บางครั้งต้องตรวจเงื่อนไขใน block ของเงื่อนไขอื่น — แต่ถ้าซ้อนลึกมากให้คิดวิธีเขียน if-else if แทน
Nested if — อ่านได้แต่ระวัง indentation
int score = 85; int attended = 1; /* 1=yes */ if (score >= 60) { if (attended) { printf("ผ่าน ✓\n"); } else { printf("ขาดสอบ\n"); } } else { printf("สอบตก\n"); }
เขียนใหม่ด้วย && — อ่านง่ายกว่า
if (score >= 60 && attended) printf("ผ่าน ✓\n"); else if (score >= 60) printf("ขาดสอบ\n"); else printf("สอบตก\n");
⚠️ Dangling else ปัญหาคลาสสิก
if (x > 0)
  if (x > 10)
    printf("big");
else ← else นี้ belongs กับ if ตัวไหน?

ใน C: else จับคู่กับ if ใกล้ที่สุด เสมอ ใส่ {} ทุกครั้งเพื่อหลีกเลี่ยง
✅ Best Practice
ใส่ {} ทุก block เสมอ แม้จะมีบรรทัดเดียว

Indent สม่ำเสมอ — 4 spaces ต่อ level

ถ้า nest ลึกกว่า 3 ชั้น ให้คิดใหม่ว่าเขียน function แยกได้ไหม
บทที่ 2 · switch
switch — เลือกจากหลายค่าตรงๆ
เมื่อต้องเปรียบเทียบตัวแปรเดียวกับหลายค่า switch อ่านง่ายกว่า if-else if chain มาก
โครงสร้าง switch
int day = 3; switch (day) { case 1: printf("จันทร์"); break; case 2: printf("อังคาร"); break; case 3: printf("พุธ"); break; /* runs */ case 4: printf("พฤหัส"); break; case 5: printf("ศุกร์"); break; default: printf("วันหยุด"); }
❌ ลืม break — Fall-through!
ถ้าไม่มี break โปรแกรมจะรันต่อไปยัง case ถัดไปเลย (fall-through) บางครั้งตั้งใจ แต่ส่วนใหญ่คือ bug
Fall-through ใช้ประโยชน์ได้
/* รวม case ที่ทำเหมือนกัน */ switch (month) { case 1: case 3: case 5: /* ไม่มี break ตั้งใจ */ days = 31; break; case 4: case 6: days = 30; break; default: days = 28; }
🏦 Use Case — ATM Menu
เลือก transaction type
switch รับ choice 1-4: ฝาก, ถอน, โอน, ตรวจยอด — แต่ละ case ทำงานแยกชัดเจน default ขึ้น error
บทที่ 2 · Ternary Operator
Ternary ?: — if-else บรรทัดเดียว
condition ? value_if_true : value_if_false — ใช้เมื่อต้องการกำหนดค่าตามเงื่อนไข สั้นกว่า if-else มาก
เปรียบเทียบ if-else vs ternary
/* แบบยาว — if-else */ int max; if (a > b) max = a; else max = b;
/* แบบสั้น — ternary */ int max = (a > b) ? a : b;
ตัวอย่างที่ใช้บ่อย
/* ตรวจคู่/คี่ */ printf("%s", (n%2==0) ? "Even" : "Odd"); /* แสดงสถานะ */ char *status = (score>=50) ? "Pass" : "Fail"; printf("%s", status); /* ค่าสัมบูรณ์ */ int abs = (x >= 0) ? x : -x;
⚠️ อย่า nest ternary
a ? b ? c : d : e

อ่านยากมาก ถ้าเงื่อนไขซับซ้อนให้ใช้ if-else แทนเสมอ

Ternary เหมาะกับเงื่อนไขง่ายๆ 2 กรณีเท่านั้น
เขียน ternary ที่พิมพ์ "Positive", "Negative", หรือ "Zero" สำหรับตัวแปร int n ได้ไหม? ถ้าไม่ได้ทำไม?
💡 ternary มีแค่ 2 branch (true/false) — 3 กรณีต้องซ้อน หรือใช้ if-else if แทน
บทที่ 2 · Patterns
Pattern ที่ใช้บ่อย — จำไว้ใช้ได้เลย
โจทย์ส่วนใหญ่มี pattern ซ้ำๆ — เข้าใจ pattern เหล่านี้แล้วแก้โจทย์ได้เร็วขึ้นมาก
Pattern 1 — Range Check
/* ตรวจว่า x อยู่ในช่วง [a, b] */ if (x >= 1 && x <= 10) printf("in range");
Pattern 2 — Guard Clause (ตรวจ error ก่อน)
/* ตรวจ invalid ก่อน แล้วค่อยทำงานจริง */ if (score < 0 || score > 100) { printf("Invalid!"); return; /* ออกจาก function เลย */ } /* ถึงตรงนี้ score ถูกต้องแน่นอน */ if (score >= 80) ...
Pattern 3 — Multi-tier (จาก High → Low)
/* เรียงจากมากไปน้อย เสมอ */ if (price >= 1000) disc = 20; else if (price >= 500) disc = 10; else if (price >= 100) disc = 5; else disc = 0;
💡 ทำไม Guard Clause ดี
แทนที่จะ nest deep: if valid { if (...) { if (...) {

ให้ตรวจ error แล้ว return ออกก่อน code หลักจะแบนและอ่านง่ายกว่ามาก

เรียกว่า "Early return" pattern
🏦 Use Case — KTB Loan
อัตราดอกเบี้ยขั้นบันได
วงเงินกู้ ≥ 5M → 3.5% | ≥ 1M → 4.5% | ≥ 500K → 5.5% | น้อยกว่า → 6.5% — Multi-tier pattern จาก high ลง low
บทที่ 2 · Use Case
🏦 Use Case จริง — ระบบ ATM
รวม if-else + switch + ternary เพื่อสร้างระบบ ATM อย่างง่าย — ทุก control flow ที่เรียนมาอยู่ในนี้
โจทย์ระบบ ATM
ระบบเลือก transaction
รับยอดเงินในบัญชีและ choice ของผู้ใช้
1=ฝาก, 2=ถอน, 3=ตรวจยอด

ถ้าถอน: ตรวจว่าเงินพอไหม
แสดงยอดใหม่และสถานะ "Balance OK" / "Low Balance"
ใช้ทุก concept บทนี้
switch — เลือก transaction type
if-else — ตรวจเงินพอไหม
ternary — แสดงสถานะยอดเงิน
&& — เงื่อนไขซ้อน
โปรแกรม ATM อย่างง่าย
int balance = 5000, choice, amount; printf("1=ฝาก 2=ถอน 3=ยอด: "); scanf("%d", &choice); switch (choice) { case 1: printf("ฝากเท่าไหร่: "); scanf("%d", &amount); balance += amount; printf("ยอดใหม่: %d\n", balance); break; case 2: printf("ถอนเท่าไหร่: "); scanf("%d", &amount); if (amount > balance) printf("เงินไม่พอ!\n"); else { balance -= amount; printf("ยอดใหม่: %d | %s\n", balance, (balance < 1000) ? "⚠ Low" : "OK"); } break; case 3: printf("ยอดปัจจุบัน: %d\n", balance); break; default: printf("ตัวเลือกไม่ถูกต้อง\n"); }
บทที่ 2 · Think!
คิดก่อน เขียน
อ่านแต่ละโจทย์แล้วคิดในใจก่อน — ฝึก trace code และวิเคราะห์ logic
1. ถ้า x = 0 แล้ว if (x) จะเข้า block ไหม? เพราะอะไร?
💡 ใน C: 0 = false, non-zero = true ไม่ต้องเขียน x != 0 ก็ได้
2. Code ต่อไปนี้มี bug อะไร?
if (score = 80) printf("Pass");
💡 = กับ == ต่างกัน — ตัวไหนเป็นการกำหนดค่า ตัวไหนเปรียบเทียบ?
3. Output คืออะไร?
int x=5; printf("%d", (x>3) ? x*2 : x+1);
💡 ตรวจเงื่อนไขก่อน — 5 > 3 จริงหรือเปล่า?
4. switch ใช้กับ float ได้ไหม? เช่น switch (3.14)
💡 switch ใช้ได้เฉพาะ integer types เท่านั้น (int, char, enum)
5. ระบบตรวจว่าปีนั้นเป็นปีอธิกสุรทิน (leap year) หรือไม่
เงื่อนไข: หาร 4 ลงตัว และ (ไม่หาร 100 ลงตัว หรือ หาร 400 ลงตัว)
เขียน if condition ได้ไหม?
💡 (year%4==0 && year%100!=0) || year%400==0

บทที่ 2 · สรุป
สรุป บทที่ 2
ก่อนไปบทที่ 3 (Loop) ตรวจสอบว่าเข้าใจทุกจุดเหล่านี้
✓
if → else if → else ตรวจจาก บนลงล่าง หยุดที่แรกที่ผ่านลำดับ condition สำคัญมาก
✓
&& AND, || OR, ! NOT + Short-circuitถ้า A false แล้ว A&&B ไม่ตรวจ B
✓
switch สำหรับ exact value match + อย่าลืม breakfall-through ตั้งใจได้ แต่ต้อง comment ไว้
✓
Ternary ? : สำหรับกำหนดค่า 2 กรณีถ้ามากกว่า 2 กรณีใช้ if-else แทน
✓
Guard clause — ตรวจ error แล้ว return ก่อนทำให้ code หลักสะอาดและอ่านง่าย
