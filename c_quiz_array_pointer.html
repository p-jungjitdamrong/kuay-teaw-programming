#02ARRAY

Dint[] arr = {1,2,3};
🇹🇭 คำอธิบาย
C นับขนาดให้เองเมื่อไม่ใส่ตัวเลขใน [] และมี initializer list — int arr[] = {10,20,30} จะได้ size=3 อัตโนมัติ A ว่างเปล่าไม่ได้ B ใช้ n ที่ไม่ใช่ constant ไม่ได้ D syntax ผิด

#08ARRAY

Bเรียงลำดับ
Cกลับด้าน array
Dคัดลอก array

#09ARRAY

AC copy ทั้ง array เข้า function
Bfunction ไม่สามารถแก้ค่าใน array ได้
Csizeof(arr) ใน function ให้ขนาด array จริงๆ
DC ส่ง address ของช่องแรก ไม่ได้ copy ทั้ง array

C ส่งแค่ address ของ arr[0] เข้า function (ไม่ copy) ดังนั้น function แก้ค่าได้จริง แต่ sizeof(arr) ใน function ให้ขนาด pointer ไม่ใช่ array จึงต้องส่ง size ด้วย

#12ARRAY

#17POINTER
ข้อใดกล่าวถูกต้องเกี่ยวกับ NULL pointer?
A*p เมื่อ p=NULL จะให้ค่า 0
BNULL pointer มีค่าเป็น address 0 และ dereference ทำให้ crash
CNULL เป็นเหมือน int 0 ใช้แทนกันได้เลย
DNULL pointer ชี้ไปที่ตัวแปร x ที่ค่าเป็น 0
🇹🇭 คำอธิบาย
NULL คือ address 0 ซึ่ง OS สงวนไว้ — ถ้า dereference pointer ที่เป็น NULL จะเกิด segmentation fault (crash) ทันที ต้องตรวจ if(p != NULL) ก่อนใช้เสมอ

#24POINTER
