บทพิเศษ · Pattern 1

เห็นแบบนี้ → O(1)

ไม่ว่า n จะเป็นเท่าไหร่ ใช้ memory เพิ่มเท่าเดิม

✅ แค่ตัวแปร int/float/char
int i, j, temp, min_idx;
double sum = 0;
char c;
/* ไม่ว่า n=10 หรือ n=1M
   ตัวแปรเหล่านี้ใช้แค่ช่อง
   memory คงที่เสมอ */
✅ swap, ตัวแปร flag, pointer
int swapped = 0;   /* flag */
int *ptr = &arr[0]; /* pointer */
int lo = 0, hi = n-1;
/* ไม่ว่า array ใหญ่แค่ไหน
   ตัวแปรช่วยเหล่านี้ = O(1) */
✅ Algorithm In-place ที่ไม่ recurse
Bubble Sort    → O(1)
Selection Sort → O(1)
Insertion Sort → O(1)
Heap Sort      → O(1)
/* sort in-place = เรียงใน
   array เดิม ไม่สร้างใหม่ */
✅ Array ขนาด constant (ไม่ขึ้นกับ n)
int count[10] = {0};  /* 10 ช่อง */
int freq[256];         /* 256 ช่อง */
/* ขนาดคงที่ ไม่ขึ้นกับ n
   → O(1) เสมอ */
เห็น: ตัวแปรเดี่ยว หรือ array ขนาด constant→O(1) ทันที!
บทพิเศษ · Pattern 2

เห็นแบบนี้ → O(n)

สร้าง array หรือโครงสร้างที่ขนาดขึ้นกับ n

⚠️ สร้าง array ขนาด n
int output[n];     ← O(n)
int temp[n];       ← O(n)
int L[n1], R[n2];  ← O(n)
/* Merge Sort: สร้าง L, R
   ขนาดรวม n → O(n) */
⚠️ สร้าง Linked List / struct ขนาด n
Node *new_node = malloc(sizeof(Node));
/* ถ้า malloc n ครั้ง → O(n) */

int memo[n];  /* memoization */
int dp[n];    /* DP table → O(n) */
⚠️ Counting Sort count array = O(k)
int count[max_val + 1]; ← O(k)
int output[n];          ← O(n)
/* k = ขอบเขตค่า
   ถ้า k >> n → สิ้นเปลือง!
   ถ้า k ≈ n → O(n) */
⚠️ Recursion ลึก n ชั้น
/* Factorial — n calls deep */
int fact(int n) {
    if (n==0) return 1;
    return n * fact(n-1); ← n ชั้น
} /* call stack = O(n) */
เห็น: int arr[n] หรือ malloc n ครั้ง หรือ recurse n ชั้น→O(n) ทันที!
บทพิเศษ · Pattern 3

เห็นแบบนี้ → O(log n)

Recursion ที่ตัด input ครึ่งทุกครั้ง — call stack ลึก log n ชั้น

Quick Sort — stack ลึก O(log n)
void quick_sort(int arr[], int lo, int hi) {
    if (lo < hi) {
        int pi = partition(arr, lo, hi);
        quick_sort(arr, lo, pi-1);   ← n/2
        quick_sort(arr, pi+1, hi);  ← n/2
    }
}
/* Average: ทุก call ตัดครึ่ง
   ลึกสุด = log₂(n) ชั้น
   → Space O(log n) call stack

   Worst: pivot แย่ ลึก n ชั้น
   → Space O(n) call stack */
Binary Search — stack O(log n)
int bs(int arr[], int lo, int hi, int x) {
    if (lo > hi) return -1;
    int mid = (lo+hi)/2;
    if (arr[mid]==x) return mid;
    if (arr[mid]<x)
        return bs(arr, mid+1, hi, x); ← n/2
    return bs(arr, lo, mid-1, x);     ← n/2
}
/* call stack depth = log₂(n)
   แต่ละ frame: i, j เล็กน้อย
   → Space O(log n) */
เห็น: recurse แบบ f(n/2) ครั้งเดียว (ไม่สร้าง array ใหม่)→O(log n) ทันที!
บทพิเศษ · Pattern 4

Recursion → Space = ความลึก Call Stack

วิธีคิดง่ายๆ: ลึกกี่ชั้น = Space เท่านั้น — ไม่ใช่จำนวน call ทั้งหมด

ภาพ call stack
merge_sort(0,7)  ← level 0
merge_sort(0,3) ← level 1
merge_sort(0,1) ← level 2
merge_sort(0,0) ← level 3 ← MAX DEPTH
n=8 → ลึกสุด log₂(8) = 3 ชั้น → Space O(log n)
ตาราง: recursion → space
Pattern RecursionStack DepthSpace
f(n-1) เรียกต่อเนื่องnO(n)
f(n/2) เรียกทีละข้างlog nO(log n)
f(n/2) เรียกสองข้างlog nO(log n)
f(n-1) + f(n-2)nO(n)
Merge Sort เรียก 2 ข้าง แต่ stack depth = log n เพราะ call เสร็จแล้วจึงไปต่อ
เห็น: f(n/2) → ลึก log n→O(log n)
เห็น: f(n-1) → ลึก n→O(n)
บทพิเศษ · Pattern 5

เห็นแบบนี้ → O(n²) หรือ O(n×m)

สร้าง 2D array หรือ nested structure ขนาด n×n

🔴 2D Array n×n
int dp[n][n];
int matrix[n][n];
char grid[n][n];
/* n×n ช่อง = O(n²) space
   n=1000 → 1,000,000 ints
   ≈ 4 MB */
⚠️ 2D Array n×m
int dp[n][m];
char table[n][m];
/* n×m ช่อง = O(n×m)
   เช่น LCS problem:
   n = len string 1
   m = len string 2 */
🔴 Adjacency Matrix
int adj[V][V]; /* V vertices */
/* Graph n nodes
   → O(n²) space
   เหมาะกับ Dense graph เท่านั้น
   Sparse → ใช้ Adjacency List */
⚠️ DP 1D = O(n) ดีกว่า 2D
/* Fibonacci DP:
   Naive: dp[n] = O(n)
   Optimized: แค่ 2 ตัวแปร */
int a = 0, b = 1; ← O(1)!
/* trade-off: เร็วเท่ากัน
   แต่ space น้อยกว่ามาก */
เห็น: arr[n][n] หรือ 2D struct→O(n²) ทันที!
บทพิเศษ · สรุปกฎ

5 กฎ ดูปั๊บรู้เลย

เห็น: แค่ตัวแปร int, pointer, flag หรือ array ขนาดคงที่ → O(1)
เห็น: recurse แบบ f(n/2) ทีละข้าง ไม่สร้าง array → O(log n)
เห็น: สร้าง int arr[n] หรือ recurse แบบ f(n-1) → O(n)
เห็น: Merge Sort pattern (สร้าง temp array ขนาด n ทุก level) → O(n)
เห็น: สร้าง arr[n][n] หรือ 2D structure → O(n²)
ลำดับถาม: ① สร้าง array ขนาดอะไร? → ② recurse ลึกแค่ไหน? → ③ เลือก Space ที่ใหญ่กว่าระหว่างสอง
บทพิเศษ · Workshop

ดูโค้ด → ตอบ Space ทันที

ใช้กฎ 5 ข้อ — หา "สิ่งที่สร้างขึ้นเพิ่ม" ในแต่ละโค้ด

/* ① Space = ? */
void f1(int arr[], int n) {
    int i=0, sum=0;       ← นับตรงนี้
    for (i=0; i<n; i++) sum += arr[i];
}  /* แค่ตัวแปร i, sum → O(1) */

/* ② Space = ? */
int* f2(int arr[], int n) {
    int *copy = malloc(n * sizeof(int));  ← นับตรงนี้
    for (int i=0; i<n; i++) copy[i] = arr[i];
    return copy;
}  /* malloc n ints → O(n) */

/* ③ Space = ? */
int f3(int n) {
    if (n==0) return 0;
    return n + f3(n-1);  ← f(n-1) ลึก n ชั้น
}  /* call stack n ชั้น → O(n) */

/* ④ Space = ? */
void f4(int arr[], int lo, int hi) {
    if (lo >= hi) return;
    int mid = (lo+hi)/2;  ← แค่ตัวแปร
    f4(arr, lo, mid);       ← f(n/2) ลึก log n
    f4(arr, mid+1, hi);
}  /* call stack log n ชั้น → O(log n) */

Sorting Algorithms — Space ทุกตัว อธิบายว่าเพราะอะไร

AlgorithmSpaceเหตุผล (เห็นแล้วเข้าใจ)
Bubble SortO(1) แค่ตัวแปร i, j, temp, swapped
Selection SortO(1) แค่ i, j, min_idx — ไม่สร้างอะไรใหม่
Insertion SortO(1) แค่ key, j — shift in-place
Heap SortO(1) heapify ใน array เดิม + i, largest เท่านั้น
Quick Sort (avg)O(log n) call stack ลึก log n ชั้น (pivot แบ่งครึ่ง)
Quick Sort (worst)O(n) call stack ลึก n ชั้น (pivot แย่ทุกรอบ)
Merge SortO(n) สร้าง temp arrays L, R รวม n elements
Counting SortO(k) count[k] + output[n] → O(n+k)
Radix SortO(n+k) output array n + count array k ทุก pass
จำง่าย: In-place (เรียงใน array เดิม) → O(1) · สร้าง array ใหม่ → O(n) · Recursion ลึก log n → O(log n)

void mystery_sort(int arr[], int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    int temp[r - l + 1];          ← สร้าง array ขนาด (r-l+1)
    /* ... merge logic ... */
    mystery_sort(arr, l, m);
    mystery_sort(arr, m+1, r);
}
/* วิเคราะห์:
   ① temp[r-l+1]: ทุก call สร้าง array ขนาด O(n) รวมกัน
   ② call stack: log n ชั้น
   ③ เลือกที่ใหญ่กว่า: max(O(n), O(log n)) = O(n)
   → นี่คือ Merge Sort! Space O(n) */
