ทำไมต้องเรียงข้อมูล?

ข้อมูลที่ถูก sort แล้ว ค้นหาได้เร็วกว่ามาก — Binary Search O(log n) ทำได้ก็ต่อเมื่อข้อมูลเรียงแล้วเท่านั้น

ค้นหาแบบ Linear (ไม่ได้ sort)
/* ต้องวนทุกตัว O(n) */
int i;
for (i = 0; i < n; i++) {
    if (arr[i] == target)
        return i;
}
/* 1,000,000 รายการ = loop 1M ครั้ง */
Binary Search (sort แล้ว)
/* แบ่งครึ่งทุกรอบ O(log n) */
int lo=0, hi=n-1;
while(lo <= hi){
    int mid=(lo+hi)/2;
    if(arr[mid]==target) ...
    else if(arr[mid]<target) lo=mid+1;
    else hi=mid-1;
}
/* 1,000,000 รายการ = loop แค่ 20 ครั้ง! */
Sort ใช้ใน: แสดงรายการธุรกรรมล่าสุดก่อน · จัดอันดับ credit score · ค้นหาลูกค้าตามชื่อ · Group ข้อมูลตามประเภท

Stability — ลำดับ relative ของค่าเท่ากัน

Stable sort รักษาลำดับเดิมของ element ที่มีค่าเท่ากัน — สำคัญมากเมื่อ sort หลาย key

ก่อน sort (เรียงตาม Amount)
TXN  Name      Amount
T001 สมชาย    500
T002 สมหญิง   300  ← ซ้ำ
T003 วิชัย    300  ← ซ้ำ
T004 มานี     100
Stable vs Unstable
/* Stable sort → ลำดับ T002, T003 ยังเดิม */
T004 มานี     100
T002 สมหญิง   300  ✅ ยังมาก่อน
T003 วิชัย    300
T001 สมชาย    500

/* Unstable sort → อาจสลับ */
T004 มานี     100
T003 วิชัย    300  ⚠️ สลับ!
T002 สมหญิง   300
T001 สมชาย    500
ธนาคารต้องใช้ Stable sort เมื่อ sort ธุรกรรมตาม amount แล้ว sort อีกรอบตาม date — ต้องการ sort หลาย level โดยรักษาลำดับจาก level ก่อน

In-place vs Out-of-place

In-place = sort ในอาร์เรย์เดิม ไม่ต้องใช้ array เพิ่ม O(1) extra space — Out-of-place = ต้องการ array ช่วย O(n)

In-place — ใช้ memory น้อย
/* Bubble, Selection, Insertion,
   Quick, Heap Sort */
void bubble_sort(int arr[], int n) {
    /* แก้ค่าใน arr เดิมเลย */
    /* ไม่สร้าง array ใหม่ */
}

/* Memory เพิ่ม: O(1) — แค่ตัวแปร temp */
Out-of-place — ต้องการ extra space
/* Merge Sort */
void merge(int arr[], int l,
           int m, int r) {
    /* ต้องสร้าง temp array */
    int temp[r - l + 1];
    /* copy กลับไป arr */
}

/* Memory เพิ่ม: O(n) */
Embedded system หรือ environment ที่ memory จำกัด → ใช้ In-place sort · ถ้า memory ไม่ใช่ปัญหา → Merge Sort stable + O(n log n) guaranteed

Swap Function — หัวใจของ Sorting

ทุก comparison-based sort ใช้ swap ในการสลับตำแหน่ง — ต้องส่ง pointer เพื่อให้แก้ค่าจริงใน caller

/* ผิด — เปลี่ยนแค่ copy local */
void swap_wrong(int a, int b) {
    int temp = a;
    a = b;
    b = temp;  /* a, b ที่นี่เป็น local copy — caller ไม่เห็น */
}

/* ถูก — ส่ง pointer เข้ามา */
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

/* เรียก: ส่ง address ด้วย & */
int arr[] = {5, 3};
swap(&arr[0], &arr[1]);  /* → {3, 5} */

/* XOR swap — ไม่ใช้ temp (เท่ แต่อ่านยาก) */
void swap_xor(int *a, int *b) {
    *a ^= *b;
    *b ^= *a;
    *a ^= *b;  /* a=5,b=3 → a=6,b=5,a=3 */
}

/* sort transactions array ตาม amount */
typedef struct { int id; double amount; } Txn;

int cmp_amount(const void *a, const void *b) {
    Txn *ta = (Txn *)a, *tb = (Txn *)b;
    return (ta->amount > tb->amount) - (ta->amount < tb->amount);
}
qsort(txns, n, sizeof(Txn), cmp_amount); /* stdlib Quick Sort */
