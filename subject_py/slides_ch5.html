บทที่ 5 · class

class คืออะไร — Blueprint ของ Object

class คือแม่แบบ — Object คือสิ่งที่สร้างจากแม่แบบนั้น เช่น class BankAccount → object บัญชีของสมชาย

C — struct (ไม่มี method)
struct BankAccount {
    char owner[50];
    double balance;
};
/* ต้องแยก function ออกมา */
void deposit(struct BankAccount *a,
             double amt) {
    a->balance += amt;
}
Python — class (data + method รวมกัน)
class BankAccount:
    def __init__(self, owner):
        self.owner = owner
        self.balance = 0

    def deposit(self, amount):
        self.balance += amount

# สร้าง object
acc = BankAccount("สมชาย")
acc.deposit(50_000)
class รวม data (attributes) และ function (methods) ไว้ด้วยกัน — ทำให้โค้ดจัดระเบียบง่ายขึ้น
บทที่ 5 · __init__ & self

__init__ และ self — Constructor ของ Python

__init__ ถูกเรียกอัตโนมัติตอน create object — self คือ reference ถึง object ตัวเอง (เหมือน this ใน Java แต่ต้องเขียนชัดเจน)

class BankAccount:
    def __init__(self, owner, initial_balance=0):
        # self.xxx คือ instance attribute
        self.owner = owner
        self.balance = initial_balance
        self.transactions = []   # แต่ละ object มี list ของตัวเอง

    def deposit(self, amount):
        self.balance += amount
        self.transactions.append((+amount, "ฝาก"))

    def get_balance(self):
        return self.balance

# self ถูกส่งอัตโนมัติเมื่อเรียกผ่าน object
acc1 = BankAccount("สมชาย")
acc2 = BankAccount("สมหญิง", 10_000)

acc1.deposit(5_000)   # Python แปลเป็น BankAccount.deposit(acc1, 5000)
acc2.deposit(3_000)   # acc1 และ acc2 เก็บ transaction แยกกัน
ทำไม Python ต้องเขียน self ชัดเจน? — เพราะ Explicit is better than implicit (Zen of Python)
บทที่ 5 · Encapsulation

Encapsulation — _ และ __ Convention

Python ไม่มี private/public keyword เหมือน Java — ใช้ naming convention แทน

class BankAccount:
    def __init__(self, owner):
        self.owner = owner         # public — เข้าถึงได้จากนอก
        self._pin = "1234"       # _single: "please don't touch" convention
        self.__balance = 0       # __double: name mangling — ซ่อนแน่นกว่า

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount   # เข้าถึง __balance ได้ใน class

    def get_balance(self):
        return self.__balance

acc = BankAccount("สมชาย")
print(acc.owner)          # ✅ "สมชาย"
print(acc._pin)           # ⚠️ ทำได้แต่ไม่ควร
# print(acc.__balance)   # ❌ AttributeError
print(acc._BankAccount__balance)  # ✅ name mangling — เข้าถึงได้แต่ ugly
print(acc.get_balance())  # ✅ วิธีที่ถูกต้อง
Python เชื่อใจ developer — ไม่บังคับ private แต่ใช้ convention บอกว่า "อย่าแตะ"
บทที่ 5 · @property

@property — Getter/Setter แบบ Pythonic

ใน Java ต้องเขียน getBalance(), setBalance() — Python ใช้ @property ทำให้ method เรียกได้เหมือน attribute

Java style (ไม่ Pythonic)
def get_balance(self):
    return self.__balance

def set_balance(self, v):
    if v >= 0:
        self.__balance = v

# เรียก
acc.get_balance()
acc.set_balance(1000)
Pythonic — @property
@property
def balance(self):
    return self.__balance

@balance.setter
def balance(self, v):
    if v >= 0:
        self.__balance = v

# เรียกเหมือน attribute!
acc.balance       # getter
acc.balance = 1000  # setter
# @property ใช้เพิ่ม validation และ computed attribute
@property
def tier(self):   # computed จาก balance
    if self.__balance >= 500_000: return "Platinum"
    if self.__balance >= 100_000: return "Gold"
    return "Silver"

print(acc.tier)   # เรียกเหมือน attribute แต่ compute ทุกครั้ง
บทที่ 5 · Attributes

Class Attribute vs Instance Attribute

Class attribute ใช้ร่วมกันทุก object — Instance attribute เป็นของแต่ละ object

class BankAccount:
    # Class attribute — ทุก object ใช้ร่วมกัน
    bank_name = "KTB"
    interest_rate = 0.025
    _total_accounts = 0   # นับบัญชีทั้งหมด

    def __init__(self, owner):
        # Instance attributes — แต่ละ object มีของตัวเอง
        self.owner = owner
        self.__balance = 0
        BankAccount._total_accounts += 1

    @classmethod
    def get_total(cls):
        return cls._total_accounts   # cls คือ class เอง

    @staticmethod
    def validate_amount(amount):
        return amount > 0   # ไม่ต้องการ self หรือ cls

a1 = BankAccount("สมชาย")
a2 = BankAccount("สมหญิง")
print(BankAccount.get_total())        # 2
print(BankAccount.validate_amount(-5))  # False
print(a1.bank_name)                   # "KTB" — อ่าน class attr ผ่าน instance
บทที่ 5 · Dunder Methods

__str__ และ __repr__ — แสดง Object เป็น String

ถ้าไม่เขียน __str__ การ print object จะได้ <BankAccount object at 0x...> — ต้องเขียนเองให้อ่านได้

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance

    def __str__(self):
        # ใช้เมื่อ print() — สำหรับผู้ใช้อ่าน
        return f"บัญชีของ {self.owner} ยอด {self.__balance:,} บาท"

    def __repr__(self):
        # ใช้ใน debug — สำหรับ developer
        return f"BankAccount(owner='{self.owner}', balance={self.__balance})"

    def __len__(self):
        # len(acc) — คืนจำนวนธุรกรรม
        return len(self.transactions)

acc = BankAccount("สมชาย", 50_000)
print(acc)        # บัญชีของสมชาย ยอด 50,000 บาท
repr(acc)         # BankAccount(owner='สมชาย', balance=50000)
Dunder methods (double underscore) คือ magic methods ของ Python — ทำให้ object ทำงานกับ built-in functions ได้
บทที่ 5 · Banking Use Case

🏦 BankAccount class แบบสมบูรณ์

class BankAccount:
    def __init__(self, owner, account_id):
        self.owner = owner
        self.account_id = account_id
        self.__balance = 0
        self.__transactions = []

    @property
    def balance(self):
        return self.__balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("จำนวนเงินต้องมากกว่า 0")
        self.__balance += amount
        self.__transactions.append({"type": "D", "amount": amount})
        return self

    def withdraw(self, amount):
        if amount > self.__balance:
            raise ValueError("ยอดเงินไม่เพียงพอ")
        self.__balance -= amount
        self.__transactions.append({"type": "W", "amount": amount})
        return self  # return self → method chaining!

    def __str__(self):
        return f"[{self.account_id}] {self.owner}: {self.__balance:,} บาท"

# Method chaining
acc = BankAccount("สมชาย", "A001")
acc.deposit(50_000).withdraw(12_000).deposit(5_000)
print(acc)
