Nested Loop — ลูปในลูป

ใช้เมื่อลูปรอบเดียวทำไม่ได้ เช่น ข้อมูลแบบตาราง ที่มีทั้งแถวและคอลัมน์

โจทย์: พิมพ์ * เป็นสี่เหลี่ยม 3×3
# แบบไม่ใช้ nested loop — เขียน 3 ชุด
for i in range(3):
    print("*", end='')
print('')
for i in range(3):
    print("*", end='')
print('')
for i in range(3):
    print("*", end='')
print('')
# ← ซ้ำ 3 ชุด ถ้า 100 แถวล่ะ?
แบบ nested loop
for i in range(3):        # ลูปนอก = แถว
    for j in range(3):    # ลูปใน = คอลัมน์
        print("*", end='')
    print('')          # จบแถว → ขึ้นบรรทัดใหม่
*** *** ***
# กฎทอง:
# ลูปนอกหมุน 1 รอบ
#   → ลูปในหมุน "ครบทุกรอบ"
# 3 × 3 = พิมพ์ * ทั้งหมด 9 ครั้ง
จุดที่ต้องระวังที่สุด: print('') ต้องอยู่ในลูปนอก ไม่ใช่ลูปใน — ถ้าเยื้องเข้าไปในลูปใน จะขึ้นบรรทัดใหม่ทุกดาว กลายเป็นแนวตั้ง
บทที่ 8 · ไล่ทีละรอบ

Trace: ลูปนอก i × ลูปใน j

for i in range(3):
    for j in range(2):
        print(i, j)

—0—j หมด → กลับไปลูปนอก
3101 0i รอบ 2 · j เริ่มนับใหม่จาก 0!
4111 1
5202 0i รอบ 3 · j เริ่มใหม่อีก

หัวใจของ nested loop: ตัวแปรลูปในถูกรีเซ็ตใหม่ทุกครั้งที่ลูปนอกหมุน — จำนวนรอบทั้งหมด = รอบนอก × รอบใน = 3 × 2 = 6 ครั้ง

ตารางสูตรคูณ 2×1 ถึง 8×8

แบบ while (ตามสไลด์อาจารย์)
i = 2
while i <= 8:
    j = 1              # รีเซ็ต j ทุกแถว!
    while j <= 8:
        print(i*j, end=' ')
        j += 1
    print('')         # จบแถว
    i += 1
แบบ for — สั้นกว่า
for i in range(2, 8+1):
    for j in range(1, 8+1):
        print(i*j, end=' ')
    print('')

# จัดคอลัมน์ให้ตรงด้วย f-string:
for i in range(2, 9):
    for j in range(1, 9):
        print(f"{i*j:4}", end='')

บทที่ 8 · รูปดาว

วาดรูปดาว — ความลับอยู่ที่ range ของลูปใน

① สี่เหลี่ยม — ลูปในคงที่
for i in range(4):
    for j in range(4):   # คงที่ 4
        print("*", end='')
    print()
**** **** **** ****
② สามเหลี่ยมเพิ่มขึ้น — ลูปในตาม i
for i in range(1, 5):
    for j in range(i):  # ← ตาม i!
        print("*", end='')
    print()
* ** *** ****
③ สามเหลี่ยมลดลง
for i in range(4, 0, -1):  # นับถอยหลัง
    for j in range(i):
        print("*", end='')
    print()
**** *** ** *
④ สามเหลี่ยมชิดขวา — เติมช่องว่างก่อน
for i in range(1, 5):
    for s in range(4-i):   # ช่องว่าง
        print(" ", end='')
    for j in range(i):     # ดาว
        print("*", end='')
    print()
* ** *** ****
สูตรทำโจทย์รูปดาว: ดูว่า แต่ละแถวมีกี่ตัว แล้วเขียนเป็นฟังก์ชันของ i — คงที่ → range(n) · เพิ่มขึ้น → range(i) · ลดลง → range(n-i)
บทที่ 8 · break

break — ออกจากลูปทันที

ตัวอย่างพื้นฐาน
for i in range(1, 11):
    if i == 5:
        break          # ออกทันที
    print(i, end=' ')
1 2 3 4
# พอ i เป็น 5 → break
# ไม่พิมพ์ 5 และไม่วนต่อถึง 10
ใช้จริง: ค้นหาแล้วหยุด
nums = [4, 8, 15, 16, 23]
target = 15
for i in range(len(nums)):
    if nums[i] == target:
        print("เจอที่ตำแหน่ง", i)
        break      # เจอแล้ว ไม่ต้องหาต่อ
break ใน nested loop — ออกแค่ลูปเดียว!
for i in range(3):
    for j in range(3):
        if j == 1:
            break      # ออกจากลูป j เท่านั้น
        print(i, j)
0 0 1 0 2 0
# ลูปนอก i ยังวนครบ 3 รอบ!
# break ออกได้แค่ "ลูปชั้นที่มันอยู่"

# อยากออกทั้งสองชั้น → ใช้ flag:
found = False
for i in range(3):
    for j in range(3):
        if ...:
            found = True
            break
    if found:
        break
ข้อสอบชอบถาม: "break ใน nested loop ออกจากลูปไหน" → ออกจากลูปชั้นในสุดที่มันอยู่เท่านั้น ลูปนอกยังทำงานต่อ
บทที่ 8 · continue

continue — ข้ามรอบนี้ ไปรอบถัดไป

เทียบกับ break ให้ชัด
# continue — ข้ามเฉพาะรอบนี้
for i in range(1, 6):
    if i == 3:
        continue       # ข้าม 3
    print(i, end=' ')
1 2 4 5
# break — หยุดทั้งลูป
for i in range(1, 6):
    if i == 3:
        break
    print(i, end=' ')
1 2
ใช้จริง: กรองข้อมูล
# พิมพ์เฉพาะเลขคู่
for i in range(1, 11):
    if i % 2 != 0:
        continue       # เลขคี่ → ข้าม
    print(i, end=' ')
# 2 4 6 8 10
# ข้ามค่าที่ผิดปกติ
scores = [85, -1, 90, 200, 78]
total = 0
count = 0
for s in scores:
    if s < 0 or s > 100:
        continue   # ข้ามค่าที่ใช้ไม่ได้
    total += s
    count += 1
print(total / count)  # 84.33
จำง่ายๆ: break = "พอแล้ว เลิกวน" · continue = "รอบนี้ข้ามไป วนต่อ" — ทั้งคู่ใช้ได้ทั้ง for และ while
บทที่ 8 · Use Case

🏦 รวมทุกอย่าง — ระบบตรวจสอบธุรกรรม

# ข้อมูลธุรกรรมของลูกค้า 3 คน คนละหลายรายการ
customers = {
    "สมชาย": [1200, 500, -100, 8000],
    "สมศรี": [300, 450, 200],
    "สมหญิง": [50000, 100],
}

LIMIT = 10000      # วงเงินที่ต้องแจ้งเตือน

for name, txns in customers.items():    # ลูปนอก = ลูกค้าแต่ละคน
    total = 0
    print(f"── {name} ──")

    for t in txns:                       # ลูปใน = ธุรกรรมของคนนั้น
        if t <= 0:
            print(f"  ข้าม {t} (ยอดไม่ถูกต้อง)")
            continue                    # ข้ามรายการเสีย วนต่อ

        if t >= LIMIT:
            print(f"  ⚠️ พบยอด {t} เกินวงเงิน — หยุดตรวจ")
            break                       # เจอแล้วหยุดเลย

        total += t
        print(f"  + {t}")

    print(f"  รวม: {total}\n")         # อยู่ในลูปนอก = สรุปต่อคน

"""
── สมชาย ──          ← continue ข้าม -100
  + 1200                break ตอนเจอ 8000? ไม่ (8000 < 10000)
  + 500
  ข้าม -100 (ยอดไม่ถูกต้อง)
  + 8000
  รวม: 9700

── สมหญิง ──         ← break ทันทีที่เจอ 50000
  ⚠️ พบยอด 50000 เกินวงเงิน — หยุดตรวจ
  รวม: 0
"""
โจทย์จริงมักผสม nested loop + break + continue แบบนี้ — continue คัดข้อมูลเสียทิ้ง · break หยุดเมื่อเจอสิ่งที่ตามหา · สังเกตว่า break ออกแค่ลูปใน ลูกค้าคนถัดไปยังถูกตรวจต่อ
