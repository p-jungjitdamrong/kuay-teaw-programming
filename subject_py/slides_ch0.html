บทที่ 0 · เปรียบเทียบ

C vs Python — เทียบบรรทัดต่อบรรทัด

งานเดียวกัน โค้ดต่างกันมาก — อ่านเทียบกันเลย

C — อ่านยอดในอาร์เรย์
#include <stdio.h>
int main() {
    int nums[] = {10, 20, 30};
    int total = 0;
    for (int i = 0; i < 3; i++) {
        total += nums[i];
    }
    printf("%d\n", total);
    return 0;
}
Python — งานเดียวกัน
nums = [10, 20, 30]
print(sum(nums))  # 60
10 บรรทัด → 2 บรรทัด
ไม่มี #include ไม่มี main()
ไม่มี type declaration ไม่มี return
บทที่ 0 · Philosophy

The Zen of Python — PEP 20

พิมพ์ import this ใน Python จะได้หลักการ 19 ข้อ — นี่คือข้อสำคัญที่สุด

  • Beautiful is better than ugly. โค้ดสวยงาม อ่านได้ ดีกว่าโค้ดที่ทำงานได้แต่อ่านไม่รู้เรื่อง
  • Explicit is better than implicit. บอกชัดเจนว่าทำอะไร ดีกว่าให้คนอ่านเดา
  • Simple is better than complex. เขียนง่ายๆ ก่อน — ซับซ้อนได้เมื่อจำเป็นเท่านั้น
  • Readability counts. โค้ดอ่านได้ = maintainable = ทีมทำงานร่วมกันได้
  • There should be one — and preferably only one — obvious way to do it. Python มีวิธี "Pythonic" เดียวสำหรับแต่ละงาน ไม่ใช่ 10 วิธี
ใน C มีหลายวิธีทำงานเดียวกัน — Python ชี้ทาง "ถูก" ไว้แล้ว เรียกว่า Pythonic

PEP 8 — ข้อตกลงการเขียนโค้ด Python

PEP = Python Enhancement Proposal — PEP 8 คือ Style Guide ที่ทุกคนใช้ร่วมกัน

✅ Pythonic (PEP 8)
# ชื่อตัวแปร: snake_case
account_balance = 1000
user_name = "somchai"

# ชื่อ class: PascalCase
class BankAccount:
    pass

# ชื่อ constant: UPPER_SNAKE
MAX_RETRY = 3

# เว้นวรรค 2 บรรทัดระหว่าง function
def deposit(amount):
    pass


def withdraw(amount):
    pass
❌ ไม่ Pythonic
# camelCase ใช้ใน C/Java ไม่ใช่ Python
accountBalance = 1000
userName = "somchai"

# ชื่อ class ตัวเล็ก
class bankaccount:
    pass

# ไม่เว้นบรรทัด
def deposit(amount):
    pass
def withdraw(amount):
    pass
Indent ใน Python ใช้ 4 spaces (ไม่ใช่ tab) — indentation ไม่ใช่แค่สวยงาม แต่เป็น syntax จริงๆ
บทที่ 0 · Syntax

Indentation คือ Syntax — ไม่มี { } ใน Python

ใน C ใช้ { } บอก block — Python ใช้ การย่อหน้า (indent) 4 spaces แทน

C — ใช้ { }
if (score >= 50) {
    printf("ผ่าน\n");
    grade = 'C';
} else {
    printf("ไม่ผ่าน\n");
}
Python — ใช้ indent
if score >= 50:
    print("ผ่าน")
    grade = "C"
else:
    print("ไม่ผ่าน")
⚠️ IndentationError คือ error ที่เจอบ่อยที่สุดสำหรับคนมาจาก C — ถ้า indent ผิดโปรแกรม error ทันที
ข้อดี: บังคับให้โค้ดสวยงามตลอด — ไม่มีโค้ดที่ indent ยุ่งเหยิงแต่ยังรันได้
บทที่ 0 · Type System

Dynamic Typing — Python รู้ type เองตอน runtime

ใน C ต้อง declare type ก่อนใช้เสมอ — Python ดูค่าที่ assign แล้วรู้เองว่า type อะไร

# Python — ไม่ต้อง declare type
x = 42          # x เป็น int
x = "hello"     # x เปลี่ยนเป็น str ได้เลย!
x = 3.14        # x เปลี่ยนเป็น float

# ตรวจ type ได้ด้วย type()
print(type(42))       # <class 'int'>
print(type("hello"))  # <class 'str'>
print(type(3.14))     # <class 'float'>
print(type(True))     # <class 'bool'>

# Python 3.9+ มี Type Hints (optional)
balance: float = 1000.0  # แค่ hint ไม่บังคับ
Dynamic Typing ทำให้เขียนเร็ว — แต่ต้องระวัง type error ตอน runtime เพราะ compiler ไม่จับให้
