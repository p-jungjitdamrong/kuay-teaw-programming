ไล่จากล่างขึ้นบน
① ภาษาเครื่อง (Machine Language)
   เขียนด้วย 0 กับ 1 เท่านั้น
   00000101 10101010 00000110  ← 5+6
   • ภาษาเดียวที่คอมพิวเตอร์เข้าใจทันที
   • เร็วที่สุด แต่คนเขียนแทบไม่ไหว
   • ผูกกับ CPU รุ่นนั้นๆ (Machine Dependent)

② ภาษาระดับต่ำ (Assembly)
   ใช้ชื่อย่อแทนคำสั่ง: ADD, LD, MUL, SUB
   ใช้ชื่อแทนตำแหน่งหน่วยความจำ: R1, R2
   • คนอ่านง่ายขึ้น แต่ยังผูกกับเครื่อง

③ ภาษาระดับสูง (High-Level)
   Python, C, Java — ใกล้ภาษาคน
   • ไม่ผูกกับเครื่อง เขียนครั้งเดียวใช้ได้หลายที่
ทุกภาษาต้องกลายเป็นภาษาเครื่อง
โค้ด Python (คนเขียน) │ │ ตัวแปลภาษา ▼ ภาษาเครื่อง (CPU รัน)

บทที่ 1 · รูปแบบที่ 1

Sequence — ทำเรียงลงมาทีละขั้น

ผังงาน: หาพื้นที่สี่เหลี่ยมผืนผ้า
⬭ เริ่มต้น │ ▱ รับ w, h │ ▭ area = w × h │ ▽ แสดง area │ ⬭ จบ
แปลงเป็นโค้ด
# ⬭ เริ่มต้น — ไม่ต้องเขียนอะไร

# ▱ รับข้อมูล
w = float(input("กว้าง: "))
h = float(input("ยาว: "))

# ▭ ประมวลผล
area = w * h

# ▽ แสดงผล
print("พื้นที่ =", area)

# ⬭ จบ — จบไฟล์
โครง รับ → คำนวณ → แสดง คือแม่แบบของโจทย์ 80% ในบทต้นๆ — วาดผังงานได้ก็เขียนโค้ดได้ทันที เพราะแต่ละกล่อง = 1 บรรทัด
บทที่ 1 · รูปแบบที่ 2

Selection — แยกทางด้วย ◇

if เดี่ยว (ทางเดียว)
│ ◇ x < 0 ─── เท็จ ──┐ │ จริง │ ▽ "ติดลบ" │ │ │ └────────────────┘ │
if x < 0:
    print("ติดลบ")
if-else (สองทาง)
│ ◇ score >= 50 จริง │ │ เท็จ ▽"ผ่าน" │ ▽"ตก" │ │ └──┴──┐ │
if score >= 50:
    print("ผ่าน")
else:
    print("ตก")
กฎการอ่าน ◇: ต้องมีทางออก 2 ทางเสมอ (จริง/เท็จ) และทั้งสองทางต้องกลับมาบรรจบกันก่อนไปต่อ — ถ้าวาดแล้วมีเส้นค้าง แสดงว่าลืมเคสใดเคสหนึ่ง
บทที่ 1 · Nested if

◇ ซ้อน ◇ — เงื่อนไขหลายชั้น

ผังงาน: ตัดเกรด
◇ s >= 80 จริง│ │เท็จ ▽"A" │ ◇ s >= 70 │ จริง│ │เท็จ │ ▽"B"│ ◇ s >= 60 │ │จริง│ │เท็จ │ │▽"C"│ ▽"F"
2 วิธีเขียน — ผลเหมือนกัน
# แบบซ้อนจริง (ตามผังงานเป๊ะ)
if s >= 80:
    print("A")
else:
    if s >= 70:
        print("B")
    else:
        if s >= 60:
            print("C")
        else:
            print("F")

# แบบ elif — Python นิยมกว่า
if s >= 80:   print("A")
elif s >= 70: print("B")
elif s >= 60: print("C")
else:         print("F")
จุดพลาดคลาสสิก: เรียงเงื่อนไขผิดลำดับ — ถ้าเช็ค s >= 60 ก่อน คนได้ 90 จะได้ "C" เพราะเข้าเงื่อนไขแรกแล้วหยุด · เรียงจากแคบไปกว้างเสมอ
บทที่ 1 · รูปแบบที่ 3

Loop — ◇ ที่มีเส้นย้อนกลับ

ผังงาน: พิมพ์ Hello 2000 ครั้ง
▭ i = 0 │ ▼ ┌─▶ ◇ i < 2000 ── เท็จ ──▶ จบ │ │ จริง │ ▽ "Hello" │ │ │ ▭ i = i + 1 │ │ └──────┘ ← เส้นย้อนกลับ!
แปลงได้ 2 แบบ
# while — ตามผังงานตรงตัว
i = 0
while i < 2000:
    print("Hello, Kitty")
    i = i + 1

# for — สั้นกว่า เมื่อรู้จำนวนรอบ
for i in range(2000):
    print("Hello, Kitty")
# คำศัพท์ 2 แบบของการวนซ้ำ:
# Counting Loop — รู้จำนวนรอบล่วงหน้า
#   → ใช้ for
# Sentinel Loop — วนจนเจอค่าหยุด
#   → ใช้ while

# Sentinel: วนจนกว่าจะใส่ 0
n = int(input())
while n != 0:
    print(n * 2)
    n = int(input())
วิธีดูว่าเป็นลูปในผังงาน: มีเส้นย้อนกลับขึ้นไปหา ◇ เดิม — ถ้าลืมกล่อง i = i + 1 จะกลายเป็น infinite loop ทันที (ข้อสอบชอบเว้นกล่องนี้ให้เติม)
บทที่ 1 · ฝึกแปลง

อ่านผังงาน → เขียนโค้ด (ทำให้ดูจบๆ)

โจทย์: หาผลรวม 1..n
▱ รับ n │ ▭ sum = 0, i = 1 │ ▼ ┌─▶ ◇ i <= n ── เท็จ ─┐ │ │ จริง │ │ ▭ sum = sum + i │ │ │ │ │ ▭ i = i + 1 │ │ │ │ └──────┘ ▽ แสดง sum │ ⬭ จบ
เฉลย
n = int(input("n = "))

sum = 0          # กล่อง ▭ ตัวแรก
i = 1

while i <= n:     # กล่อง ◇
    sum = sum + i  # ▭ ในลูป
    i = i + 1      # ▭ เพิ่มตัวนับ

print("ผลรวม =", sum)   # ▽

# n = 5 → 1+2+3+4+5 = 15
# เขียนด้วย for ก็ได้:
sum = 0
for i in range(1, n+1):
    sum += i
print(sum)
เทคนิคทำข้อสอบ: เขียน ตัวแปรกับค่าของมันกำกับข้างผังงาน แล้วไล่ทีละรอบ (i=1 sum=1 → i=2 sum=3 → i=3 sum=6...) — เห็นแพตเทิร์นแล้วเขียนโค้ดถูกแน่
