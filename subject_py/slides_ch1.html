บทที่ 1 · Types

Built-in Types ใน Python

Python มี type พื้นฐานครบ — ไม่ต้อง include header ไม่ต้อง declare ก่อนใช้

Typeตัวอย่างหมายเหตุ
int42, -7, 0ขนาดไม่จำกัด (ต่างจาก C int 32-bit)
float3.14, -0.5, 1e10เทียบเท่า double ใน C
str"hello", 'ธนาคาร'Unicode ในตัว — ไม่ต้องแปลง Thai
boolTrue, Falseตัวใหญ่! — ต่างจาก C ที่ใช้ 0/1
NoneNoneเทียบได้กับ NULL ใน C — "ไม่มีค่า"
complex2+3jจำนวนเชิงซ้อน — ใช้ใน signal processing
 
balance = 50000          # int
rate = 0.025             # float
name = "สมชาย ใจดี"       # str — Thai ได้เลย
is_active = True         # bool

บทที่ 1 · Operators

Operators — Python มีของพิเศษที่ C ไม่มี

Arithmetic เหมือน C แต่มีบางตัวที่ต่างออกไป — ต้องจำ

Arithmetic
10 + 3   # 13
10 - 3   # 7
10 * 3   # 30
10 / 3   # 3.333... (float เสมอ!)
10 // 3  # 3 (integer division)
10 % 3   # 1 (modulo)
10 ** 3  # 1000 (ยกกำลัง!)
⚠️ / ใน Python 3 คือ float เสมอ
10/3 = 3.333 ไม่ใช่ 3
Comparison & Logical
# Comparison → bool
5 == 5   # True
5 != 3   # True
5 > 3    # True

# Logical — Python ใช้คำ ไม่ใช่ &&/||
True and False  # False
True or False   # True
not True        # False

# Chaining — Python ทำได้, C ไม่ได้
1 < x < 10  # ถ้า x=5 → True!
บทที่ 1 · String

String ใน Python — ทรงพลังมากกว่า C มาก

ใน C string คือ char array จัดการยาก — Python string เป็น object มี method ในตัวครบ

s = "Hello Python"

# Indexing — เหมือน C
s[0]      # 'H'
s[-1]     # 'n' (index ลบ = นับจากท้าย)

# Slicing [start:end:step] — C ไม่มี
s[0:5]    # 'Hello'
s[6:]     # 'Python'
s[::-1]   # 'nohtyP olleH' (reverse!)

# Methods — ใช้ . เรียก
s.upper()          # 'HELLO PYTHON'
s.lower()          # 'hello python'
s.replace("Hello", "Hi")  # 'Hi Python'
s.split(" ")       # ['Hello', 'Python']
s.startswith("H") # True
len(s)             # 12
บทที่ 1 · f-string

f-string — แทน printf ของ C

f-string คือวิธีที่ Pythonic ที่สุด สำหรับ format string — ใส่ expression ใน { } ได้เลย

C — printf format
char name[] = "สมชาย";
double bal = 50000.0;
printf("ชื่อ: %s\n", name);
printf("ยอด: %.2f บาท\n", bal);
Python — f-string
name = "สมชาย"
balance = 50000.0
print(f"ชื่อ: {name}")
print(f"ยอด: {balance:,.2f} บาท")
# Format spec ใน f-string
x = 1234567.89
print(f"{x:,.2f}")   # 1,234,567.89 — ใส่ comma + 2 decimal
print(f"{x:.0f}")    # 1234568 — ปัดเศษ
print(f"{42:05d}")   # 00042 — zero-pad 5 หลัก

# Expression ใน { } ได้เลย
print(f"ดอกเบี้ย: {50000 * 0.025:,.2f} บาท")  # 1,250.00
f-string เร็วกว่า .format() และ % formatting — ใช้ f-string เสมอใน Python 3.6+
บทที่ 1 · Input

input() — รับค่าจากผู้ใช้

input() คืน string เสมอ — ต้องแปลง type เองถ้าต้องการตัวเลข

C — scanf
int amount;
printf("ใส่จำนวนเงิน: ");
scanf("%d", &amount);
Python — input()
amount = int(input("ใส่จำนวนเงิน: "))
# Type conversion functions
int("42")      # 42 (str → int)
float("3.14")  # 3.14 (str → float)
str(100)      # "100" (int → str)
bool(0)       # False — 0 คือ False, อื่นๆ คือ True

# ตัวอย่างโปรแกรม ATM
name = input("ชื่อลูกค้า: ")
amount = float(input("จำนวนเงินฝาก: "))
print(f"คุณ {name} ฝากเงิน {amount:,.2f} บาท เรียบร้อย")
⚠️ input() คืน str เสมอ — ถ้า int(input()) แล้วผู้ใช้พิมพ์ "abc" จะ ValueError
บทที่ 1 · Assignment

Multiple Assignment & Unpacking

Python มีวิธี assign หลายตัวพร้อมกัน — เป็น syntax ที่ C ไม่มี

# Multiple assignment ในบรรทัดเดียว
a, b, c = 1, 2, 3

# Swap โดยไม่ต้องใช้ temp variable!
a, b = b, a   # ใน C ต้องใช้ tmp

# Augmented assignment
x = 10
x += 5   # x = 15
x *= 2   # x = 30
x //= 4  # x = 7

# Unpack จาก list/tuple
coords = (13.76, 100.50)
lat, lng = coords   # lat=13.76, lng=100.50

# Star unpack
first, *rest = [1, 2, 3, 4]
# first=1, rest=[2,3,4]
Python ไม่มี ++ และ -- — ใช้ += 1 และ -= 1 แทน
บทที่ 1 · Banking Use Case

🏦 คำนวณดอกเบี้ยเงินฝากประจำ

โปรแกรม Python เดี่ยวที่ใช้ syntax ทั้งหมดในบทนี้

# คำนวณดอกเบี้ยเงินฝากประจำ — KTB
principal = float(input("เงินต้น (บาท): "))
rate_pct = float(input("ดอกเบี้ย (%/ปี): "))
years = int(input("ระยะเวลา (ปี): "))

rate = rate_pct / 100
interest = principal * rate * years
total = principal + interest

print(f"""
=== สรุปเงินฝากประจำ ===
เงินต้น  : {principal:>12,.2f} บาท
ดอกเบี้ย : {interest:>12,.2f} บาท
รวมทั้งหมด: {total:>12,.2f} บาท
""")
Triple-quote string """...""" ใช้เขียน multiline string — ไม่ต้อง \n ทุกบรรทัด
