ติว 5 บท ตามขอบเขตสอบจริง
สรุปจากสไลด์อาจารย์ + ใบ practice + lab ทุกใบใน data-midterm — เจาะเฉพาะที่ออกสอบ
🧱→
ติวบทที่ 1
Intro + Array — เก็บคะแนนฟรี
DS คืออะไร ตอบยังไงให้ได้คะแนน, Array ทำอะไรได้/ไม่ได้, insert/remove ต้องเลื่อนข้อมูลยังไง — บทนี้คือข้อสอบปรนัยฟรีๆ
12 slidesจุดออกสอบชัด
⏱️→
ติวบทที่ 2 · ออกแน่
T(n) + Big-O — ข้อสอบตัวเป้ง
นับ T(n) ทีละบรรทัดแบบที่อาจารย์ให้คะแนน, กฎหา Big-O, Best/Worst case + เฉลย function_A B C จากใบ practice จริง
14 slidesเฉลย practice ครบ
🔄→
ติวบทที่ 3 · ออกแน่
Sorting 3 ตัว — trace ลงตาราง
Selection / Insertion / Bubble ตาม pseudocode อาจารย์เป๊ะๆ, วิธี trace ลงตารางข้อสอบ, นับจำนวน swap, Best/Worst ของแต่ละตัว
14 slidesตารางแบบข้อสอบ
🔗→
ติวบทที่ 4 · ออกแน่
Linked List — เขียนโค้ดให้เป็น
Singly insert/delete ทีละกรณี (หัว/กลาง/ท้าย), Doubly, Circular, ตารางเทียบ Array vs LL ที่ชอบออก + applications
14 slidesโค้ด C ครบทุกเคส
#️⃣→
ติวบทที่ 5 · ออกแน่
Hashing — เติมตารางให้ถูก
h(k)=k mod m, Separate Chaining, Linear/Quadratic/Double probing — ทำโจทย์ 15,22,95,56,63,13,27 จากใบ practice จริงทีละช่อง
14 slidesเฉลย practice ครบ
✅→
