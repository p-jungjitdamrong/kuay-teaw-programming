Cheat Sheet · ห้ามทำ

10 ข้อผิดพลาดเสียคะแนนฟรี (ข้อ 1–5)

① ตอบ Big-O โดยไม่แสดง T(n)
   โจทย์สั่ง "ระบุเวลาแต่ละบรรทัด" → เขียนกำกับทุกบรรทัด รวม แล้วค่อยสรุป O

② เห็นลูปซ้อนตอบ O(n²) ทันที โดยไม่อ่านข้างใน
   มี break → ลูปในอาจเหลือ O(1) (function_A!)
   ลูปในเป็น j=j*2 → O(n log n) ไม่ใช่ O(n²)

③ Best/Worst ตอบแค่ O ไม่บอกรูปแบบข้อมูล
   ต้องตอบคู่: "O(n) เมื่อข้อมูลเรียงลำดับอยู่แล้ว" — ครึ่งคะแนนอยู่ตรงนี้

④ Selection Sort สลับกลางรอบ (เอา Bubble มาปน)
   Selection หา min ให้จบรอบก่อน แล้วสลับ "ครั้งเดียว" ท้ายรอบ

⑤ trace sorting ผิดทิศ
   อ่านโจทย์ให้ชัด: น้อย→มาก หรือ มาก→น้อย · ลอกเลขทุกตัวลงแถวใหม่ อย่าเขียนลัด
Cheat Sheet · ห้ามทำ

10 ข้อผิดพลาดเสียคะแนนฟรี (ข้อ 6–10)

⑥ insertFront สลับลำดับ 2 บรรทัด
   n->next = head ก่อนเสมอ แล้วค่อย head = n — "ต่อของใหม่ก่อน ค่อยปล่อยของเก่า"

⑦ ลบโหนดโดยเดินไปถึงตัวที่จะลบ
   ต้องหยุดที่ "ตัวก่อนหน้า": while (p->next->data != x) — Singly เดินย้อนไม่ได้

⑧ ลืม p = p->next ท้าย while
   infinite loop = ข้อนั้นศูนย์ — เช็คทุก while ก่อนส่งกระดาษ

⑨ mod ผิด / ลืม mod วนกลับ
   95%7 = 4 (ไม่ใช่ 5!) · probe เกินท้ายตาราง (9+1)%10 = 0 วนกลับหัว

⑩ Double hashing ใช้ h₂ ผิดตัว
   h₂ คำนวณจาก k ของ "ตัวที่กำลังแทรก" — แต่ละ key ก้าวไม่เท่ากัน
   และ h₂ ต้องไม่เป็น 0 (สูตร 5−(k%5) ให้ 1..5 เสมอ)
คืนก่อนสอบ: อ่าน 10 ข้อนี้อีกรอบเดียวพอ — มันคือสาเหตุการเสียคะแนนของคนสอบตกรุ่นก่อนๆ ทั้งนั้น
Cheat Sheet · โค้ดท่องจำ

โค้ด Linked List 4 ท่า — เขียนได้จากความจำ

/* ① เดินลิสต์ (โครงศักดิ์สิทธิ์) */
Node *p = head;
while (p != NULL) {
    /* ใช้ p->data */
    p = p->next;      /* ห้ามลืม! */
}

/* ② แทรกหน้า */
n->next = *head;      /* ก่อน */
*head = n;            /* หลัง */
/* ③ แทรกหลัง p */
n->next = p->next;    /* ก่อน */
p->next = n;          /* หลัง */

/* ④ ลบตัวถัดจาก p (ตัวก่อนหน้า!) */
Node *tmp = p->next;  /* จำ */
p->next = tmp->next;  /* ข้าม */
free(tmp);            /* ค่อยทิ้ง */
ทดสอบตัวเอง: ปิดหน้านี้ เขียน 4 ท่าลงกระดาษเปล่า — เขียนถูกครบใน 5 นาที = บท 4 พร้อมสอบ · สังเกตว่าทุกท่ามี pattern "จำ/ต่อของใหม่ก่อน แก้ลิงก์ทีหลัง"
Cheat Sheet · Hashing

Hashing Quick Reference

ขั้นตอนข้อเติมตาราง
① เขียน h(k)=k%m ของทุก key ยกแผง
② วาดตารางเปล่า 0..m−1
③ ใส่ทีละตัวตามลำดับโจทย์
④ ชน → เขียนสมการ probe ทุกขั้น:
   Linear:    +1, +2, +3, ...
   Quadratic: +1, +4, +9, +16, ...
   Double:    +h₂, +2h₂, +3h₂, ...
   (บวกจาก h(k) เดิม แล้ว mod m เสมอ)
⑤ Quadratic หาไม่เจอ → ตอบ
   "แทรกไม่ได้ probe วนซ้ำ" ได้!
การค้นหา — กติกาหยุด
เริ่มที่ h(k) → probe แบบเดียวกับตอนแทรก

หยุดเมื่อ:
① เจอ k          → "เจอ"
② เจอช่องว่าง     → "ไม่เจอ"
③ ครบทั้งตาราง   → "ไม่เจอ"

จำนวนครั้ง = ทุกช่องที่เปิดดู
(รวมช่องที่ทำให้หยุด)

ศัพท์: Open = Chaining (ต่อ LL)
      Closed = Probing (ในตาราง)
