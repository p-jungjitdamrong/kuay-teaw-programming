ติวบทที่ 6 · แนวคิด

Queue = แถวรอคิว — FIFO เข้าก่อนออกก่อน

กฎเหล็ก 2 ข้อ
เพิ่มข้อมูล (Enqueue) → ท้ายคิว (Rear) เสมอ
ลบข้อมูล (Dequeue)  → หัวคิว (Front) เสมอ

Front ──▶ [A][B][C][D] ◀── Rear
ออกทางนี้ ↑          ↑ เข้าทางนี้

First In First Out (FIFO)
"มาก่อน ได้ก่อน" เหมือนต่อแถวซื้อข้าว

/* เทียบ Stack (ถ้าเรียนแล้ว):
   Stack = LIFO เข้า-ออกทางเดียว
   Queue = FIFO เข้าท้าย ออกหัว */
5 Operations (ปรนัยถามชื่อ)
① Enqueue  เพิ่มที่ท้ายคิว
   → ต้องเช็ค isFull ก่อน
② Dequeue  ลบที่หัวคิว
   → ต้องเช็ค isEmpty ก่อน
③ Peek     ดูค่าหัวคิว "ไม่เอาออก"
④ isEmpty  คิวว่างไหม
⑤ isFull   คิวเต็มไหม
   (LL ไม่ต้องมี — ไม่มีวันเต็ม!)

/* คู่ที่ต้องจำ:
   Enqueue↔isFull · Dequeue↔isEmpty */
ปรนัยเก็งได้: "Peek ต่างจาก Dequeue อย่างไร" → Peek แค่ดูค่าหัวคิว ไม่นำออก · "Queue ที่สร้างด้วย LL ไม่ต้องมี operation ใด" → isFull เพราะ LL ขยายได้เรื่อยๆ
ติวบทที่ 6 · Linked List

Queue ด้วย Singly LL — pointer 2 ตัว front/rear

Enqueue (ตาม pseudocode อาจารย์)
/* เพิ่มท้ายลิสต์ — ใช้ rear ช่วย
   ไม่ต้องเดินหาท้าย → O(1)! */

1. สร้าง newnode
   newnode->data = value
   newnode->next = NULL

2. if (Front == NULL)      /* คิวว่าง */
       Front = Rear = newnode
   else {
       Rear->next = newnode  /* ต่อท้าย */
       Rear = newnode        /* ย้าย rear */
   }
Dequeue + Peek
/* Dequeue = ลบหัวลิสต์ (บท 4!) */
if (Front == NULL)
    printf("Underflow");
else {
    ptr = Front;           /* จำ */
    Front = Front->next;   /* ข้าม */
    free(ptr);             /* ทิ้ง */
}

/* Peek — เติมช่องว่างในสไลด์อาจารย์: */
void peek() {
    if (Front == NULL)
        printf("Underflow");
    else
        printf("%d", Front->data);
}
คำถามในสไลด์อาจารย์ที่ต้องตอบได้: "ทำไม Enqueue ที่ท้าย + Dequeue ที่หัว?" → เพราะลบหัวลิสต์ O(1) แต่ลบท้าย Singly ต้องเดินหาตัวก่อนหน้า O(n) — จึงเอา "ลบ" ไว้หัว "เพิ่ม" ไว้ท้าย (มี rear ชี้อยู่แล้ว O(1) ทั้งคู่)
ติวบทที่ 6 · Linear Array

Queue ด้วย Array ธรรมดา + ตัวแปร 4 ตัว

ตัวแปร + Enqueue
maxsize  ขนาดอาเรย์
size     จำนวนสมาชิกตอนนี้
Front    ดัชนีหัวคิว   (เริ่ม −1)
Rear     ดัชนีท้ายคิว  (เริ่ม −1)

/* Enqueue: */
if (Rear == maxsize-1)     /* เต็ม? */
    printf("Full");
else {
    if (Front == -1 && Rear == -1)
        Front = Rear = 0;   /* ตัวแรก */
    else
        Rear = Rear + 1;
    Q[Rear] = data;
}
Dequeue แบบ "เลื่อน Front"
/* วิธีที่อาจารย์ใช้: ไม่ย้ายข้อมูล
   แค่เลื่อน Front ไปขวา */
if (Front == -1 || Front > Rear)
    printf("Underflow");
else {
    data = Q[Front];
    Front = Front + 1;
}

/* อีกแบบในสไลด์: ย้ายข้อมูลทั้งแถว
   หลังลบตัวแรก → O(n) แย่กว่า
   ← ปรนัยถามเทียบสองแบบนี้ได้ */
เงื่อนไขต้องแม่น: เต็ม → Rear == maxsize−1 · ว่าง → Front == −1 หรือ Front > Rear — เงื่อนไขพวกนี้คือช่องว่างที่ Lab ให้เติม จำเป๊ะๆ

เพิ่มค่า 100:
Rear == maxsize−1 → "คิวเต็ม"!?

แต่ช่อง 0–5 ว่างตั้ง 6 ช่อง!
← "เต็มปลอม" เพราะ Rear ชนขอบขวา
   ทั้งที่ข้างหน้าว่าง
ทางแก้: Circular Array
/* ให้ index "วนกลับ" ด้วย mod:
   Rear = (Rear + 1) % maxsize
   Front = (Front + 1) % maxsize

   ชนขอบขวา → วนกลับช่อง 0
   (mod เดียวกับ hashing บท 5!)

   เช็คเต็มด้วย size:
   size == maxsize     → เต็มจริง
   เช็คว่างด้วย
   size == 0           → ว่างจริง */
ข้อ 2 ของใบ practice ถามตรงนี้เป๊ะๆ: "enqueue(35) สำเร็จหรือไม่ เพราะเหตุใด พร้อมวิธีแก้" → ไม่สำเร็จ เพราะ Rear == maxsize−1 (เต็มปลอม — ยังมีช่องหน้าว่าง) · วิธีแก้: ใช้ Circular Array ให้ Rear วนกลับด้วย mod

ติวบทที่ 6 · เฉลยใบ practice ข้อ 5

เฉลยจริง: สายการบิน — Multiple Queue 3 แถว

กติกา + ลำดับ operations
คิว 3 แถวตามชั้นผู้โดยสาร:
Q1 ชั้นหนึ่ง · Q2 ชั้นธุรกิจ · Q3 ประหยัด
dequeue = เอาจาก Q1 ก่อน → Q2 → Q3
(ชั้นเดียวกัน มาก่อนได้ก่อน = FIFO)

1. e(1,1234)   6. e(3,3456)
2. e(1,2222)   7. e(3,1489)
3. e(3,3333)   8. dequeue()
4. dequeue()   9. dequeue()
5. e(2,9876)  10. e(2,4579)
ไล่ทีละขั้น
หลังข้อ 3: Q1=[1234,2222] Q3=[3333]
④ dequeue → Q1 มีของ → 1234 ออก
หลังข้อ 7: Q1=[2222] Q2=[9876]
          Q3=[3333,3456,1489]
⑧ dequeue → Q1 ก่อน → 2222 ออก
⑨ dequeue → Q1 ว่าง → Q2 → 9876 ออก
⑩ e(2,4579) → Q2=[4579]

สถานะจบ: Q1=[] Q2=[4579]
         Q3=[3333,3456,1489]
ข้อ 5.2 ตอบ: ผู้โดยสารที่เช็คอินเสร็จ (ถูก dequeue) = 1234, 2222, 9876 ตามลำดับ · แนวคิดนี้คือ Priority Queue อย่างง่าย — ทำด้วยหลายคิวเรียงตามความสำคัญ ปรนัยชอบถามว่า "ระบบนี้ใช้โครงสร้างใด"

ใช้คิว 10 ใบ (bucket 0-9)

รอบ 1: แจกตามหลักหน่วย
  แต่ละตัว → enqueue เข้าคิว
  ตามเลขหลักหน่วยของมัน
  แล้ว dequeue กลับตามลำดับคิว 0→9

รอบ 2: แจกตามหลักสิบ ...
รอบ 3: หลักร้อย ... ทำจนครบหลัก
ของค่ามากสุด → เรียงเสร็จ!

/* ตัวอย่างสั้น: 25 13 8 31
   หน่วย: [1]:31 [3]:13 [5]:25 [8]:8
   → 31 13 25 8
   สิบ:  [0]:8 [1]:13 [2]:25 [3]:31
   → 8 13 25 31 ✓ */
ทำไมต้องใช้ Queue?
/* จุดที่ข้อสอบถาม:
   "เพราะเหตุใด Radix sort
    ต้องใช้ Queue ไม่ใช่ Stack?"

   → เพราะต้องรักษา "ลำดับเดิม"
     ของตัวที่ลงหลักเดียวกัน
     (FIFO = เข้าก่อนออกก่อน)
     ถ้าใช้ Stack ลำดับจะกลับด้าน
     ผลรอบก่อนหน้าพัง!

   คำศัพท์: คุณสมบัตินี้เรียกว่า
   sort แบบ "Stable" */

/* จำนวนรอบ = จำนวนหลัก (d)
   เวลารวม O(d × n) */
ครบวงจรพอดี: Radix sort ใช้ Queue (บทนี้) + แนวคิด mod หลัก (บท 5) + เทียบกับ sorting O(n²) (บท 3) — ข้อสอบชอบออกเป็นข้อเชื่อมบท ตอบให้ได้ว่า "Queue รักษาลำดับ = stable"

CQ[5] วงกลม: Front=3, Rear=4 แล้ว enqueue(9) — Rear ใหม่คือ?

A Rear = 5
B Rear = 0
C เพิ่มไม่ได้ คิวเต็ม
D Front = 4
Rear = (Rear + 1) % maxsize = (4 + 1) % 5 = 0   → Q[0] = 9
