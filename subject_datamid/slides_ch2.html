ติวบทที่ 2 · หัวใจของบท

นับ T(n) ทีละบรรทัด — วิธีที่อาจารย์ให้คะแนน

ข้อสอบสั่งว่า "ระบุเวลาที่ใช้แต่ละบรรทัด" — ต้องเขียนข้างบรรทัด ไม่ใช่ตอบ Big-O ลอยๆ

กฎการนับ (จำ 4 ข้อ)
① คำสั่งเดี่ยว (กำหนดค่า, if, printf)
   → นับ 1

② for(i=0; i<n; i++)
   → หัวลูปทำงาน n+1 ครั้ง
     (เช็คเงื่อนไขรอบสุดท้ายที่หลุด)
   → body ทำงาน n ครั้ง

③ ลูปซ้อน → คูณกัน

④ รวมทุกบรรทัด = T(n)
   แล้วค่อยลดรูปเป็น Big-O
ตัวอย่างมาตรฐาน
int sum = 0;              /* 1        */
for (i=1; i<=n; i++) {    /* n+1      */
    sum = sum + i;         /* n        */
}
printf("%d", sum);        /* 1        */

T(n) = 1 + (n+1) + n + 1
     = 2n + 3

Big-O: ตัด constant, ตัด term เล็ก
     → O(n)
เขียนตอบแบบได้คะแนนเต็ม: ① เขียนจำนวนครั้งข้างทุกบรรทัด ② รวมเป็น T(n) = ... ③ สรุป "ดังนั้น Big-O คือ O(...)" — ข้ามขั้นตอนไหนโดนหักขั้นตอนนั้น
ติวบทที่ 2 · กฎลดรูป

T(n) → Big-O ใน 2 ขั้นตอน

ขั้น 1 ตัดตัวน้อย · ขั้น 2 ตัด constant
T(n) = 6n² + 10n + 5
  ขั้น 1: เก็บ term โตสุด → 6n²
  ขั้น 2: ตัด 6 → n²
  ∴ O(n²)

T(n) = 2n + 3        → O(n)
T(n) = 5             → O(1)
T(n) = n²/2 + n/2    → O(n²)
T(n) = 3n + 2log n   → O(n)
T(n) = n log n + n   → O(n log n)
ลำดับการโต (เรียงให้ได้)
O(1) < O(log n) < O(n)
     < O(n log n) < O(n²)
     < O(n³) < O(2ⁿ)

ชื่อเรียก (ข้อสอบให้ "ระบุชื่อฟังก์ชัน"):
O(1)       constant
O(log n)   logarithmic
O(n)       linear
O(n log n) linearithmic
O(n²)      quadratic
O(2ⁿ)      exponential
ระวังในใบ practice: โจทย์ function_A/B/C สั่งให้ "ระบุชื่อฟังก์ชันของอัตราการเติบโต" ด้วย — ตอบ O(n) เฉยๆ ไม่พอ ต้องเขียน "linear" กำกับ
ติวบทที่ 2 · ดูลูปปุ๊บตอบปั๊บ

4 Pattern ลูปที่ต้องมองออกทันที

/* ① เพิ่มทีละคงที่ → O(n)   (i++ หรือ i+=5 ก็ O(n) — n/5 ตัด constant) */
for (i = 1; i <= n; i++)     ...
for (i = 1; i <= n; i += 5)  ...

/* ② คูณ/หารทีละเท่า → O(log n)   (จำนวนรอบ = log₂ n) */
for (j = 1; j <= n; j = 2 * j)  ...
for (j = n; j >= 1; j = j / 2)  ...

/* ③ ลูปซ้อน → คูณกัน */
for (i = 0; i < n; i++)          /* n     */
    for (j = 0; j < n; j++)      /* × n   */
        ...                       /* = O(n²) */

for (i = n/2; i <= n; i++)       /* n/2 → O(n) */
    for (j = 1; j <= n; j = 2*j) /* × log n    */
        ...                       /* = O(n log n) */

/* ④ มี break ในลูปใน → ลูปในทำแค่รอบเดียว! */
for (i = 1; i <= n; i++)
    for (j = 1; j <= n; j += 5) {
        printf("*");
        break;                    /* ← ออกทันที! ลูปใน = O(1) */
    }                             /* รวม = O(n) ไม่ใช่ O(n²)!! */
Pattern ④ คือ function_A ในใบ practice เป๊ะๆ — อาจารย์จงใจใส่ break หลอก คนไม่อ่านโค้ดจะตอบ O(n²) แล้วผิด · อ่านทุกบรรทัดก่อนตอบเสมอ
ติวบทที่ 2 · เฉลยใบ practice ข้อ 1

เฉลยจริง: ค้นหา item ใน matrix n×n

โจทย์ practice_ch2 ข้อ 1 — โปรแกรมวนหา item ใน mat[100][100] แล้วตอบ 1.1–1.4

1.1-1.2: ปัญหาอะไร + T(n)
/* 1.1 โปรแกรมแก้ปัญหาอะไร?
   → ค้นหาค่า item ใน matrix ขนาด n×n
     (Searching) */

/* 1.2 นับตั้งแต่บรรทัด 9: */
for(row=0;row<n;row++)      /* n+1 */
 for(col=0;col<n;col++)     /* n(n+1) */
  if(mat[row][col]==item)   /* n·n */
    found=1;                 /* ≤ n·n */
if(found) ... else ...       /* 1+1 */

T(n) = (n+1) + n(n+1) + n² + n² + 2
     ≈ 3n² + 2n + 3
1.3-1.4: Big-O + ปรับปรุง
/* 1.3 Big-O = O(n²) — แต่โจทย์ให้บอก
   "รูปแบบข้อมูล" แต่ละกรณีด้วย!

   ⚠️ โค้ดนี้ไม่มี break
   → วนครบทุกช่องเสมอ
   Best  = Worst = O(n²)
   (เจอเร็วก็ไม่หยุด!) */

/* 1.4 เขียนใหม่ให้ดีกว่า: เพิ่ม break */
if (mat[row][col]==item) {
    found=1; break;  /* + ออกลูปนอกด้วย */
}
/* Best: เจอช่องแรก O(1)
   Worst: ไม่เจอเลย O(n²) */
จุดที่เก็งได้เลย: โค้ดค้นหา "ไม่มี break" → Best = Worst · เติม break แล้ว Best O(1) — ข้อสอบชอบให้เทียบสองเวอร์ชันนี้ และถามว่า "รูปแบบข้อมูล Best case คืออะไร" (ตอบ: item อยู่ช่องแรก)

เฉลยจริง: sum 1..n และเวอร์ชัน O(1)

2.1: T(n) ของ pseudocode
Set i=1, sum=0        /* 2      */
While i<=n            /* n+1    */
    sum=sum+i         /* n      */
    i=i+1             /* n      */
End while

T(n) = 2 + (n+1) + n + n
     = 3n + 3
∴ O(n) — linear
2.2: เขียนใหม่ให้เป็น O(1)
/* ใช้สูตร Gauss:
   1+2+...+n = n(n+1)/2 */

Begin
  sum = n * (n + 1) / 2   /* 1 คำสั่ง */
End

T(n) = 1 → O(1) — constant

/* สูตรนี้ต้องจำ! ใช้อีกในบท 3:
   จำนวนเปรียบเทียบของ
   selection sort = n(n-1)/2 */
สูตรบังคับจำ: 1+2+...+n = n(n+1)/2 และ 1+2+...+(n−1) = n(n−1)/2 — โผล่ทั้งบท 2 (ลดรูป T(n)) และบท 3 (นับการเปรียบเทียบ sorting) สองบทใช้สูตรเดียวกัน

โจทย์
void function_A(int n) {
    int i, j;
    if (n == 1) return;
    for (i = 1; i <= n; i++) {

   break ทันที → ทำงานแค่ 1 รอบเสมอ
   = O(1)

   ลูปนอก: วน n รอบ = O(n)

   รวม: n × 1 = O(n) — linear ✓ */

เฉลยจริง: function_B และ function_C

function_B → O(n log n)
for (i = n/2; i <= n; i++)      /* n/2 รอบ
                                   → O(n) */
    for (j = 1; j <= n; j = 2*j) /* คูณ 2
                                   → log₂n */
        count++;

รวม: (n/2) × log n
   → O(n log n) — linearithmic ✓
function_C → O(n² log n)
for (i = n/2; i <= n; i++)       /* n/2 → O(n) */
    for (j = 1; j+n/2 <= n; j++)  /* j วน 1..n/2
                                    → O(n) */
        for (k = 1; k <= n; k = k*2) /* → log₂n */
            count++;

รวม: (n/2) × (n/2) × log n
   → O(n² log n) ✓

/* เทคนิค: วิเคราะห์ทีละชั้น
   เขียนกำกับข้างลูป แล้วคูณรวม */
วิธีทำสามข้อนี้ในห้องสอบ: เขียนข้างลูปทุกตัวว่า "กี่รอบ" (n/2, log n, ...) → คูณจากนอกเข้าใน → ตัด constant — อย่าลัดขั้นตอนแม้มั่นใจ เพราะคะแนนอยู่ที่วิธีทำ
ติวบทที่ 2 · Best/Worst

Best / Worst Case — ต้องตอบ "รูปแบบข้อมูล" ด้วย

หลักการ
Best Case  = ข้อมูลแบบไหนทำให้
             ทำงานน้อยสุด + O เท่าไหร่
Worst Case = ข้อมูลแบบไหนทำให้
             ทำงานมากสุด + O เท่าไหร่

/* ตัวอย่าง: Linear Search (มี break)
   Best:  item อยู่ตัวแรก → O(1)
   Worst: item อยู่ตัวสุดท้าย
          หรือไม่มีในข้อมูล → O(n) */
ตารางที่ใช้ตอบบท 3 ล่วงหน้า
Selection Sort:
  Best = Worst = O(n²)
  (ไม่มีทางหยุดก่อน — วนครบเสมอ)

Insertion Sort:
  Best: เรียงอยู่แล้ว → O(n)
  Worst: เรียงกลับด้าน → O(n²)

Bubble Sort (มี flag):
  Best: เรียงอยู่แล้ว → O(n)
  Worst: เรียงกลับด้าน → O(n²)
สูตรตอบเต็ม: "Best case คือ O(...) เมื่อข้อมูล [บอกรูปแบบ]" — เช่น "O(n) เมื่อข้อมูลเรียงลำดับอยู่แล้ว" · ลืมบอกรูปแบบข้อมูล = โดนหักครึ่ง ทุกปีมีคนพลาดตรงนี้
