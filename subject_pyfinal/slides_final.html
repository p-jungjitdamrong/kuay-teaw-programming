Cheat Sheet · ห้ามพลาด

10 จุดหลอกเสียคะแนนฟรี (1–5)

① index เริ่มที่ 0
   a = [1,2,3,4,5] → index 0–4 · a[5] = IndexError
   ตัวสุดท้าย = a[-1] หรือ a[len(a)-1]

② slice ไม่รวมตัวสุดท้าย
   a[1:4] → index 1,2,3 (ไม่รวม 4) · เหมือนกฎของ range()

③ sort() คืน None
   b = a.sort()  → b เป็น None!  (sort แก้ a เอง)
   อยากได้ list ใหม่ → b = sorted(a)

④ String แก้ตัวอักษรไม่ได้
   s[0] = "J"  ❌ TypeError  (immutable)
   ต้องสร้างใหม่: s = "J" + s[1:]
   และ s.upper() ต้องรับค่ากลับ: s = s.upper()

⑤ dict ไม่มี key → KeyError
   d['z']       ❌ KeyError
   d.get('z')   ✓ None    ·    d.get('z', 0) ✓ 0
Cheat Sheet · ห้ามพลาด

10 จุดหลอกเสียคะแนนฟรี (6–10)

⑥ ฟังก์ชันไม่มี return → คืน None
   def f(x): print(x*2)
   y = f(5)   → พิมพ์ 10 แต่ y = None

⑦ แก้ global ในฟังก์ชันต้องประกาศ global
   count = 0
   def add(): count = count + 1   ❌ UnboundLocalError
   def add(): global count; count = count + 1   ✓

⑧ ส่ง list เข้าฟังก์ชัน → แก้แล้วกระทบตัวจริง
   ตัวเลข/string → แก้ไม่กระทบ
   list/dict + append()/แก้สมาชิก → กระทบข้างนอกด้วย

⑨ โหมด "w" ลบข้อมูลเดิมทันทีที่ open
   open("data.txt", "w")  ← ไฟล์ถูกล้างตั้งแต่บรรทัดนี้
   อยากเขียนเพิ่ม → ใช้ "a"  ·  write() ไม่เติม \n ให้

⑩ Tkinter: ลืม mainloop() / ใส่วงเล็บใน command
   ไม่มี win.mainloop() → หน้าต่างแวบเดียวหาย
   command=fn()  ❌ ทำงานทันที   ·   command=fn  ✓
คืนก่อนสอบอ่านสองหน้านี้รอบเดียวพอ — สิบข้อนี้คือจุดที่เสียคะแนนโดยไม่จำเป็น ทั้งที่เข้าใจเนื้อหาแล้ว

scores = []
for i in range(n):
    scores.append(int(input()))
print(sum(scores), max(scores),
      sum(scores)/len(scores))

# ② นับความถี่ด้วย dict
count = {}
for ch in text:
    count[ch] = count.get(ch, 0) + 1
for k, v in count.items():
    print(k, v)

# ③ ฟังก์ชัน + return หลายค่า
def stat(a):
    return sum(a)/len(a), max(a), min(a)
avg, mx, mn = stat([1,2,3])
# ④ อ่าน/เขียนไฟล์
with open("out.txt", "w") as f:
    f.write(f"{name},{score}\n")

with open("out.txt", "r") as f:
    for line in f:
        a, b = line.strip().split(",")
        print(a, int(b))

# ⑤ GUI พื้นฐาน
import tkinter as tk
win = tk.Tk()
def click():
    lbl.config(text=ent.get())
ent = tk.Entry(win); ent.pack()
tk.Button(win, text="OK",
          command=click).pack()
lbl = tk.Label(win, text=""); lbl.pack()
win.mainloop()

ข้อสุดท้าย — ผสมทุกบท

d = {}
for ch in "apple":
    d[ch] = d.get(ch, 0) + 1
print(len(d), d['p'])
A 5 2
B 4 2
C 4 1
D KeyError
"apple" → a p p l e
d = {'a':1, 'p':2, 'l':1, 'e':1}

len(d) = 4  (key ไม่ซ้ำ 4 ตัว — dict key ห้ามซ้ำ)
d['p'] = 2  (p ปรากฏ 2 ครั้ง)

get(ch, 0) = ถ้ายังไม่มี key ให้ใช้ 0 แล้ว +1 → กัน KeyError
