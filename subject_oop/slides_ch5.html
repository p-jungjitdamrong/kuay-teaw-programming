Lab 5 · แนวคิด

คลาสสัมพันธ์กัน 3 แบบ (has-a)

① Association — รู้จักกัน ใช้งานกัน
// Cashier "ใช้" Cart ตอนคิดเงิน
// แต่ไม่ได้เป็นเจ้าของ
public void printReceipt(InventoryCart ic) {
    // รับมาใช้ชั่วคราวผ่าน parameter
}
② Aggregation — มีเป็นของ แต่แยกกันอยู่ได้
// Cart "มี" Products
// แต่ Product สร้างข้างนอก ใส่เข้ามา
// Cart หายไป Product ยังอยู่
ic.add(p1);   // p1 สร้างจากข้างนอก
③ Composition — เป็นส่วนหนึ่งของกันจริงๆ
// BankAccount สร้าง Date เองข้างใน
// (Lab 4!) — บัญชีหาย วันเปิดก็หาย
public BankAccount(String name) {
    this.openDate = new Date(...);
    // ← new ข้างใน = composition
}
สังเกตง่ายๆ
รับผ่าน parameter ใช้แล้วคืน → Association
รับเข้ามาเก็บใน field       → Aggregation
new เองข้างใน constructor  → Composition
ทั้งสามแบบคือ "has-a / uses-a" — ต่างจาก "is-a" (inheritance) ที่จะเรียนใน Lab 6

Lab 5 · เฉลย (1/3)

class Product

public class Product {
    private String code;
    private String name;
    private double price;

    public Product(String code, String name, double price) {
        this.code = code;
        this.name = name;
        this.price = price;
    }

    public String getCode()  { return code; }
    public String getName()  { return name; }
    public double getPrice() { return price; }
}
ใช้ความรู้ Lab 4 เต็มๆ — private + constructor + getter · ไม่มี setter เพราะสินค้าไม่ควรเปลี่ยนรหัส/ราคากลางทาง (read-only)
Lab 5 · เฉลย (2/3)

class InventoryCart — รถเข็นเก็บ Product

public class InventoryCart {
    private Product[] products;              // Aggregation: มี Product หลายตัว
    private int count;                       // จำนวนของในรถตอนนี้

    public InventoryCart(int capacity) {    // constructor กำหนดความจุ (โจทย์: 10)
        products = new Product[capacity];
        count = 0;
    }

    public void add(Product p) {             // addProduct — ใส่ของลงรถ
        if (count < products.length) {
            products[count] = p;
            count++;
        }
    }

    public Product getProduct() {            // หยิบออกทีละชิ้น (จากท้าย)
        if (count == 0) return null;         // รถว่าง → null
        count--;
        Product p = products[count];
        products[count] = null;              // เอาออกจากรถจริงๆ
        return p;
    }

    public Product[] getAllProducts() {      // หยิบออกทั้งหมด
        Product[] all = new Product[count];
        for (int i = 0; i < all.length; i++)
            all[i] = getProduct();           // reuse getProduct ทีละชิ้น!
        return all;
    }

    public int getCount() { return count; }
}
สังเกต: getAllProducts วน getProduct ซ้ำ — reuse เหมือน transfer ใน Lab 4 · โครงสร้างนี้คือ Stack จากวิชา Data Structures นั่นเอง!
Lab 5 · เฉลย (3/3)

class Cashier — คิดเงิน + พิมพ์ใบเสร็จ

public class Cashier {
    private String name;

    public Cashier(String name) {
        this.name = name;
    }

    public void printReceipt(InventoryCart ic) {      // Association: รับ cart มาใช้
        System.out.println("Pumpkin Shop (" + name + ")");
        System.out.println();

        double total = 0;
        Product[] items = ic.getAllProducts();        // ดึงของออกจากรถทั้งหมด

        for (Product p : items) {
            System.out.printf("1 x %-7s(%s)  %8.0f%n",
                p.getName(), p.getCode(), p.getPrice());
            total += p.getPrice();                    // สะสมราคารวม
        }

        System.out.println("---------------");
        System.out.printf("       Total   %8.0f $%n", total);
    }
}
/* Pumpkin Shop (John Doe)

   1 x Milk   (XA1101)    150
   1 x Suger  (XA1102)    50
   1 x Coffee (XA1103)    250
   ---------------
                  Total      450 $   ✓ ตรงตามโจทย์ */
Lab 5 · ภาพรวม

ของไหลผ่านระบบยังไง

main │ new Product ×3 (สร้างสินค้า) │ ↓ │ ic.add(p1..p3) (ใส่รถเข็น — Aggregation) │ ↓ │ c.printReceipt(ic) (ส่งรถให้แคชเชียร์ — Association) │ ↓ │ Cashier → ic.getAllProducts() (ดึงของออกจากรถ) │ ↓ │ วนพิมพ์ + รวมราคา → ใบเสร็จ Total 450 $
// แต่ละคลาสมีหน้าที่เดียวชัดเจน:
// Product       = เก็บข้อมูลสินค้า
// InventoryCart = จัดการของเข้า-ออก
// Cashier       = คิดเงิน แสดงผล
// หลักนี้เรียก
// "Single Responsibility"
// — คลาสละหนึ่งหน้าที่
// แก้การพิมพ์ใบเสร็จ → แก้แค่ Cashier
// แก้วิธีเก็บของ → แก้แค่ Cart
