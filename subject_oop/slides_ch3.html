Class = พิมพ์เขียว · Object = บ้านจริง

Class — นิยามครั้งเดียว

Book b1 = new Book();

b1.name = "Harry Potter";

// b1, b2 เป็นคนละเล่ม

Lab 3 · ข้อ 2.1 เฉลย

ข้อ 2.1: กำหนดค่า + แสดงผล Book

public class Book {
    String name;
    double price;
    int year;
    String author;
}

class Program {
    public static void main(String[] args) {
        Book book1 = new Book();

        book1.name   = "Harry Potter and The Chamber of Secret";  // เติมช่องว่าง
        book1.author = "J.K. Rowling";
        book1.year   = 2542;

        System.out.println("Book: " + book1.name);
        System.out.println("Written by " + book1.author + " in " + book1.year);
    }
}
/* Book: Harry Potter and The Chamber of Secret
   Written by J.K. Rowling in 2542  ✓ ตรงตามโจทย์ */
ตอบคำถามท้ายข้อ: "ทำไมเรียก Book() ได้ทั้งที่ไม่ได้เขียน constructor" — Java แถม default constructor (ตัวว่างๆ) ให้อัตโนมัติ เมื่อเราไม่เขียน constructor เองเลย

ข้อ 2.2: เปลี่ยนเป็นรับค่าจากคีย์บอร์ด

โจทย์ให้เขียน "เฉพาะบรรทัดที่เปลี่ยน/เพิ่ม" — ใช้ความรู้ Scanner จาก Lab 2

// เพิ่ม import บนสุดของไฟล์
import java.util.Scanner;

// เพิ่มใน main — สร้าง Scanner
Scanner scanner = new Scanner(System.in);

// เปลี่ยนบรรทัดกำหนด name เป็นรับจากคีย์บอร์ด
System.out.print("Enter Book name: ");
book1.name = scanner.nextLine();            // ชื่อหนังสือมีช่องว่างได้ → nextLine

// เพิ่มรับราคา
System.out.print("Enter Book price:");
book1.price = scanner.nextDouble();

// เพิ่มบรรทัดแสดงราคา (ต่อจาก println เดิม)
System.out.println("Price is " + book1.price + " Bath");

/* Enter Book name: xxxxxxxxxxxxx
   Enter Book price:150

   Book: xxxxxxxxxxxxx
   Written by J.K. Rowling in 2542
   Price is 150 Bath  ✓ */
สังเกต: รับ name ก่อน price — ถ้ารับ nextDouble() ก่อนแล้วค่อย nextLine() จะเจอปัญหา \n ค้าง (Lab 2 เตือนแล้ว!)

ข้อ 2.3: ประกาศแต่ไม่ new — เกิดอะไรขึ้น?

โค้ดในโจทย์
Book book2;                    // ประกาศเฉยๆ
System.out.println(book2.name);

// ☑ เกิดข้อผิดพลาด

// เหตุผล: book2 ยังไม่ได้ new
// → ยังไม่มี object จริงใน memory
// → compiler ฟ้อง:
//   "variable book2 might not
//    have been initialized"
วิธีแก้
// ต้อง new ก่อนใช้เสมอ
Book book2 = new Book();
System.out.println(book2.name);
// พิมพ์ null (ยังไม่กำหนดค่า)
// แต่ไม่ error แล้ว
ข้อ 2.4: เทียบสองแบบ
Book book1 = new Book();
// ประกาศ + สร้าง object จริง
// book1 ชี้ไป object ใน heap ใช้ได้เลย

Book book2;
// ประกาศตัวแปรอ้างอิง (reference) เฉยๆ
// ยังไม่ชี้ไป object ใด → ใช้ไม่ได้
ตัวแปร object ใน Java คือ "รีโมท" — ประกาศรีโมทแล้วแต่ยังไม่มีทีวี (new) กดปุ่มอะไรก็ไม่เกิดอะไรขึ้น
Lab 3 · ข้อ 3

ข้อ 3: class Box — field + method + this

public class Box {
    public double width;
    public double height;
    public double depth;

    public double getVolume() {
        return width * height * depth;
    }

    public void setDimension(double width, double height, double depth) {
        this.width  = width;    // this.width = field ของ object
        this.height = height;   // width เฉยๆ = parameter
        this.depth  = depth;
    }
}
// ตอบ 3.1: สมาชิกของ Box
// field 3 ตัว: width, height, depth
// method 2 ตัว: getVolume(),
//               setDimension()
// ทำไมต้องมี this?
// parameter ชื่อซ้ำกับ field
// ถ้าเขียน width = width;
// คือ parameter = parameter ← ไร้ผล!
// this.width บอกชัดว่าเอาของ object
Lab 3 · ข้อ 3.2 เฉลย

ข้อ 3.2: TestBox ทีละขั้นตามตารางโจทย์

public class TestBox {
    public static void main(String[] args) {

        // ① สร้างวัตถุ Box 1 ตัว — ใช้ new เพราะ class คือพิมพ์เขียว ต้อง new จึงได้ object จริง
        Box b = new Box();

        // ② เรียก getVolume() แสดงผล — ได้ 0.0 เพราะ double ยังไม่กำหนด = 0.0 ทุกตัว
        System.out.println(b.getVolume());     // 0.0

        // ③ setDimension(3,4,5) แล้ว getVolume()
        b.setDimension(3, 4, 5);
        System.out.println(b.getVolume());     // 60.0
    }
}

// ④ เปลี่ยน setDimension เป็น constructor (แก้ในคลาส Box):
public Box(double width, double height, double depth) {
    this.width  = width;
    this.height = height;
    this.depth  = depth;
}

// ⑤ เกิดอะไรกับวัตถุก่อนหน้า?
//    Box b = new Box();  ← compile error!
//    เพราะเมื่อเราเขียน constructor เอง Java จะ "ไม่แถม" default constructor ให้อีก

// ⑥ สร้างวัตถุใหม่จาก constructor:
Box b2 = new Box(3, 4, 5);
System.out.println(b2.getVolume());        // 60.0
Lab 3 · ข้อ 3.3-3.4 เฉลย

ข้อ 3.3-3.4: resizeBox — pass by reference

3.3: เขียน resizeBox ใน TestBox
public static void resizeBox(Box b, int fold) {
    b.width  *= fold;
    b.height *= fold;
    b.depth  *= fold;
}

// 3.4: เรียกใช้ใน main
Box b2 = new Box(3, 4, 5);
System.out.println(b2.getVolume());
// 60.0

resizeBox(b2, 2);        // ×2 ทุกด้าน
System.out.println(b2.getVolume());
// 480.0  ← เปลี่ยนจริง!
ทำไมกล่องจริงเปลี่ยน?
// Java ส่ง object เป็น
// "ค่าของ reference"
// b ใน resizeBox ชี้ไป object
// เดียวกันกับ b2 ใน main!

//   main: b2 ──┐
//              ├──→ [Box 6×8×10]
// method: b ──┘

// แก้ผ่าน b = แก้ object จริง
// → ปริมาตรเปลี่ยนตาม ✓

// ตอบโจทย์ 3.4: "เปลี่ยนไหม?"
// → เปลี่ยน! 60 → 480
//   (2³ = 8 เท่า เพราะคูณ 3 มิติ)
จุดสอบ: ×2 ทุกด้าน ปริมาตรไม่ใช่ ×2 แต่เป็น ×8 (2×2×2) — อาจารย์ชอบถามตรงนี้

Constructor Overloading — มีได้หลายตัว

class เดียวมี constructor หลายแบบได้ ถ้า parameter ต่างกัน — Java เลือกตัวที่ตรงให้เอง

กติกา
public class Vector {
    // ตัวที่ 1: ไม่มี parameter
    // = "default constructor"
    public Vector() { ... }

    // ตัวที่ 2: มี 3 parameters
    public Vector(double p1,
                  double p2,
                  double p3) { ... }
}

new Vector()        // → เรียกตัวที่ 1
new Vector(3,4,5)   // → เรียกตัวที่ 2
กฎ constructor สรุป
// 1. ชื่อ = ชื่อ class เป๊ะๆ
// 2. ไม่มี return type (void ก็ไม่ใส่)
// 3. ถูกเรียกอัตโนมัติตอน new
// 4. ไม่เขียนเลย → Java แถมตัวว่างให้
// 5. เขียนเองแล้ว → Java ไม่แถม!
//    (บทเรียนจากข้อ 3 Box)
// 6. overload ได้ถ้า parameter ต่างกัน
Lab 3 · ข้อ 4 เฉลย

ข้อ 4: Vector 3 มิติ — เติมโปรแกรมสมบูรณ์

public class Vector {
    double x;                                   // เติม: field 3 แกน
    double y;
    double z;

    public Vector() {                           // default constructor
        x = 0;
        y = 0;
        z = 0;
    }
    public Vector(double p1, double p2, double p3) {
        x = p1;
        y = p2;
        z = p3;
    }
    public void printVector() {
        System.out.println("(" + x + "," + y + "," + z + ")");
    }
}

class Program {
    public static void main(String[] args) {
        Vector v1 = new Vector();          // default → (0,0,0)
        Vector v2 = new Vector(3, 4, 5);  // overload → (3,4,5)
        System.out.print("Vector v1:");
        v1.printVector();
        System.out.print("Vector v2:");
        v2.printVector();
    }
}
/* Vector v1:(0.0,0.0,0.0)
   Vector v2:(3.0,4.0,5.0)  ✓ */

สรุป Lab 3 — Class & Object
Class vs Object
Class = พิมพ์เขียว นิยามครั้งเดียว · Object = ของจริง new กี่ตัวก็ได้
new
ประกาศเฉยๆ ยังใช้ไม่ได้ — ต้อง new จึงมี object จริงใน memory
this
this.width = field ของ object · แยกจาก parameter ชื่อซ้ำ
Constructor
ชื่อ = ชื่อ class, ไม่มี return type · เขียนเองแล้ว default ตัวแถมหาย!
Overloading
constructor หลายตัวได้ถ้า parameter ต่างกัน — Vector() กับ Vector(3,4,5)
Reference
ส่ง object เข้า method = ส่งรีโมทตัวเดียวกัน — แก้ในนั้นคือแก้ตัวจริง
