ติวบทที่ 12 · นิยาม

G = (V, E) + ศัพท์ที่ออกปรนัย

A ─── B V = {A,B,C,D,E} │ ╲ E = {AB,AC,AD,CD,DE} │ ╲ C ── D ── E
Vertex (โหนด/จุด) เก็บข้อมูล
Edge เส้นเชื่อม e = (u,v)

Undirected: เส้นไม่มีหัวลูกศร
  (u,v) = (v,u) ไปกลับได้
Directed (Digraph): มีหัวลูกศร
  (u,v) ≠ (v,u) ทางเดียว!
Degree = จำนวนเส้นของโหนด
  กราฟมีทิศ แยกเป็น:
  In-degree  = ลูกศร "ชี้เข้า"
  Out-degree = ลูกศร "ชี้ออก"

Adjacent nodes = คู่โหนดที่มี
  เส้นเชื่อมถึงกันโดยตรง
Path = ลำดับโหนดที่เชื่อมต่อกัน
  จากต้นถึงปลาย

/* Tree vs Graph (โยงบท 8):
   tree = graph ที่ "ไม่มีวงจรปิด"
   และเชื่อมถึงกันหมด
   graph มี cycle ได้ มีหลายทางได้ */
สูตรเช็คเร็ว (undirected): ผลรวม degree ทุกโหนด = 2 × จำนวน edge — ใช้ตรวจคำตอบข้อนับ degree ได้ทันที
ติวบทที่ 12 · เฉลยใบ practice ข้อ 1-2

Adjacency Matrix → อ่านประเภท + วาดรูป

ตัวอย่างแนวใบ practice (A-E = 0-4)
A B C D E A [ 0 1 0 1 0 ] B [ 0 0 1 0 0 ] C [ 0 0 0 1 1 ] D [ 0 0 0 0 1 ] E [ 1 0 0 0 0 ] M[i][j] = 1 คือ "มีเส้นจาก i ไป j"
/* ข้อ 1: กราฟประเภทใด?
   เช็ค "สมมาตร" รอบแนวทแยง:
   M[0][1]=1 แต่ M[1][0]=0
   → ไม่สมมาตร
   ∴ กราฟมีทิศทาง (Directed)
   + เหตุผล: มีเส้น A→B
     แต่ไม่มี B→A */
ข้อ 2: วาดรูปจาก matrix
อ่านทีละแถว (แถว = ต้นทาง): A→B, A→D · B→C · C→D, C→E D→E · E→A A ──▶ B ▲ ╲ │ │ ╲ ▼ │ ▶ ─C │ D ◀╱ ╲ │ │ ▼ └─ E ◀──┘ (D→E, C→E, E→A)
/* วิธีวาดไม่พลาด:
   วางจุด 5 จุดก่อน แล้วไล่
   matrix ทีละช่องที่เป็น 1
   ลากลูกศร i → j ทีละเส้น
   นับเส้นรวม = จำนวนเลข 1 */
กติกาจำ: undirected → matrix สมมาตรเสมอ (ใส่ 1 ทั้ง [i][j] และ [j][i]) · directed → ไม่จำเป็นต้องสมมาตร — ข้อ "ประเภทใด" ตัดสินจากความสมมาตรนี่แหละ
ติวบทที่ 12 · เฉลยใบ practice ข้อ 3

Adjacency List + ตารางเทียบที่ชอบออก

แปลงจาก matrix เดิม
A ─▶ [B] ─▶ [D] ─▶ ╳ B ─▶ [C] ─▶ ╳ C ─▶ [D] ─▶ [E] ─▶ ╳ D ─▶ [E] ─▶ ╳ E ─▶ [A] ─▶ ╳ (array ของ head pointer + linked list — บท 4 กลับมาอีกแล้ว!)
Matrix vs List
Matrix:
+ เช็ค "มีเส้น i→j ไหม" O(1)
− กิน memory O(V²) เสมอ
  (กราฟโปร่งก็เปลือง)

List:
+ กิน memory ตามเส้นจริง O(V+E)
+ ไล่เพื่อนบ้านเร็ว
− เช็คเส้นเจาะจงต้องไล่ลิสต์ O(V)

/* กราฟเส้นน้อย (sparse) → List
   กราฟเส้นแน่น (dense) → Matrix */
แนวถาม: "กราฟ 1000 โหนด 1500 เส้น ควรแทนแบบใด" → List (sparse — matrix เปลือง 10⁶ ช่องเพื่อเก็บ 1 แค่ 1500 ตัว)
ติวบทที่ 12 · Traversal

BFS ใช้ Queue · DFS ใช้ Stack — สองบทเก่ากลับมาทำงาน

BFS — ท่องทีละชั้น (Queue/FIFO)
① เริ่มที่จุดตั้งต้น mark visited
   แล้ว enqueue
② dequeue 1 ตัว → เพื่อนบ้าน
   ที่ยังไม่ visited: mark + enqueue
③ ทำจน queue ว่าง

/* กระจายเป็นวงเหมือนหยดน้ำ
   → ใกล้ก่อน ไกลทีหลัง
   ใช้หา "เส้นทางสั้นสุด"
   (จำนวน edge น้อยสุด) ได้ */
DFS — มุดให้สุดทาง (Stack/LIFO)
เดินลึกไปทางเดียวจนตัน
→ ถอยกลับ (backtrack) มาแยกอื่น

ใช้ stack หรือ recursion
(recursion = stack ซ่อนรูป!)

/* จุดสอบ:
   BFS ↔ Queue (บท 6 midterm)
   DFS ↔ Stack (บท 7)
   ห้ามจำสลับ! ท่อง:
   Breadth=กว้าง=แผ่=คิว
   Depth=ลึก=มุด=สแตค */
ทั้งสองแบบต้องมี visited — กราฟมี cycle ได้ ไม่ mark = วนไม่รู้จบ (ต่างจาก tree ที่ไม่ต้อง) · ข้อสอบให้กราฟ + จุดเริ่ม แล้วสั่งเขียนลำดับ BFS/DFS — ตอนไล่เพื่อนบ้านให้เรียงตามตัวอักษร/หมายเลขน้อยก่อน (ตาม convention ที่โจทย์กำหนด)
ติวบทที่ 12 · เฉลยใบ practice ข้อ 4

เฉลยจริง: getDegree() — แถว = ออก, คอลัมน์ = เข้า

หลักคิด
ใน adjacency matrix G ของกราฟมีทิศ:

Out-degree ของโหนด k
= จำนวนเลข 1 ใน "แถว k"
  (เส้นที่ออกจาก k)

In-degree ของโหนด k
= จำนวนเลข 1 ใน "คอลัมน์ k"
  (เส้นที่ชี้เข้า k)

/* โจทย์กำหนด: ฟังก์ชันไม่คืนค่า
   รับ 4 พารามิเตอร์ โดย InDeg/
   OutDeg เป็น output parameter
   → ต้องรับเป็น pointer! (บท 1) */
โค้ดเฉลย
#define N 5

void getDegree(int G[N][N], int k,
               int *InDeg, int *OutDeg)
{
    int i;
    *InDeg = 0;
    *OutDeg = 0;

    for (i = 0; i < N; i++) {
        *OutDeg += G[k][i];  /* แถว k */
        *InDeg  += G[i][k];  /* คอลัมน์ k */
    }
}
/* เรียกใช้:
   int in, out;
   getDegree(G, 2, &in, &out); */
สองจุดให้คะแนนของข้อนี้: ① รู้ว่าแถว=out คอลัมน์=in ② output parameter ใช้ pointer (*InDeg, &in) — ความรู้บท 1 (pointer 3 ตัว) มาปิดจ๊อบบทสุดท้ายพอดี

เช็คตัวเอง!
จากกราฟ matrix ในบทนี้ (A→B, A→D, B→C, C→D, C→E, D→E, E→A)

เริ่ม BFS จาก A (ไล่เพื่อนบ้านตามตัวอักษร) ได้ลำดับอะไร?

ไล่: A เข้าคิว → dequeue A เจอ B, D → dequeue B เจอ C
→ dequeue D เจอ E → dequeue C (D,E visited แล้ว) → dequeue E
ลำดับ: A B D C E

แล้ว DFS จาก A ล่ะ? (มุดทาง B ก่อน)
A → B → C → D → E — เห็นไหมว่าคนละลำดับ คนละนิสัย
ติวบทที่ 12 · ลองข้อสอบ

Adjacency matrix ที่ "สมมาตร" บอกอะไร?

A กราฟมีวงจรปิด (cycle)
B กราฟไม่มีทิศทาง (undirected)
C กราฟเชื่อมถึงกันทุกโหนด
D กราฟมีน้ำหนักเท่ากันทุกเส้น
สมมาตร (M[i][j] == M[j][i]) ⇔ undirected — เส้น (u,v) คือเส้น (v,u)
ไม่สมมาตรแม้ช่องเดียว → directed ("มี A→B แต่ไม่มี B→A")
