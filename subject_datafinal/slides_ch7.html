คำนวณค่า Postfix ด้วย Stack

กติกา (ง่ายกว่าแปลงอีก)
อ่านซ้าย → ขวา:
• เจอตัวเลข → push
• เจอ operator →
  pop 2 ตัว (ตัวหลัง=ขวา ตัวแรก=ซ้าย!)
  คำนวณ แล้ว push ผลกลับ
จบ → ค่าใน stack ตัวเดียว = คำตอบ

/* ⚠️ ลำดับ operand:
   pop ได้ b ก่อน แล้วได้ a
   ต้องคำนวณ a - b ไม่ใช่ b - a!
   สำคัญมากกับ - และ / */
ตัวอย่าง: 7 3 * 8 + 9 /
7      push       [7]
3      push       [7,3]
*      3,7→21     [21]
8      push       [21,8]
+      8,21→29    [29]
9      push       [29,9]
/      9,29→29/9  [3.22]

= (7×3+8)/9 = 29/9 ≈ 3.22 ✓

← ใช้เช็คคำตอบข้อแปลงได้ด้วย!

โค้ด Stack Array — เติมช่องว่าง Lab ได้

#define maxsize 10
int S[maxsize];
int Top = -1;

void push(int data) {
    if (Top == maxsize - 1)          /* เต็ม? */
        printf("Stack is Full\n");
    else {
        Top++;                        /* ขยับก่อน */
        S[Top] = data;                /* แล้วใส่ */
    }
}

int pop() {
    if (Top == -1) {                 /* ว่าง? */
        printf("Stack is Empty\n");
        return -1;
    }
    int data = S[Top];                /* เอาค่าก่อน */
    Top--;                            /* แล้วขยับลง */
    return data;
}

int peek() {
    if (Top == -1) { printf("Empty\n"); return -1; }
    return S[Top];                    /* ไม่แตะ Top! */
}
ลำดับห้ามสลับ: push = Top++ ก่อนใส่ · pop = เอาค่าก่อนแล้ว Top-- · peek ไม่แตะ Top เลย — สลับเมื่อไหร่ off-by-one ทันที
