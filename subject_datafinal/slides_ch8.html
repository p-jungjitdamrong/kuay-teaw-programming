ศัพท์ต้นไม้ — ตอบปรนัยได้ทั้งชุด

ระดับ 0 a ← Root ╱ ╲ ระดับ 1 b c ← Branch node ╱ ╲ ╱ ╲ ระดับ 2 d e f g │ ระดับ 3 i ← Leaf (และ d,f,g)
Root      โหนดแรก ไม่มีแม่
Branch    โหนดกลาง มีทั้งแม่และลูก
Leaf      โหนดปลาย ไม่มีลูก
Parent/Child  ความสัมพันธ์แม่-ลูก
Level     ระดับ (root = 0)
Height    ความสูง = จำนวนระดับ
Degree    จำนวนลูกของโหนด

/* Tree = ไม่เชิงเส้น (Non-linear)
   แทนข้อมูลแบบลำดับชั้น
   (Hierarchical) เช่น โฟลเดอร์

   ถ้าเส้นเชื่อมทำให้เกิด "วงจรปิด"
   → ไม่ใช่ tree แล้ว เป็น graph!
   ← ประโยคในสไลด์ ออกปรนัยได้ */
Binary Tree = tree ที่ทุกโหนดมีลูกได้ ไม่เกิน 2 (ซ้าย/ขวา) — บทนี้ + BST + AVL + Heap ทั้งหมดคือ binary tree ที่เพิ่มกฎต่างกัน
ติวบทที่ 8 · หัวใจของบท

ท่อง 3 แบบ — ตำแหน่งของ "ราก" คือชื่อ

Pre-order:   ราก → ซ้าย → ขวา
In-order:    ซ้าย → ราก → ขวา
Post-order:  ซ้าย → ขวา → ราก

/* Pre = รากก่อน (ก่อน=pre)
   In  = รากอยู่กลาง (ใน=in)
   Post = รากทีหลัง (หลัง=post)
   ← ชื่อบอกตำแหน่งรากเอง! */

/* โค้ด recursive 3 บรรทัดสลับที่: */
void inorder(Node *r) {
    if (r == NULL) return;
    inorder(r->left);
    printf("%d ", r->data);  /* กลาง */
    inorder(r->right);
}
A ╱ ╲ B C ╱ ╲ ╲ D E F Pre: A B D E C F In: D B E A C F Post: D E B F C A
/* วิธีทำไม่พลาด: ทำทีละต้นย่อย
   In-order ของ A =
   in(ซ้ายของA) + A + in(ขวาของA)
   = (D B E) + A + (C F แบบ in)
   แตกลงไปเรื่อยๆ จนถึงใบ */
ข้อสอบวาดต้นไม้ให้ แล้วสั่ง "เขียนผลการท่องทั้ง 3 แบบ" — ฝึกกับต้นไม้ 6-9 โหนดจนทำได้ใน 3 นาที · เช็คตัวเอง: ทั้งสามแบบต้องมีโหนดครบทุกตัวเท่ากัน
ติวบทที่ 8 · เฉลยใบ practice ข้อ 1

Expression Tree — อ่าน 3 แบบ ได้ 3 notation

ตัวอย่าง: ต้นไม้ของ (a+b)*(c-d) * ╱ ╲ + − ╱ ╲ ╱ ╲ a b c d
In-order   → a + b * c − d
  (ต้องเติมวงเล็บเอง: (a+b)*(c−d))
Pre-order  → * + a b − c d  = Prefix!
Post-order → a b + c d − *  = Postfix!
ความเชื่อมโยงสุดสวย (ออกสอบ)
/* Expression Tree:
   - โหนดใน = operator
   - โหนดใบ = operand (ตัวเลข/ตัวแปร)

   ท่อง In-order   → Infix
   ท่อง Pre-order  → Prefix
   ท่อง Post-order → Postfix

   ← บทที่ 7 (postfix) กับบทนี้
   คือเรื่องเดียวกันคนละมุม!
   ข้อสอบชอบให้ tree แล้วถาม
   ทั้ง 3 แบบ (ใบ practice ข้อ 1) */

/* ระวัง: in-order อ่านตรงๆ
   "ไม่มีวงเล็บ" — ถ้าโจทย์ให้เขียน
   infix ที่ถูกต้อง ต้องใส่วงเล็บ
   ตามโครงต้นไม้ */
สูตรจำข้อนี้: ต้นไม้เดียว ตอบได้ 3 notation ตามวิธีท่อง — Pre=Prefix, In=Infix(เติมวงเล็บ), Post=Postfix · แค่จำ mapping นี้ ข้อ 1 ของ practice คือของฟรี

เก็บ Binary Tree ใน Array

กติกา index (เริ่มที่ 1 ตามสไลด์)
root อยู่ index 1
ลูกซ้ายของ i  → 2i
ลูกขวาของ i  → 2i + 1
แม่ของ i     → i / 2

/* บางตำราเริ่ม 0:
   ลูก = 2i+1, 2i+2 · แม่ = (i-1)/2
   → ทำตามแบบที่อาจารย์สอน
   (สไลด์ heap ใช้เริ่ม 1) */
* idx: 1 2 3 4 5 6 7 ╱ ╲ ค่า: * + − a b c d + − ╱ ╲ ╱ ╲ ตำแหน่งว่าง (ต้นไม้ไม่เต็ม) a b c d → เว้นช่องว่างไว้!
/* จุดหลอก: ต้นไม้เบี้ยว (skew)
   โหนดขวาลึกๆ index กระโดดไกล
   n โหนดอาจใช้ array ถึง 2ⁿ ช่อง
   → เปลือง! นี่คือเหตุผลที่
   tree ทั่วไปใช้ pointer
   แต่ heap (บท 11) ใช้ array ได้
   เพราะ complete เสมอ ไม่มีรู */
practice ข้อ 2 สั่ง "วาดโครงสร้าง array จากต้นไม้ข้อ 1" — ไล่ index 1,2,3,... แถวบนลงล่าง ซ้ายไปขวา ช่องไหนไม่มีโหนดให้เว้นว่าง

เฉลยจริง: ฟังก์ชัน xxx ทำอะไร?

โจทย์จากใบ practice
int xxx(struct Treenode *r)
{
    if (r == NULL)
        return 0;
    return 1 + xxx(r->leftChild)
             + xxx(r->rightChild);
}
คำตอบ 3.1 + วิธีอ่าน
/* อ่าน recursive แบบ "แปลสมการ":
   ต้นไม้ว่าง → 0 โหนด
   ไม่ว่าง → ตัวเอง (1)
            + โหนดฝั่งซ้ายทั้งหมด
            + โหนดฝั่งขวาทั้งหมด

   ∴ ฟังก์ชันนี้ "นับจำนวนโหนด
     ทั้งหมดในต้นไม้" (count nodes)

   3.2: printf("%d", xxx(Root));
   → พิมพ์จำนวนโหนดของต้นไม้
     ที่สร้างใน Lab (นับจากรูป
     ต้นไม้ของ Lab แล้วตอบตัวเลข) */
Pattern ข้อ "ฟังก์ชันนี้ทำอะไร": เปลี่ยน return เป็นสมการ — 1+ซ้าย+ขวา = นับโหนด · ถ้าเป็น max(ซ้าย,ขวา)+1 = หาความสูง · ถ้า if(leaf) return 1 = นับใบ — สามตัวนี้คือญาติกัน ออกสลับกันได้
💭
เช็คตัวเอง!
แก้ฟังก์ชัน xxx จากใบ practice ให้กลายเป็น "หาความสูงของต้นไม้"

ใบ้: จาก 1 + ซ้าย + ขวา (นับรวมทุกโหนด)
เปลี่ยนเป็น 1 + "ตัวที่มากกว่า" ระหว่างซ้ายกับขวา

return 1 + max(xxx(r->leftChild), xxx(r->rightChild));

แล้วถ้าอยาก "นับเฉพาะโหนดใบ" ล่ะ?
(เพิ่มเงื่อนไข: ซ้ายและขวาเป็น NULL ทั้งคู่ → return 1)

สามฟังก์ชันนี้คือชุดข้อสอบ recursive ยอดฮิตของบทต้นไม้
