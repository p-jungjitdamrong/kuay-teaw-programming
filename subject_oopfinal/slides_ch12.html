ติวบทที่ 12 · Wrapper Class

Wrapper Class — ห่อ primitive ให้กลายเป็น object

ตาราง 8 คู่ (สไลด์มีเต็มๆ)
PrimitiveWrapper
booleanBoolean
charCharacter
byteByte
shortShort
intInteger
longLong
floatFloat
doubleDouble
ทำไมต้องมี + จุดหลอก
/* เหตุผลตามสไลด์:
   "คอลเลคชั่นคลาส สมาชิกย่อยต้องเป็น
    พอยต์เตอร์ไปยัง object
    → ใช้ชุดข้อมูลพื้นฐานเป็นสมาชิก
      ของ collection ไม่ได้!
    (แต่มี wrapper class ใช้แทนได้) */

ArrayList<int> ❌      // ใช้ไม่ได้!
ArrayList<Integer> ✓    // ต้องใช้ wrapper

/* 2 ชื่อที่ไม่ตรงตัว (ข้อสอบชอบหลอก):
   char  → Character (ไม่ใช่ Char!)
   int   → Integer   (ไม่ใช่ Int!)
   ที่เหลือแค่เปลี่ยนตัวแรกเป็นพิมพ์ใหญ่ */

/* wrapper object เป็น immutable
   (แก้ค่าที่กำหนดไว้ไม่ได้) */
method ที่ใช้บ่อย (ส่วนใหญ่เป็น static เรียกผ่านชื่อคลาสได้เลย): Integer.parseInt("1") · Double.parseDouble(s) · Integer.valueOf(1) — parseInt คืน primitive, valueOf คืน object
ติวบทที่ 12 · Boxing

Boxing / Unboxing + คำว่า "Auto"

4 คำจากสไลด์ (แยกให้ออก)
// Boxing: primitive → object (เขียนเอง)
int x = 5;
Integer y = new Integer(x);

// Unboxing: object → primitive (เขียนเอง)
Integer a = new Integer("5");
int b = a.intValue();

// Autoboxing: อัตโนมัติ (J2SE 5.0+)
int p = 5;
Integer q = p;              // ไม่ต้อง new!

// Autounboxing: อัตโนมัติ
Integer m = new Integer("5");
int n = m;                  // ไม่ต้อง intValue()!
ประโยชน์ + จุดพัง
/* ประโยชน์ตามสไลด์:
   "สะดวกต่อการทำงานระหว่าง
    primitive type และ collection" */

ArrayList<Integer> list = new ArrayList<>();
list.add(10);          // autoboxing!
int v = list.get(0);   // autounboxing!

/* ⚠️ จุดพังที่ข้อสอบชอบ:
   Integer a = null;
   int b = a;    → NullPointerException!
   (autounboxing จาก null)

   และการเทียบ:
   Integer x = 1000, y = 1000;
   x == y     → false! (คนละ object)
   x.equals(y) → true  ✓
   ← เทียบ wrapper ต้องใช้ equals */
โยงกลับ midterm: เรื่อง == vs equals กลับมาอีกครั้ง — wrapper เป็น object จึงต้องเทียบด้วย .equals() · แต่ primitive (int) เทียบด้วย == ได้ปกติ
ติวบทที่ 12 · Generics

Generics <T> — ทำไมต้องมี (ตัวอย่าง Box ในสไลด์)

แบบเก่า: ใช้ Object
public class Box {
    private Object content;
    public Object getContent() { return content; }
    public void setContent(Object c) { content = c; }
}

Box myBox = new Box();
myBox.setContent("I am a String");
String s = (String) myBox.getContent();
//         ↑ ต้อง cast ทุกครั้ง!

/* ปัญหา:
   ① ต้อง cast เอง เสี่ยงพลาด
   ② ใส่อะไรก็ได้ — ใส่ Integer
      แล้ว cast เป็น String
      → ClassCastException ตอนรัน! */
แบบใหม่: Generic <T>
public class Box<T> {
    private T content;
    public T getContent() { return content; }
    public void setContent(T c) { content = c; }
}

Box<String> myBox = new Box<>();
myBox.setContent("I am a String");
String s = myBox.getContent();  // no casting!

myBox.setContent(1);        // compile error ✓
Integer i = myBox.getContent(); // compile error ✓

/* ข้อดี: ผิดตั้งแต่ compile
   ไม่ต้องรอพังตอนรัน + ไม่ต้อง cast */
ประโยคทองของ Generics: "ย้ายความผิดพลาดจาก run-time มาเป็น compile-time" — พังตอน compile ดีกว่าพังตอนลูกค้าใช้ · Java 1.5 ขึ้นไปถึงมี · <> ฝั่งขวาเว้นว่างได้ (diamond operator)
ติวบทที่ 12 · เลือกใช้

List / Set / Map — เลือกตัวไหนดี

ตระกูลคุณสมบัติคลาสที่ใช้ใช้เมื่อ
Listมีลำดับ · ซ้ำได้ · เข้าถึงด้วย indexArrayList, LinkedListเก็บรายการเรียงลำดับ
Setไม่มีลำดับ · ห้ามซ้ำHashSet, TreeSetเก็บของไม่ซ้ำ (เช่นรหัสนิสิต)
Mapคู่ key→value · key ห้ามซ้ำHashMap, TreeMapค้นด้วยคีย์ (เช่น รหัส→ชื่อ)
 
// List — มีลำดับ ซ้ำได้
List<String> list = new ArrayList<>();
list.add("A"); list.add("A");   // ได้ 2 ตัว
list.get(0);        // เข้าถึงด้วย index
list.size();         // จำนวน
list.remove(0);

// Set — ห้ามซ้ำ
Set<String> set = new HashSet<>();
set.add("A"); set.add("A");    // เหลือ 1 ตัว!
// Map — คู่ key/value
Map<String,Integer> m = new HashMap<>();
m.put("apple", 50);
m.put("banana", 30);
m.get("apple");        // 50
m.containsKey("apple"); // true

/* ArrayList vs LinkedList
   (ความรู้จากวิชา Data Structures!)
   ArrayList  → เข้าถึง index O(1)
                แทรกกลาง O(n)
   LinkedList → เข้าถึง O(n)
                แทรก/ลบ O(1) */
ประกาศแบบมืออาชีพ: List<String> list = new ArrayList<>(); — ฝั่งซ้ายใช้ interface ฝั่งขวาใช้ คลาสจริง · เปลี่ยนไปใช้ LinkedList ทีหลังแก้ที่เดียว (นี่คือ polymorphism บท 7 ใช้จริง!)
ติวบทที่ 12 · วนอ่าน

3 วิธีวนอ่าน Collection

// ① for ธรรมดา (ใช้กับ List เท่านั้น)
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

// ② for-each (ง่ายสุด นิยมสุด)
for (String s : list) {
    System.out.println(s);
}

// ③ Iterator (แบบที่ lab 8 ให้ทำเอง!)
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    System.out.println(it.next());
}
วน Map ต้องใช้ท่าพิเศษ
// วน key อย่างเดียว
for (String key : map.keySet()) {
    System.out.println(key + " = "
                     + map.get(key));
}

// วนทั้งคู่ (entrySet)
for (Map.Entry<String,Integer> e
     : map.entrySet()) {
    System.out.println(e.getKey()
                     + " = " + e.getValue());
}

/* ⚠️ ห้ามลบสมาชิกระหว่าง for-each!
   → ConcurrentModificationException
   ต้องใช้ it.remove() ของ Iterator */
เชื่อมบท 8: Iterator ที่ lab 8 ให้เขียนเอง (hasNext/next) คือ interface มาตรฐานตัวเดียวกับที่ collection ทุกตัวใน Java ใช้ — เขียนเองครั้งเดียวเข้าใจทั้งระบบ
ติวบทที่ 12 · เฉลย lab 12

เฉลย: คลาส Item + ArrayList เก็บรายการ

public class Item {                      // ตามที่โจทย์กำหนด 3 field
    private String name;
    private double price;
    private int quantity;

    public Item(String name, double price, int quantity) {
        this.name = name; this.price = price; this.quantity = quantity;
    }
    public String getName()   { return name; }
    public double getPrice()  { return price; }
    public int getQuantity()  { return quantity; }
    public double getTotal()  { return price * quantity; }

    public String toString() {                // Override → println(item) สวย
        return String.format("%-10s %8.2f %5d %10.2f",
                             name, price, quantity, getTotal());
    }
}

import java.util.*;
public class TestItem {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        ArrayList<Item> items = new ArrayList<>();   // Generic! เก็บเฉพาะ Item

        while (true) {
            System.out.print("Name (พิมพ์ exit เพื่อจบ): ");
            String name = sc.nextLine();
            if (name.equals("exit")) break;        // String → equals!
            System.out.print("Price: ");
            double price = Double.parseDouble(sc.nextLine());
            System.out.print("Quantity: ");
            int qty = Integer.parseInt(sc.nextLine());
            items.add(new Item(name, price, qty));     // เพิ่มลง list
        }

        double grand = 0;
        System.out.printf("%-10s %8s %5s %10s%n", "NAME","PRICE","QTY","TOTAL");
        for (Item it : items) {                       // for-each
            System.out.println(it);                    // เรียก toString() อัตโนมัติ
            grand += it.getTotal();
        }
        System.out.printf("Grand Total: %.2f%n", grand);
    }
}
4 จุดให้คะแนนของข้อนี้: ① คลาส Item ครบ 3 field + getter ② ใช้ ArrayList<Item> (มี generic!) ③ วนรับจนกว่าจะจบด้วย add() ④ for-each รวมยอด — และ toString() ทำให้ println สวยโดยไม่ต้องเขียนซ้ำ
