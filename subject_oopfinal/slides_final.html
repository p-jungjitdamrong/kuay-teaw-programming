ศัพท์ความหมายสั้นที่สุดที่ยังถูก
Polymorphismวัตถุต่างกันตอบสนองข่าวสารเดียวกันต่างกัน (poly=หลาย morph=รูปแบบ)
Overloadingชื่อซ้ำในคลาสเดียว parameter ต่าง — ตัดสินตอน compile
Overridingลูกทับ method แม่ signature เหมือนเป๊ะ — ตัดสินตอน run-time
Interface"บอกสิ่งที่ต้องทำ ไม่บอกว่าทำอย่างไร" — method ไม่มี body, field เป็นค่าคงที่

Exceptionข้อผิดพลาดที่ "จัดการได้" · Error = ร้ายแรง ไม่ควรจับ
Checkedไม่ใช่ Error/RuntimeException — compiler บังคับ try-catch หรือ throws
Event Listenerคลาสที่ implements ActionListener + เขียน actionPerformed()
Wrapper classห่อ primitive ให้เป็น object (int→Integer) — collection ต้องใช้
Autoboxingprimitive → object อัตโนมัติ (ทางกลับ = Autounboxing)
Generics <T>กำหนดชนิดสมาชิก — ย้าย error จาก run-time มา compile-time
Stream"ท่อ" ส่งข้อมูล source→sink · Stream=byte, Reader/Writer=char
Cheat Sheet · 4 ตารางทอง

4 ตารางเทียบที่ออกบ่อยที่สุด

① Overload vs Override
Overload: คลาสเดียว · param ต่าง · compile
Override: แม่-ลูก · signature เหมือน · runtime

② abstract class vs interface
abstract: extends แม่เดียว · มี field/ctor ได้
          "เป็นอะไร" (is-a)
interface: implements หลายตัว · ค่าคงที่เท่านั้น
          "ทำอะไรได้" (can-do)
③ Checked vs Unchecked
Unchecked: Error + RuntimeException
           compiler ไม่บังคับ (NullPointer,
           ArithmeticException, ArrayIndex...)
Checked:   ที่เหลือ — บังคับจัดการ
           (IOException, FileNotFound...)

④ List / Set / Map
List: ลำดับ + ซ้ำได้ + index (ArrayList)
Set:  ห้ามซ้ำ (HashSet)
Map:  key→value, key ห้ามซ้ำ (HashMap)
วิธีใช้: คืนก่อนสอบเขียน 4 ตารางนี้จากความจำ — เขียนได้ครบ = ตอบข้อทฤษฎีครึ่งหลังได้เกือบหมด เพราะข้อสอบวนอยู่ 4 คู่เทียบนี้
Cheat Sheet · ห้ามพลาด

10 จุดหลอกเสียคะแนนฟรี (ข้อ 1–5)

① Dynamic binding — ดูฝั่งขวาของ new
   A r = new B(); r.callme(); → เรียกของ B ไม่ใช่ A
   ชนิดตัวแปรมีผลแค่ตอน compile ว่า "เรียก method นี้ได้ไหม"

② Overload ไม่ได้ทับ Overload
   B มี show(String) ไม่ได้ลบ show() ของ A ทิ้ง — เรียกได้ทั้งคู่

③ interface: field ต้องกำหนดค่า
   int x;  ❌  → int x = 10; ✓  (เพราะเป็น public static final)

④ inner class new ยังไง
   มี static → new Outer.Inner()   ·   ไม่มี static → outerObj.new Inner()

⑤ catch เรียงลูกก่อนแม่
   catch(Exception) ไว้บนสุด แล้วตามด้วย catch(IOException) = compile error
Cheat Sheet · ห้ามพลาด

10 จุดหลอกเสียคะแนนฟรี (ข้อ 6–10)

⑥ throw vs throws
   throw (ไม่มี s) = โยนจริงในตัว method  ·  throws (มี s) = ประกาศที่หัว method

⑦ ลืม addActionListener
   compile ผ่าน หน้าต่างขึ้น แต่กดปุ่มเงียบ — bug ที่หาไม่เจอถ้าไม่รู้

⑧ Swing ไม่ได้แทนที่ AWT
   Swing สร้างบน AWT และยังใช้ event handling ของ AWT (ActionListener อยู่ java.awt.event)

⑨ JScrollPane ต้อง "ห่อ" ไม่ใช่ "add"
   new JScrollPane(area) ✓   ·   scrollPane.add(area) ✗

⑩ collection ใช้ primitive ไม่ได้
   ArrayList<int> ❌ → ArrayList<Integer> ✓  · และเทียบ wrapper ด้วย .equals() ไม่ใช่ ==
คืนก่อนสอบอ่านสองหน้านี้รอบเดียวพอ — สิบข้อนี้คือจุดที่นักศึกษาเสียคะแนนซ้ำๆ ทุกปีในครึ่งหลังของวิชา
Cheat Sheet · โค้ดท่องจำ

โค้ด 5 ท่า — เขียนได้จากความจำ = ข้อเขียนโค้ดผ่าน

// ① interface + implements
interface Rollable { void roll(); }
class Ball implements Rollable {
    public void roll() { ... }
}

// ② try-catch-finally
try { ... }
catch (ArithmeticException e) {
    System.out.println(e.getMessage());
}
finally { ... }

// ③ GUI + ActionListener 3 ขั้น
class W extends JFrame
        implements ActionListener {   // ①
    W() {
        btn.addActionListener(this);   // ②
        setVisible(true);
    }
    public void actionPerformed(ActionEvent e) { }  // ③
}
// ④ ArrayList + for-each
ArrayList<Item> list = new ArrayList<>();
list.add(new Item(...));
for (Item it : list) {
    System.out.println(it);
}

// ⑤ อ่าน/เขียนไฟล์
try (BufferedReader br = new BufferedReader(
         new FileReader("in.txt"))) {
    String line;
    while ((line = br.readLine()) != null)
        System.out.println(line);
} catch (IOException e) { }

try (PrintWriter pw = new PrintWriter(
         new FileWriter("out.txt"))) {
    pw.println("data");
} catch (IOException e) { }
ทดสอบ: ปิดจอ เขียนทั้ง 5 ท่าลงกระดาษใน 15 นาที — ผ่าน = ข้อเขียนโค้ดของ final พร้อมแล้ว เพราะโจทย์ส่วนใหญ่คือการผสม 5 ท่านี้เข้าด้วยกัน

Cheat Sheet · ข้อสุดท้าย

ข้อรวบยอด — ผสม 4 บทในข้อเดียว

ArrayList<Integer> list = new ArrayList<>();
list.add(10);
list.add(20);
try {
    System.out.println(list.get(5));
} catch (IndexOutOfBoundsException e) {
    System.out.println("error");
} finally {
    System.out.println(list.size());
}
// รวม 3 บท: ArrayList+Generic (12) · Exception (9) · autoboxing (12)
// ไล่: add 2 ตัว → get(5) เกิน → โยน IndexOutOfBounds (unchecked)
//      → catch ตรงชนิด พิมพ์ "error" → finally ทำเสมอ พิมพ์ size = 2
