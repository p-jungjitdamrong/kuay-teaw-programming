ติวบทที่ 11 · โครงสร้าง

Component 3 ระดับ — จัดกลุ่มตามสไลด์

① top-level container
   frame หรือ main window
   → JFrame (+ JDialog, JApplet)
   "มีหน้าที่ไว้ให้ component อื่นมาวาง"

② intermediate container
   "มีเพื่อให้ง่ายต่อการวางตำแหน่ง"
   → JPanel, JScrollPane, JTabbedPane

③ atomic components
   "องค์ประกอบที่มีข้อมูลและ
    มีความหมายในตัว"
   → JTextField, JComboBox, JLabel,
      JTable, JButton
┌─ JFrame ─────────────────────┐ ① top-level │ ┌─ JPanel ─────────────────┐ │ ② intermediate │ │ [JLabel] [JTextField] │ │ ③ atomic │ │ [JButton] [JButton] │ │ │ └──────────────────────────┘ │ └──────────────────────────────┘
/* ลำดับการประกอบ (จากในออกนอก):
   ① สร้าง atomic (ปุ่ม/ช่องกรอก)
   ② add ลง JPanel
   ③ add JPanel ลง JFrame
   ④ setVisible(true)

   ⚠️ JFrame ต้องมีเสมอ 1 อัน —
   ไม่มี top-level container
   = ไม่มีหน้าต่างให้แสดง */
ข้อปรนัยเก็ง: "JPanel จัดอยู่ในระดับใด" → intermediate container · "component ใดเป็น top-level" → JFrame/JDialog/JApplet · "JButton จัดเป็น" → atomic component
ติวบทที่ 11 · ท่าบังคับ

โครงหน้าต่าง 6 บรรทัด — เขียนได้หลับตา

import javax.swing.*;

JFrame f = new JFrame("ชื่อหน้าต่าง");      // ① สร้างหน้าต่าง
f.setSize(200, 100);                        // ② กำหนดขนาด (กว้าง, สูง)

JPanel pane = new JPanel();                  // ③ สร้างแผงรอง
JTextField textField = new JTextField("default text", 10);
pane.add(textField);                          // ④ ใส่ component ลงแผง
f.add(pane);                                  // ⑤ ใส่แผงลงหน้าต่าง

f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); // ⑥ กด X แล้วจบโปรแกรม
f.setVisible(true);                            // ⑦ แสดงผล — บรรทัดสุดท้ายเสมอ!
/* 2 บรรทัดที่ลืมแล้วเจ็บ:

   ลืม setVisible(true)
   → รันแล้ว "ไม่มีอะไรขึ้น"
     (โปรแกรมทำงานแต่ไม่แสดง)

   ลืม setDefaultCloseOperation
   → กด X ปิดหน้าต่างแล้ว
     โปรแกรมยังค้างอยู่เบื้องหลัง */
/* setVisible(true) ต้องอยู่
   "หลังจาก add component ครบแล้ว"
   ไม่งั้นบาง component อาจไม่แสดง

   อีกแบบ: เขียนเป็นคลาส
   public class MyWin extends JFrame {
       public MyWin() {
           ... ทุกอย่างข้างบน
           แต่ใช้ this แทน f ...
       }
   }  ← แบบที่ lab 10 ใช้ */
ข้อเขียนโค้ด GUI ให้คะแนนตาม 7 บรรทัดนี้ — จำลำดับ "สร้าง → ใส่ลงแผง → ใส่แผงลง frame → setVisible ท้ายสุด" แล้วเปลี่ยนแค่ component ตรงกลางตามโจทย์
ติวบทที่ 11 · Component หลัก

Component ที่สไลด์ไล่ให้ — constructor ที่ต้องจำ

Componentใช้ทำอะไรConstructor ที่ใช้บ่อย
JTextFieldกรอกข้อความ 1 บรรทัดJTextField(int cols)
JTextField(String text, int cols)
JLabelข้อความกำกับ "ไม่ตอบสนองผู้ใช้"JLabel(String text)
JLabel(String text, int align)
JPasswordFieldกรอกรหัสผ่าน (ไม่เห็นตัวอักษร)JPasswordField(int columns)
JTextAreaกรอกข้อความ "มากกว่า 1 บรรทัด"JTextArea(int lines, int columns)
JButtonปุ่มกด (ผูก ActionListener)JButton(String text)
JScrollPanecontainer ที่มี scroll barJScrollPane(component)
JPanelแผงรองจัดวางJPanel() / JPanel(layout)
คู่ที่ข้อสอบชอบสลับ: JTextField = 1 บรรทัด (parameter คือ "จำนวน column") · JTextArea = หลายบรรทัด (parameter คือ "lines, columns" — บรรทัดมาก่อน!) · JLabel = แสดงอย่างเดียว ผู้ใช้แก้ไม่ได้
ติวบทที่ 11 · JScrollPane

JScrollPane — "ห่อ" ไม่ใช่ "ใส่"

❌ ผิด (คนพลาดบ่อย)
JTextArea area = new JTextArea(5, 15);
JScrollPane sp = new JScrollPane();
sp.add(area);          // ❌ ไม่ทำงาน!
pane.add(sp);
✅ ถูก — ส่งเข้า constructor
JTextArea area = new JTextArea(5, 15);
JScrollPane sp = new JScrollPane(area);  // ห่อ!
pane.add(sp);          // ใส่ตัวที่ห่อแล้วลงแผง

/* คิดว่า JScrollPane เป็น "กรอบ
   ที่ครอบของ" ไม่ใช่กล่องที่ใส่ของ */
ตัวอย่างเต็มจากสไลด์
JFrame f = new JFrame();
f.setSize(200, 200);
JPanel pane = new JPanel();

JTextArea area = new JTextArea(5, 15);
pane.add(new JScrollPane(area));   // ห่อแล้วใส่เลย

f.add(pane);
f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
f.setVisible(true);

/* ใช้กับอะไรได้บ้าง:
   JTextArea (ข้อความยาว)
   JTable (ตารางแถวเยอะ)
   JList (รายการยาว)
   → อะไรก็ตามที่ "ล้นกรอบ" ได้ */
เหตุผลเชิงเทคนิค: JScrollPane มี "viewport" ข้างในที่จัดการการเลื่อนเอง — ต้องส่ง component เข้าไปตอนสร้าง (หรือ sp.setViewportView(area)) การ add ตรงๆ จะไปวางผิดที่
ติวบทที่ 11 · Layout Manager

Layout Manager 3 ตัวหลัก — ตัวจัดตำแหน่งอัตโนมัติ

FlowLayout — เรียงต่อกันเป็นแถว
  ล้นแล้วขึ้นบรรทัดใหม่
  → ค่าเริ่มต้นของ JPanel
  new JPanel();  // FlowLayout อัตโนมัติ

BorderLayout — แบ่ง 5 ทิศ
  NORTH / SOUTH / EAST / WEST / CENTER
  → ค่าเริ่มต้นของ JFrame
  f.add(comp, BorderLayout.NORTH);
  // ไม่ระบุทิศ = CENTER

GridLayout — ตารางช่องเท่ากัน
  new GridLayout(4, 4);  // 4×4 = 16 ช่อง
  → เหมาะกับ "ปุ่มเครื่องคิดเลข"!
BorderLayout: GridLayout(2,3): ┌─── NORTH ───┐ ┌───┬───┬───┐ │W│ CENTER │E│ │ 1 │ 2 │ 3 │ │ │ │ │ ├───┼───┼───┤ └─── SOUTH ───┘ │ 4 │ 5 │ 6 │ └───┴───┴───┘ FlowLayout: [btn1] [btn2] [btn3] [btn4] ← ล้นแล้วขึ้นบรรทัดใหม่
/* ตั้ง layout ให้ panel:
   JPanel p = new JPanel(new GridLayout(4,4));
   หรือ p.setLayout(new GridLayout(4,4)); */
สูตรจัดหน้าเครื่องคิดเลข (ใช้กับ lab 10): JFrame ใช้ BorderLayout อยู่แล้ว → ใส่จอ (JTextField) ที่ NORTH · ใส่ JPanel ที่ตั้ง GridLayout(4,4) เก็บปุ่มไว้ที่ CENTER — จบสวยด้วย 2 บรรทัด
ติวบทที่ 11 · อ่าน/เขียนค่า

method อ่าน-เขียนค่าที่ใช้จริงในโจทย์

// อ่านค่าที่ผู้ใช้กรอก
String s = textField.getText();
String t = textArea.getText();

// เขียนค่าลงไป
textField.setText("ข้อความใหม่");
textField.setText("");         // ล้างช่อง
label.setText("ผลลัพธ์: " + x);

// แปลง String → ตัวเลข (ใช้บ่อยมาก!)
int n = Integer.parseInt(textField.getText());
double d = Double.parseDouble(textField.getText());
จุดที่ต้องระวัง (โยงบท 9)
/* getText() คืน String เสมอ
   ผู้ใช้พิมพ์ "abc" แล้ว parseInt
   → NumberFormatException!
     (Unchecked แต่ควรจับ) */

try {
    int n = Integer.parseInt(
                field.getText());
    label.setText("OK: " + n);
} catch (NumberFormatException ex) {
    label.setText("กรุณากรอกตัวเลข");
}

/* JPasswordField ต่าง:
   getPassword() คืน char[]
   ไม่ใช่ String (เหตุผลด้านความปลอดภัย)
   → new String(pass.getPassword()) */
โจทย์ GUI ที่สมบูรณ์มักผสม 3 บท: component (บท 11) + ActionListener (บท 10) + try-catch ตอนแปลงตัวเลข (บท 9) — เขียนครบสามอย่างนี้ = คำตอบที่อาจารย์อยากเห็น

ติวบทที่ 11 · ลองข้อสอบ

อยากให้ JTextArea เลื่อนดูข้อความยาวๆ ได้ ต้องทำอย่างไร?

A area.setScrollable(true);
B pane.add(new JScrollPane(area));
C JScrollPane sp = new JScrollPane(); sp.add(area);
D JTextArea มี scroll bar ในตัวอยู่แล้ว
JScrollPane เป็น "กรอบที่ครอบของ" — ต้องส่ง component เข้า constructor:
  new JScrollPane(component)     ✓
  scrollPane.add(component)      ✗ (ไม่ทำงาน)
ใช้ได้กับทุกอย่างที่ล้นกรอบ: JTextArea, JTable, JList
