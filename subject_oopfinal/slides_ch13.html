ติวบทที่ 13 · แนวคิด

Stream คืออะไร — นิยามตามสไลด์

"Stream เป็นเหมือน 'ท่อ' ส่งข้อมูล
 จากต้นทาง (source) ไปยังปลายทาง (sink)

 source = ตำแหน่งเริ่มต้นของ stream
        → เรียกว่า input stream
 sink   = ตำแหน่งสิ้นสุดของ stream
        → เรียกว่า output stream

 source หรือ sink อาจเป็น
 ฮาร์ดแวร์หรือซอฟต์แวร์
 เช่น ไฟล์ หน่วยความจำ หรือ socket"
อ่านไฟล์ (input): [ไฟล์] ══ท่อ══▶ [โปรแกรม] source sink เขียนไฟล์ (output): [โปรแกรม] ══ท่อ══▶ [ไฟล์] source sink มองจาก "มุมของโปรแกรม" เสมอ: เข้าโปรแกรม = input ออกจากโปรแกรม = output
/* 2 ชนิดตามสไลด์:
   ① Byte stream
   ② Character stream

   "คำว่า stream โดยทั่วไปหมายถึง
    byte stream
    reader และ writer หมายถึง
    character stream" */
วิธีจำชื่อคลาสทั้งหมดของบทนี้: ลงท้าย Stream = byte · ลงท้าย Reader/Writer = character · ขึ้นต้น Input/Reader = อ่าน · ขึ้นต้น Output/Writer = เขียน — รู้ 2 กฎนี้เดาชื่อคลาสได้หมด
ติวบทที่ 13 · java.io

4 คลาสพื้นฐานใน package java.io

คลาสฐานชนิดข้อมูลทิศทางคลาสลูกที่ใช้จริง
InputStreambyteอ่านFileInputStream
OutputStreambyteเขียนFileOutputStream
Readercharอ่านFileReader, BufferedReader
WritercharเขียนFileWriter, PrintWriter
 
/* เลือกใช้ตัวไหน:

   ไฟล์ข้อความ (.txt, .csv)
   → Reader / Writer (character)

   ไฟล์ binary (.jpg, .mp3, .zip)
   → InputStream / OutputStream (byte)

   ← ข้อสอบถาม "ควรใช้คลาสใด"
     ดูว่าไฟล์เป็นข้อความหรือไบนารี */
/* คลาสที่ "ห่อ" เพื่อเพิ่มความสามารถ
   (Decorator pattern):

   FileReader อ่านทีละตัวอักษร → ช้า
   ห่อด้วย BufferedReader →
     อ่านทีละบรรทัดได้ (readLine())
     และเร็วขึ้นมาก

   BufferedReader br = new BufferedReader(
       new FileReader("data.txt"));
   ← เห็น new ซ้อน new บ่อยมากในบทนี้ */
ทำไมต้องห่อ (new ซ้อน new): แต่ละคลาสทำหน้าที่เดียว — FileReader รู้วิธีเปิดไฟล์ · BufferedReader รู้วิธีอ่านทีละบรรทัดเร็วๆ · เอามาต่อกันได้ผลลัพธ์ที่ต้องการ (นี่คือการ compose object แบบ OOP)

// ตัวอย่าง
File f1 = new File("data.txt");
File f2 = new File("C:/temp", "data.txt");

/* ⚠️ จุดหลอก:
   new File("x.txt") "ไม่ได้สร้างไฟล์"!
   แค่สร้าง object ที่ "อ้างถึง" path
   ไฟล์จริงจะเกิดตอน createNewFile()
   หรือตอนเขียนด้วย Writer */
method ที่ใช้บ่อย
f.exists()        // มีไฟล์นี้ไหม (boolean)
f.getName()       // ชื่อไฟล์
f.getPath()       // path
f.length()        // ขนาด (byte)
f.canRead()       // อ่านได้ไหม
f.canWrite()      // เขียนได้ไหม
f.isFile()        // เป็นไฟล์ไหม
f.isDirectory()   // เป็นโฟลเดอร์ไหม
f.delete()        // ลบ
f.createNewFile() // สร้างไฟล์จริง (throws IOException)
f.mkdir()         // สร้างโฟลเดอร์
f.list()          // รายชื่อในโฟลเดอร์ (String[])
Pattern ที่ควรเขียนเสมอ: if (f.exists()) { ...อ่าน... } else { ...แจ้งว่าไม่มีไฟล์... } — เช็คก่อนอ่าน ลด FileNotFoundException (ซึ่งเป็น checked exception จากบท 9!)
ติวบทที่ 13 · ท่าบังคับ

อ่าน / เขียนไฟล์ข้อความ — 2 ท่าที่ต้องเขียนได้

อ่านทีละบรรทัด
import java.io.*;

try (BufferedReader br = new BufferedReader(
         new FileReader("data.txt"))) {

    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    System.out.println("อ่านไฟล์ไม่ได้: "
                       + e.getMessage());
}

/* readLine() คืน null เมื่อจบไฟล์
   → เงื่อนไข while ใช้ != null */
เขียนลงไฟล์
try (PrintWriter pw = new PrintWriter(
         new FileWriter("out.txt"))) {

    pw.println("บรรทัดแรก");
    pw.printf("%s %.2f%n", "ราคา", 99.5);

} catch (IOException e) {
    e.printStackTrace();
}

/* PrintWriter ใช้ println/printf
   ได้เหมือน System.out เลย!
   ← ท่าที่จำง่ายที่สุด

   เขียนต่อท้าย (ไม่ทับของเดิม):
   new FileWriter("out.txt", true)
                            ↑ append */
try-with-resources try (... ) { } — ประกาศ resource ในวงเล็บแล้ว Java ปิดให้อัตโนมัติ ไม่ต้องเขียน finally { close(); } · ถ้าเขียนแบบเก่าต้องมี finally { br.close(); } เสมอ ไม่งั้นไฟล์ค้าง
ติวบทที่ 13 · เฉลย lab 13

เฉลย: บันทึกรายการ item ลงไฟล์ แล้วอ่านกลับ

import java.io.*;
import java.util.*;

public class ItemFileIO {
    public static void main(String[] args) {
        ArrayList<Item> items = new ArrayList<>();      // ใช้ของบท 12
        items.add(new Item("Mama", 5.5, 10));
        items.add(new Item("Lays", 10.5, 3));

        // ── เขียนลงไฟล์ ──
        try (PrintWriter pw = new PrintWriter(new FileWriter("items.txt"))) {
            for (Item it : items) {
                pw.println(it.getName() + "," + it.getPrice()
                           + "," + it.getQuantity());     // รูปแบบ CSV
            }
            System.out.println("บันทึกเรียบร้อย");
        } catch (IOException e) {
            System.out.println("เขียนไฟล์ไม่ได้: " + e.getMessage());
        }

        // ── อ่านกลับมา ──
        ArrayList<Item> loaded = new ArrayList<>();
        File f = new File("items.txt");
        if (!f.exists()) {                                // เช็คก่อนอ่าน!
            System.out.println("ไม่พบไฟล์");
            return;
        }
        try (BufferedReader br = new BufferedReader(new FileReader(f))) {
            String line;
            while ((line = br.readLine()) != null) {
                String[] p = line.split(",");              // แยกด้วย , (บท Array&String)
                loaded.add(new Item(p[0],
                        Double.parseDouble(p[1]),           // wrapper บท 12
                        Integer.parseInt(p[2])));
            }
        } catch (IOException e) {
            System.out.println("อ่านไฟล์ไม่ได้");
        }

        double grand = 0;
        for (Item it : loaded) { System.out.println(it); grand += it.getTotal(); }
        System.out.printf("Grand Total: %.2f%n", grand);
    }
}
ข้อนี้รวม 4 บทในข้อเดียว: Item + ArrayList (บท 12) · try-catch IOException (บท 9) · split/parseDouble (บท 2 midterm) · File IO (บทนี้) — ข้อสอบ final ชอบออกแบบผสมแบบนี้แหละ

เขียน "ทั้ง object" ลงไฟล์ — Serialization

แทนที่จะแปลงเป็นข้อความเอง
// ① คลาสต้อง implements Serializable
public class Item implements Serializable {
    // ... field เดิม ...
}

// ② เขียน object ทั้งก้อน
try (ObjectOutputStream out = new ObjectOutputStream(
         new FileOutputStream("items.dat"))) {
    out.writeObject(items);   // ทั้ง ArrayList เลย!
}
อ่านกลับ
try (ObjectInputStream in = new ObjectInputStream(
         new FileInputStream("items.dat"))) {
    ArrayList<Item> loaded =
        (ArrayList<Item>) in.readObject();
}

/* Serializable เป็น "marker interface"
   — ไม่มี method ให้ implement เลย!
   แค่ประกาศไว้เพื่อบอก JVM ว่า
   "คลาสนี้ยอมให้แปลงเป็น byte ได้"

   ← interface ที่ไม่มี method
     ก็มีจริงในโลก (บท 7) */

/* ไฟล์ที่ได้เป็น binary → ใช้
   Stream ไม่ใช่ Reader/Writer */
เทียบ 2 วิธี: เขียนเป็น ข้อความ (CSV) — คนอ่านได้ แก้ด้วย notepad ได้ แต่ต้อง parse เอง · Serialization — สะดวก เก็บทั้ง object แต่ไฟล์เป็น binary คนอ่านไม่ออก และต้อง implements Serializable
