ติวบทที่ 1 · ตัวแปร

ตัวแปร ชนิดข้อมูล และ Reserved Words

ชนิดข้อมูลพื้นฐาน 4 ตัว
a = 10            # int    จำนวนเต็ม
b = 3.14          # float  ทศนิยม
c = "สวัสดี"       # str    ข้อความ
d = True          # bool   True/False

print(type(a))    # <class 'int'>
Python ไม่ต้องประกาศชนิด
# C:      int x = 10;
# Python: x = 10        ← รู้เอง

x = 10      # ตอนนี้เป็น int
x = "abc"   # เปลี่ยนเป็น str ได้เลย!
# เรียกว่า Dynamic Typing
กฎการตั้งชื่อตัวแปร
✓ ขึ้นต้นด้วยตัวอักษร หรือ _
✓ ตามด้วยตัวอักษร ตัวเลข _ ได้
✗ ห้ามขึ้นต้นด้วยตัวเลข
✗ ห้ามมีช่องว่างหรืออักขระพิเศษ
✗ ห้ามใช้ reserved words

score1 = 10    ✓
_name  = "a"   ✓
1score = 10    ✗ ขึ้นต้นด้วยเลข
my name = 5    ✗ มีช่องว่าง
if = 3         ✗ reserved word
Reserved Words (ห้ามใช้ตั้งชื่อ)
if elif else for while break continue
def return import from in is not and or
True False None class try except finally
lambda global pass with as
ข้อสอบคลาสสิก: "ชื่อตัวแปรใดใช้ไม่ได้" — ไล่เช็ค 3 ข้อ: ขึ้นต้นด้วยตัวเลขไหม · มีช่องว่าง/อักขระพิเศษไหม · เป็น reserved word ไหม
ติวบทที่ 1 · input/output

input() คืน string เสมอ — จุดหลอกอันดับ 1

❌ ผิดที่คนพลาดมากที่สุด
a = input("เลข 1: ")   # "5"
b = input("เลข 2: ")   # "3"
print(a + b)
53 ← ไม่ใช่ 8!
# เพราะ input() คืน "string"
# "5" + "3" = ต่อข้อความ = "53"
✓ ต้องแปลงก่อน
a = int(input("เลข 1: "))
b = int(input("เลข 2: "))
print(a + b)      # 8 ✓

# ทศนิยมใช้ float()
w = float(input("น้ำหนัก: "))
print() — คั่นด้วย , หรือ +
name = "สมชาย"; age = 20

# ใช้ , — เว้นวรรคให้อัตโนมัติ ปนชนิดได้
print("ชื่อ", name, "อายุ", age)
# ชื่อ สมชาย อายุ 20

# ใช้ + — ต้องเป็น string ทั้งหมด!
print("ชื่อ " + name)          ✓
print("อายุ " + age)           ✗ TypeError
print("อายุ " + str(age))      ✓

# f-string — สะดวกสุด
print(f"ชื่อ {name} อายุ {age}")
# ไม่ขึ้นบรรทัดใหม่
print("A", end='')
print("B")        # AB

# เปลี่ยนตัวคั่น
print("a","b","c", sep="-")  # a-b-c
ท่องไว้: input() คืน string เสมอ · , ใน print เว้นวรรคให้และปนชนิดได้ · + ต้องเป็น string ทั้งหมด — ข้อสอบชอบให้ "5"+"3" แล้วถามผลลัพธ์

# ⚠️ ลืม import → NameError
built-in — ไม่ต้อง import
abs(-5)          # 5
round(4.567, 2)  # 4.57  ปัดทศนิยม 2 ตำแหน่ง
round(4.6)        # 5
max(3, 7, 5)     # 7
min(3, 7, 5)     # 3
len("hello")     # 5

str(100)         # "100"

ติวบทที่ 1 · ฝึกทำ

โจทย์แนวสอบ — เขียนโปรแกรมพื้นฐาน

โจทย์: หาพื้นที่วงกลม
import math

r = float(input("รัศมี: "))   # แปลงเป็นตัวเลข!
area = math.pi * r ** 2

print(f"พื้นที่ = {area:.2f}")
# รัศมี: 5 → พื้นที่ = 78.54
โจทย์: แลกเงิน
baht = float(input("เงินบาท: "))
rate = 35.5
usd = baht / rate
print(f"ได้ {usd:.2f} ดอลลาร์")
การจัดรูปแบบตัวเลขที่ต้องรู้
x = 1234.5678

print(f"{x:.2f}")     # 1234.57  ทศนิยม 2
print(f"{x:,.2f}")    # 1,234.57 มีลูกน้ำ
print(f"{x:10.2f}")   #    1234.57 กว้าง 10

n = 42
print(f"{n:5}")       #    42  ชิดขวา
print(f"{n:<5}")      # 42     ชิดซ้าย

# แบบเก่าที่อาจเจอในสไลด์
print("%.2f" % x)    # 1234.57
โครงโจทย์ 90% ของบทนี้: รับค่า (input+แปลงชนิด) → คำนวณ → แสดงผล (f-string จัดทศนิยม) — ฝึกเขียน 3 บรรทัดนี้ให้คล่อง เจอโจทย์ไหนก็ปรับได้

ข้อใดตั้งชื่อตัวแปรได้ถูกต้อง?

A 2score = 80
B my score = 80
C _total = 80
D for = 80
ไล่เช็ค 3 ข้อทุกครั้ง:
① ขึ้นต้นด้วยตัวอักษรหรือ _ เท่านั้น (ห้ามตัวเลข)  → ตัด A
② ห้ามมีช่องว่างหรืออักขระพิเศษ                    → ตัด B
③ ห้ามเป็น reserved word (if/for/while/def/...)   → ตัด D
ติวบทที่ 1 · ลองข้อสอบ

โค้ดนี้เกิดอะไรขึ้น?

age = 20
print("อายุ " + age)
A พิมพ์ "อายุ 20"
B พิมพ์ "อายุ20"
C TypeError
D NameError
"อายุ " (str) + 20 (int) → TypeError: can only concatenate str to str

แก้ได้ 3 ทาง:
  print("อายุ", age)          ← ใช้ , ปนชนิดได้
  print("อายุ " + str(age))   ← แปลงเป็น str
  print(f"อายุ {age}")        ← f-string (นิยมสุด)
