สัญลักษณ์ผังงาน 8 ตัว — ท่องให้ครบ

นิยามจากสไลด์: "ผังงาน (Flow Chart) คือวิธีการออกแบบโปรแกรมอย่างเป็นขั้นตอน โดยใช้สัญลักษณ์และตัวอักษรประกอบการอธิบาย"

รูปชื่อความหมายตรงกับโค้ด
⬭Terminalจุดเริ่มต้นหรือจุดจบของโปรแกรมเริ่ม / จบ
▱Input / Outputการรับและแสดงผลของข้อมูลinput()
▭Processการประมวลผลx = a + b
◇Decision / Selectionการตัดสินใจif / while
▽Displayข้อมูลออกทางจอภาพprint()
→Flow Lineทิศทางของขั้นตอนการดำเนินงานลำดับบรรทัด
◯Connectorจุดเชื่อมการทำงานที่อยู่หน้าเดียวกัน—
⬠Off Page Connectorจุดเชื่อมการทำงานที่อยู่คนละหน้า—
ข้อสอบมาแน่ 2 แบบ: ① ให้รูปมาแล้วถามชื่อ/ความหมาย ② ให้ผังงานมาแล้วให้เขียนโค้ด — ท่อง 5 ตัวหลักให้ได้ก่อน (⬭ ▱ ▭ ◇ ▽) ส่วน connector 2 ตัวท้ายเจอน้อย
ติวบทที่ 3 · Boolean

Boolean — ผลของ ◇ มีแค่ 2 ทาง

ชนิดข้อมูล bool
flag = True
done = False
# ⚠️ ต้องขึ้นต้นด้วยตัวใหญ่!
# true / TRUE → NameError

# นิพจน์เปรียบเทียบให้ผลเป็น bool
print(5 > 3)          # True
print(type(5 > 3))    # <class 'bool'>
bool แปลงเป็นตัวเลขได้
int(True)    # 1
int(False)   # 0
True + True  # 2
ค่าที่ถือว่าเป็น False (สอบถามได้)
bool(0)        # False
bool(0.0)      # False
bool("")       # False (string ว่าง)
bool([])       # False (list ว่าง)
bool(None)     # False

# นอกนั้นเป็น True หมด
bool(1)        # True
bool(-5)       # True (ไม่ใช่ 0 ก็ True!)
bool("0")      # True (string ไม่ว่าง!)
# ใช้ในเงื่อนไขได้เลย
name = input("ชื่อ: ")
if name:              # = if name != ""
    print("สวัสดี", name)
else:
    print("ไม่ได้กรอกชื่อ")
จุดหลอก: bool("0") เป็น True เพราะเป็น string ที่ไม่ว่าง (ไม่ใช่เลข 0) · และ True/False ต้องขึ้นต้นตัวใหญ่เสมอ
ติวบทที่ 3 · if

if — รูปแบบตามสไลด์อาจารย์

รูปแบบ
if (นิพจน์หรือเงื่อนไข):
    คำสั่ง

# ตัวอย่างในสไลด์
if (x < 0):
    print("x is negative number.")
หลายคำสั่ง = Block
# "ให้ใช้การเยื้องบรรทัดในคำสั่งทั้งหมดนั้น
#  ซึ่งเรียกว่า Block"

if (radius > 0):
    area = pi * radius * radius
    print("Area =", area)
#   ↑ ทั้งสองบรรทัดเยื้องเท่ากัน
#     = อยู่ใน block เดียวกัน
ผังงานของ if
│ ◇ x < 0 ── เท็จ ──┐ │ จริง │ ▽ "negative" │ │ │ └───────────────┘ │ (ทำงานต่อ)
# วงเล็บใส่หรือไม่ใส่ก็ได้ใน Python
if (x < 0):     # ✓ (สไลด์ใช้แบบนี้)
if x < 0:       # ✓ (Python นิยมกว่า)

# ⚠️ แต่ ":" ลืมไม่ได้!
if x < 0        # ❌ SyntaxError
3 สิ่งที่ต้องมีครบทุกครั้ง: ① เงื่อนไข ② โคลอน : ท้ายบรรทัด ③ เยื้องบรรทัดถัดไป — ขาดข้อไหนก็ error
ติวบทที่ 3 · if-else

if-else — เลือก 2 ทาง

รูปแบบ
if (เงื่อนไข):
    คำสั่ง # เมื่อจริง
else:
    คำสั่ง # เมื่อเท็จ
ตัวอย่าง: ตรวจผ่าน/ตก
score = int(input("คะแนน: "))

if score >= 50:
    print("ผ่าน")
else:
    print("ตก")
◇ score >= 50 จริง │ │ เท็จ ▽"ผ่าน" │ ▽"ตก" │ │ └─┬─┘ │
ตัวอย่าง: เลขคู่/คี่
n = int(input("เลข: "))

if n % 2 == 0:
    print(n, "เป็นเลขคู่")
else:
    print(n, "เป็นเลขคี่")
ตัวอย่าง: หาค่ามากสุด
a = int(input())
b = int(input())

if a > b:
    print("มากสุดคือ", a)
else:
    print("มากสุดคือ", b)

# หรือใช้ built-in
print("มากสุดคือ", max(a, b))
ระวัง: else ไม่มีเงื่อนไข — เขียน else score < 50: เป็น SyntaxError · และ else ต้องเยื้องเท่ากับ if ที่คู่กัน
ติวบทที่ 3 · lecture 5

Nested if — if ซ้อน if

แบบซ้อนจริง (ตามผังงาน)
s = int(input("คะแนน: "))

if s >= 80:
    print("A")
else:
    if s >= 70:
        print("B")
    else:
        if s >= 60:
            print("C")
        else:
            print("F")

# เยื้องลึกขึ้นเรื่อยๆ อ่านยาก
แบบ elif — ผลเหมือนกัน อ่านง่ายกว่า
s = int(input("คะแนน: "))

if s >= 80:
    print("A")
elif s >= 70:
    print("B")
elif s >= 60:
    print("C")
else:
    print("F")

# elif = else if ย่อ
# เยื้องระดับเดียวหมด
# หลักการทำงาน:
# เช็คจากบนลงล่าง
# เจอเงื่อนไขจริงตัวแรก → ทำแล้วออกเลย
# ไม่เช็คตัวที่เหลือ!
ต่างกันตรงไหน: ผลลัพธ์เหมือนกัน แต่ elif อ่านง่ายกว่าและไม่เยื้องลึก — ข้อสอบอาจให้แปลงจากแบบหนึ่งเป็นอีกแบบ ต้องเขียนได้ทั้งคู่
ติวบทที่ 3 · กับดักใหญ่

เรียงเงื่อนไขผิดลำดับ — ผิดโดยไม่ error!

❌ เรียงจากกว้างไปแคบ
s = 90

if s >= 60:
    print("C")     # ← เข้าตัวนี้!
elif s >= 70:
    print("B")
elif s >= 80:
    print("A")
ได้ "C" ทั้งที่คะแนน 90!
# เพราะ 90 >= 60 เป็นจริง
# → ทำแล้วออกเลย ไม่เช็คตัวอื่น
# compile ผ่าน รันได้ แต่ผลผิด
# ← bug เงียบ หายากที่สุด
✓ เรียงจากแคบไปกว้าง
s = 90

if s >= 80:
    print("A")     # ✓ ถูกต้อง
elif s >= 70:
    print("B")
elif s >= 60:
    print("C")
else:
    print("F")
# กฎ: ใช้ >= เรียงจากมากไปน้อย
#     ใช้ <= เรียงจากน้อยไปมาก

# หรือระบุช่วงให้ชัดเจน (ไม่ต้องกังวลลำดับ)
if 80 <= s <= 100: print("A")
elif 70 <= s < 80: print("B")
elif 60 <= s < 70: print("C")
else: print("F")
นี่คือข้อสอบยอดฮิต: ให้โค้ดตัดเกรดที่เรียงผิดมา แล้วถามว่า "คะแนน 90 ได้เกรดอะไร" — คำตอบคือเกรดของเงื่อนไขแรกที่เป็นจริง ไม่ใช่เกรดที่ควรได้
ติวบทที่ 3 · ฝึกแปลง

อ่านผังงาน → เขียนโค้ด

โจทย์: ตรวจสอบส่วนลด
⬭ เริ่ม │ ▱ รับ total │ ◇ total >= 1000 จริง│ │เท็จ ▭ dis=total*0.1 ▭ dis=0 │ │ └───┬──┘ │ ▭ pay = total - dis │ ▽ แสดง pay │ ⬭ จบ
เฉลย
total = float(input("ยอดซื้อ: "))   # ▱

if total >= 1000:                    # ◇
    dis = total * 0.1                 # ▭ ทางจริง
else:
    dis = 0                            # ▭ ทางเท็จ

pay = total - dis                     # ▭ หลังบรรจบ
print(f"ต้องจ่าย {pay:,.2f} บาท")      # ▽

# total = 1200
# → dis = 120 → pay = 1080.00
# สังเกต: กล่องหลังจุดบรรจบ (pay)
# ต้องอยู่ "นอก" if-else
# = ไม่เยื้อง
# ถ้าเยื้องเข้าไป จะทำงานแค่ทางเดียว!
เทคนิคแปลงผังงาน: ① กล่องก่อน ◇ = โค้ดก่อน if ② สองแขนงของ ◇ = if / else ③ กล่องหลังจุดบรรจบ = โค้ดนอก if (ไม่เยื้อง) — ข้อ ③ คือจุดที่คนพลาด

ติวบทที่ 3 · ลองข้อสอบ

สัญลักษณ์ ◇ (สี่เหลี่ยมข้าวหลามตัด) หมายถึงอะไร?

A การประมวลผล (Process)
B การรับข้อมูล (Input)
C การตัดสินใจ (Decision)
D จุดเริ่มต้น (Terminal)
⬭ Terminal เริ่ม/จบ · ▱ Input/Output รับข้อมูล · ▭ Process ประมวลผล
◇ Decision ตัดสินใจ (2 ทางออก) · ▽ Display แสดงจอภาพ
ติวบทที่ 3 · ลองข้อสอบ

โค้ดนี้พิมพ์อะไร เมื่อ x = 5?

x = 5
if x > 0:
    print("บวก")
print("จบ")
A บวก
B จบ
C บวก แล้วตามด้วย จบ
D IndentationError
if x > 0:
    print("บวก")   ← เยื้อง = อยู่ใน if (ทำเมื่อเงื่อนไขจริง)
print("จบ")        ← ไม่เยื้อง = อยู่นอก if (ทำเสมอ)

x=5 → เงื่อนไขจริง → พิมพ์ทั้งสองบรรทัด
