ติวบทที่ 4 · for

for + range() — 3 รูปแบบตามสไลด์

ไวยากรณ์
for ตัวแปรนับรอบ in range(เริ่ม, สิ้นสุด, ก้าว):
    คำสั่ง
# ① range(สิ้นสุด) — เริ่มที่ 0
for i in range(5):
    print(i, end=' ')
0 1 2 3 4
# ② range(เริ่ม, สิ้นสุด)
for i in range(1, 6):
    print(i, end=' ')
1 2 3 4 5
# ③ range(เริ่ม, สิ้นสุด, ก้าว)
for i in range(0, 10, 2):
    print(i, end=' ')
0 2 4 6 8
⚠️ กฎเหล็ก: ไม่รวมตัวสุดท้าย!
range(5)        # 0,1,2,3,4    (ไม่มี 5)
range(1, 5)     # 1,2,3,4      (ไม่มี 5)
range(1, 5+1)   # 1,2,3,4,5    ✓ ถึง 5

# อยากวน 1 ถึง n → range(1, n+1)
นับถอยหลัง — ก้าวติดลบ
for i in range(5, 0, -1):
    print(i, end=' ')
5 4 3 2 1
# จำนวนรอบคำนวณยังไง
range(5)        → 5 รอบ
range(1, 6)     → 6-1 = 5 รอบ
range(0, 10, 2) → (10-0)/2 = 5 รอบ
range(5, 0, -1) → 5 รอบ
จุดหลอกอันดับ 1 ของ for: range(1, 5) ได้ 1,2,3,4 ไม่มี 5 — ข้อสอบชอบถาม "โปรแกรมพิมพ์เลขอะไรบ้าง" แล้วดักตรงนี้ · อยากได้ถึง n ต้องเขียน range(1, n+1)

Counting Loop vs Sentinel Loop

① Counting Loop — ใช้ตัวนับ
# "คำสั่งวนซ้ำแบบใช้ตัวนับ"
# รู้จำนวนรอบล่วงหน้า → ใช้ for

# พิมพ์ 1-10
for i in range(1, 11):
    print(i)

# รับคะแนน 5 คน
total = 0
for i in range(5):
    s = int(input("คะแนน: "))
    total += s
print("รวม", total)
② Sentinel Loop — ใช้ตัวหยุด
# "คำสั่งวนซ้ำแบบใช้ตัวหยุด"
# ไม่รู้จำนวนรอบ วนจนเจอค่าพิเศษ → while

# รับเลขจนกว่าจะใส่ 0
total = 0
n = int(input("เลข (0=จบ): "))
while n != 0:          # 0 = sentinel
    total += n
    n = int(input("เลข (0=จบ): "))
print("รวม", total)

# ⚠️ ต้องรับค่า 2 ที่!
#   ก่อนเข้าลูป (priming read)
#   และท้ายลูป (ไม่งั้นวนไม่รู้จบ)
เลือกใช้ยังไง: โจทย์บอก "ทำ n ครั้ง / 1 ถึง 100" → for (counting) · โจทย์บอก "จนกว่าผู้ใช้จะใส่ −1 / จนกว่าจะถูก" → while (sentinel) — และ sentinel ต้องรับค่า 2 ที่เสมอ

ลูปคู่กับ if — โจทย์มาตรฐาน 4 แบบ

① นับจำนวนที่เข้าเงื่อนไข
count = 0
for i in range(1, 21):
    if i % 3 == 0:
        count += 1
print("หาร 3 ลงตัว", count, "ตัว")
# 6 ตัว (3,6,9,12,15,18)
② หาผลรวมเฉพาะบางตัว
total = 0
for i in range(1, 11):
    if i % 2 == 0:      # เฉพาะเลขคู่
        total += i
print(total)          # 2+4+6+8+10 = 30
③ หาค่ามากสุด/น้อยสุด
max_score = -1          # เริ่มด้วยค่าต่ำมาก
for i in range(5):
    s = int(input("คะแนน: "))
    if s > max_score:
        max_score = s      # เจอตัวใหญ่กว่า → เก็บ
print("สูงสุด", max_score)
④ ตรวจสอบทุกตัว (flag)
n = int(input("เลข: "))
is_prime = True          # สมมติว่าเป็นก่อน

for i in range(2, n):
    if n % i == 0:
        is_prime = False   # เจอตัวหาร → ไม่ใช่

if is_prime and n > 1:
    print("เป็นจำนวนเฉพาะ")
else:
    print("ไม่เป็นจำนวนเฉพาะ")
4 pattern นี้ครอบคลุมโจทย์ลูปเกือบทั้งหมด — สังเกตว่าทุกแบบมี "ตัวแปรสะสม" (count/total/max/flag) ที่ประกาศไว้นอกลูป แล้วอัปเดตในลูป · ประกาศในลูป = รีเซ็ตทุกรอบ ผลผิด!

# วิธีทำในห้องสอบ:
# ① วาดตาราง: คอลัมน์ = ตัวแปรทุกตัว
# ② เขียนค่าเริ่มต้นแถวแรก
# ③ ไล่ทีละรอบ เขียนค่าใหม่ทุกครั้ง
# ④ หยุดเมื่อเงื่อนไขเป็นเท็จ
# ⚠️ จุดที่คนพลาด:
# • ลืมว่า i เพิ่ม "หลัง" print
# • คิดในหัวรวดเดียวแล้วสับสน
# → เขียนตารางเสมอ ช้ากว่าแต่ถูก
เทคนิคนี้ใช้ได้ทุกข้อ "โปรแกรมพิมพ์อะไร" — เสียเวลา 1 นาทีวาดตาราง ดีกว่าเดาแล้วผิด · โดยเฉพาะข้อที่มีตัวแปร 2-3 ตัวเปลี่ยนพร้อมกัน
ติวบทที่ 4 · โจทย์แนวสอบ

โจทย์ที่ออกบ่อย — เขียนให้ได้ทั้ง 3 ข้อ

① ตารางสูตรคูณแม่ n
n = int(input("แม่: "))
for i in range(1, 13):
    print(f"{n} x {i} = {n*i}")
② หาผลรวม 1 ถึง n
n = int(input("n: "))
total = 0
for i in range(1, n+1):   # +1 สำคัญ!
    total += i
print("ผลรวม =", total)
# n=5 → 15
③ หาแฟกทอเรียล n!
n = int(input("n: "))
fact = 1              # ⚠️ เริ่มที่ 1 ไม่ใช่ 0!
for i in range(1, n+1):
    fact *= i
print(f"{n}! = {fact}")
# 5! = 120
# ⚠️ ค่าเริ่มต้นของตัวสะสม
# บวก → เริ่มที่ 0
# คูณ → เริ่มที่ 1  (ถ้าเริ่ม 0 ได้ 0 ตลอด!)
# หา max → เริ่มที่ค่าต่ำมาก
# หา min → เริ่มที่ค่าสูงมาก
กับดักค่าเริ่มต้น: ตัวสะสมแบบคูณต้องเริ่มที่ 1 — เริ่มที่ 0 จะได้ 0 ตลอด (0×อะไรก็ 0) · เป็นข้อผิดพลาดที่เจอบ่อยในโจทย์แฟกทอเรียล

ติวบทที่ 4 · ลองข้อสอบ

for i in range(1, 5) วนกี่รอบ และ i มีค่าอะไรบ้าง?

A 5 รอบ · 1 2 3 4 5
B 4 รอบ · 1 2 3 4
C 5 รอบ · 0 1 2 3 4
D 3 รอบ · 1 2 3
range(a, b) → เริ่มที่ a ถึง b−1 (ไม่รวม b) → จำนวนรอบ = b − a

range(5)     → 0,1,2,3,4   (5 รอบ)
range(1, 5)  → 1,2,3,4     (4 รอบ)  ← ข้อนี้
range(1, 5+1)→ 1,2,3,4,5   (5 รอบ)  ← อยากได้ถึง 5 ต้องเขียนแบบนี้

โค้ดนี้พิมพ์ค่า total เท่าไหร่?

total = 0
for i in range(1, 6):
    if i % 2 == 1:
        total += i
print(total)

B 9
C 6
D 0
range(1, 6) → i = 1, 2, 3, 4, 5
เงื่อนไข i % 2 == 1 → เลขคี่ (เศษ 1)

i=1 → คี่ → total = 1
i=2 → คู่ → ข้าม
i=3 → คี่ → total = 4
i=4 → คู่ → ข้าม
i=5 → คี่ → total = 9
