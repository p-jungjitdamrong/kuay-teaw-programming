ลำดับตัวดำเนินการ + range()

ลำดับครบทุกตัว (สูง → ต่ำ)
1.  ( )                วงเล็บ
2.  **                 ยกกำลัง (ขวา→ซ้าย)
3.  * / // %           คูณ หาร
4.  + −                บวก ลบ
5.  < <= > >= == !=    เปรียบเทียบ
6.  not
7.  and
8.  or

# ลำดับเท่ากัน → ซ้ายไปขวา
# (ยกเว้น ** ที่ขวาไปซ้าย)
range() — ไม่รวมตัวสุดท้ายเสมอ
range(5)          # 0 1 2 3 4
range(1, 5)       # 1 2 3 4
range(1, n+1)     # 1 ... n  ← อยากถึง n
range(0, 10, 2)   # 0 2 4 6 8
range(5, 0, -1)   # 5 4 3 2 1
ค่าเริ่มต้นตัวสะสม
บวก   → 0
คูณ   → 1   ⚠️ ไม่ใช่ 0!
หา max → ค่าต่ำมาก (-1 หรือตัวแรก)
หา min → ค่าสูงมาก
flag  → True แล้วเปลี่ยนเป็น False

10 จุดหลอกเสียคะแนนฟรี (1–5)

① input() คืน string เสมอ
   a = input(); b = input()
   a + b  →  ต่อข้อความ! ("10"+"20" = "1020")
   ต้อง int(input()) หรือ float(input()) ก่อนคำนวณ

② range ไม่รวมตัวสุดท้าย
   range(1, 5) → 1,2,3,4  (ไม่มี 5!)
   อยากถึง n → range(1, n+1)

③ −5 % 2 = 1 (ไม่ใช่ −1)
   Python: % มีเครื่องหมายตามตัวหาร
   และ // ปัดลงเสมอ (−7//2 = −4)

④ int(3.9) = 3 (ตัดทิ้ง ไม่ปัด)
   อยากปัดใช้ round(3.9) = 4

⑤ เรียงเงื่อนไข elif ผิดลำดับ
   if s>=60: "C" / elif s>=80: "A"  → คะแนน 90 ได้ "C"!
   ต้องเรียงแคบไปกว้าง (80 → 70 → 60)

10 จุดหลอกเสียคะแนนฟรี (6–10)

⑥ ลืมโคลอน : ท้าย if / for / while
   if x > 0        ❌ SyntaxError
   if x > 0:       ✓

⑦ Indentation ผิดชั้น
   บรรทัดที่เยื้องเท่ากัน = block เดียวกัน
   print() ที่ไม่เยื้อง = อยู่นอก if/for → ทำงานเสมอ

⑧ Python ไม่มี ++ และ −−
   x++     ❌ SyntaxError
   x += 1  ✓

⑨ = กับ == คนละตัว
   x = 5   กำหนดค่า
   x == 5  เปรียบเทียบ  ·  if x = 5: ❌ SyntaxError

⑩ while ลืมเปลี่ยนค่าตัวแปรเงื่อนไข
   i = 0
   while i < 5:
       print(i)      ← ลืม i += 1 → infinite loop!
คืนก่อนสอบอ่านสองหน้านี้รอบเดียวพอ — สิบข้อนี้คือจุดที่เสียคะแนนโดยไม่จำเป็น ทั้งที่เข้าใจเนื้อหาแล้ว
Cheat Sheet · โค้ดท่องจำ

โค้ด 5 ท่า — เขียนได้จากความจำ = ข้อเขียนโปรแกรมผ่าน

# ① รับค่า → คำนวณ → แสดง
r = float(input("รัศมี: "))
area = 3.14159 * r ** 2
print(f"พื้นที่ = {area:.2f}")

# ② ตัดสินใจหลายทาง (elif)
s = int(input())
if s >= 80:   print("A")
elif s >= 70: print("B")
elif s >= 60: print("C")
else:         print("F")

# ③ Counting loop + สะสม
total = 0
for i in range(1, n+1):
    total += i
print(total)
# ④ Sentinel loop (รับจนเจอค่าหยุด)
total = 0
n = int(input("เลข (0=จบ): "))
while n != 0:
    total += n
    n = int(input("เลข (0=จบ): "))
print(total)
# ⚠️ รับค่า 2 ที่! ก่อนลูป + ท้ายลูป

# ⑤ ลูป + if (นับ/หาสุด)
count = 0
mx = -1
for i in range(5):
    x = int(input())
    if x % 2 == 0:
        count += 1
    if x > mx:
        mx = x
print(count, mx)
ทดสอบตัวเอง: ปิดจอ เขียนทั้ง 5 ท่าลงกระดาษใน 15 นาที — ผ่าน = ข้อเขียนโปรแกรมของ midterm พร้อมแล้ว เพราะโจทย์ส่วนใหญ่คือการผสม 5 ท่านี้

ข้อสุดท้าย — ผสมทุกบท

total = 0
for i in range(1, 6):
    if i % 2 == 0:
        total += i
    else:
        total -= i
print(total)
A 15
B -3
C 3
D 0
range(1,6) → i = 1,2,3,4,5   ·   คู่ = บวก · คี่ = ลบ

i=1 คี่ → 0−1 = −1
i=2 คู่ → −1+2 = 1
i=3 คี่ → 1−3 = −2
i=4 คู่ → −2+4 = 2
i=5 คี่ → 2−5 = −3
