เลขสมบูรณ์ (Perfect Number)

โจทย์: รับจำนวนเต็มบวก n แล้วตรวจสอบว่าเป็น เลขสมบูรณ์ หรือไม่
เลขสมบูรณ์ = จำนวนที่ผลรวมของตัวหารทั้งหมด (ไม่รวมตัวมันเอง) เท่ากับตัวมันเอง
พร้อมแสดงตัวหารที่พบทั้งหมด
ตัวอย่างการทำงาน 1
Enter n: 6 ตัวหาร: 1 2 3 ผลรวม: 6 6 เป็นเลขสมบูรณ์
ตัวอย่างการทำงาน 2
Enter n: 28 ตัวหาร: 1 2 4 7 14 ผลรวม: 28 28 เป็นเลขสมบูรณ์
ตัวอย่างการทำงาน 3
Enter n: 12 ตัวหาร: 1 2 3 4 6 ผลรวม: 16 12 ไม่เป็นเลขสมบูรณ์
ตัวอย่างการทำงาน 4 (เคสขอบ)
Enter n: 1 ตัวหาร: (ไม่มี) ผลรวม: 0 1 ไม่เป็นเลขสมบูรณ์
⏸️ หยุดตรงนี้ก่อน — ลองเดิน STEP 1–3 (อ่านโจทย์ → แตกปัญหา → ผังงาน) ด้วยตัวเองอย่างน้อย 15 นาที แล้วค่อยเลื่อนไปหน้าถัดไป
โจทย์ที่ 1 · วิธีคิด

STEP 1–3: แตกปัญหาและวาดผังงาน

STEP 1 — อ่านโจทย์
  IN : n (จำนวนเต็มบวก)
  OUT: รายการตัวหาร, ผลรวม, ผลสรุป
  เงื่อนไข: "ไม่รวมตัวมันเอง"
           → ตัวหารที่สนใจคือ 1 ถึง n−1

STEP 2 — แตกปัญหา
  ทำด้วยมือกับ n=6:
    6 หาร 1 ลงตัว → 1 เป็นตัวหาร
    6 หาร 2 ลงตัว → 2 เป็นตัวหาร
    6 หาร 3 ลงตัว → 3 เป็นตัวหาร
    6 หาร 4 ไม่ลง → ข้าม
    6 หาร 5 ไม่ลง → ข้าม
    รวม 1+2+3 = 6 = n ✓

  → สิ่งที่ทำซ้ำ = "เช็คว่า i หาร n ลงตัวไหม"
    วน i จาก 1 ถึง n−1  ← ได้ลูปแล้ว!
  → ตัดสินใจ = "ลงตัวไหม" (n % i == 0)
  → สะสม = sum += i
STEP 3 — ผังงาน
⬭ เริ่ม │ ▱ รับ n │ ▭ sum = 0, i = 1 │ ▼ ┌──▶ ◇ i <= n-1 ──เท็จ──┐ │ │ จริง │ │ ◇ n % i == 0 │ │ จริง│ │เท็จ │ │ ▽ แสดง i │ │ │ ▭ sum+=i │ │ │ └──┬┘ │ │ ▭ i = i + 1 │ └──────────┘ │ ▼ ▽ แสดง sum │ ◇ sum == n จริง│ │เท็จ ▽"เป็น" │ ▽"ไม่เป็น" └─┬─┘ ⬭ จบ
STEP 5 — เคสขอบที่ต้องระวัง
  n = 1 → ลูปไม่ทำงานเลย (i=1 > n−1=0)
          sum = 0 ≠ 1 → ไม่เป็น ✓ ถูกต้อง
จุดที่คนพลาด: วน i ถึง n−1 ไม่ใช่ n — เพราะโจทย์บอก "ไม่รวมตัวมันเอง" · ถ้าวนถึง n จะได้ sum เกินเสมอ (n หาร n ลงตัว)

STEP 4: เขียนโค้ด — C และ Python

C 
#include <stdio.h>

int main() {
    int n, i, sum = 0;

    printf("Enter n: ");
    scanf("%d", &n);

    printf("ตัวหาร: ");
    for (i = 1; i <= n - 1; i++) {
        if (n % i == 0) {      /* หารลงตัว */
            printf("%d ", i);
            sum += i;             /* สะสม */
        }
    }
    printf("\nผลรวม: %d\n", sum);

    if (sum == n)
        printf("%d เป็นเลขสมบูรณ์\n", n);
    else
        printf("%d ไม่เป็นเลขสมบูรณ์\n", n);

    return 0;
}

# ตรรกะเหมือนกันเป๊ะ — ต่างแค่ไวยากรณ์
ปรับปรุงให้เร็วขึ้น (ท้าทาย): ตัวหารของ n มาเป็นคู่เสมอ (ถ้า i หารลงตัว แล้ว n/i ก็หารลงตัว) → วนแค่ถึง √n ก็พอ ลดจาก O(n) เหลือ O(√n) · ลองเขียนดู
โจทย์ที่ 2 · โจทย์ + ตัวอย่าง

พีระมิดตัวเลข

โจทย์: รับจำนวนแถว n แล้วแสดงพีระมิดตัวเลขตามรูปแบบด้านล่าง
โดยแถวที่ i จะมีตัวเลข 1 ถึง i และมีช่องว่างนำหน้าเพื่อจัดให้เป็นรูปพีระมิด
ตัวอย่างการทำงาน 1
Enter rows: 4 1 12 123 1234
ตัวอย่างการทำงาน 2
Enter rows: 6 1 12 123 1234 12345 123456
วิเคราะห์รูปแบบ (ทำตารางก่อน!)
แถว iช่องว่างตัวเลข
131
221 2
311 2 3
401 2 3 4
สูตรn − i1 ถึง i
 
# n=4 → แถว 1 มีช่องว่าง 4−1 = 3 ✓
#       แถว 4 มีช่องว่าง 4−4 = 0 ✓
# ได้สูตรแล้ว → เขียนลูปได้ทันที
⏸️ หยุดลองเอง — โจทย์นี้ต้องใช้ ลูปซ้อน 2 ชั้น และลูปในมี 2 ตัว (ช่องว่าง + ตัวเลข) · ตารางด้านขวาให้สูตรมาแล้ว ลองเขียนผังงานดู
โจทย์ที่ 2 · วิธีคิด

STEP 2–3: โครงลูปซ้อนและผังงาน

STEP 2 — แตกปัญหา

  แต่ละแถวทำ 3 อย่างตามลำดับ:
    ① พิมพ์ช่องว่าง (n−i) ตัว
    ② พิมพ์ตัวเลข 1 ถึง i
    ③ ขึ้นบรรทัดใหม่

  ทำซ้ำ n แถว → ลูปนอกวน i = 1..n
  ในแต่ละแถว ① กับ ② ก็วนซ้ำ
    → ลูปใน 2 ตัว (คนละลูป ไม่ซ้อนกัน)

  โครงที่ได้:
    for i in 1..n:
        for s in 1..(n-i):  พิมพ์ " "
        for j in 1..i:      พิมพ์ j
        ขึ้นบรรทัดใหม่
⚠️ จุดที่คนพลาดที่สุด:
  ขึ้นบรรทัดใหม่ต้องอยู่ใน "ลูปนอก"
  ถ้าเผลอใส่ในลูปใน → ทุกตัวเลข
  ขึ้นบรรทัดใหม่ กลายเป็นแนวตั้ง
STEP 3 — ผังงาน
▱ รับ n │ ▭ i = 1 ▼ ┌──▶ ◇ i <= n ──เท็จ──▶ ⬭ จบ │ │ จริง │ ▭ s = 1 │ ▼ │ ┌─▶ ◇ s <= n-i ─เท็จ─┐ │ │ ▽ พิมพ์ " " │ │ └────▭ s = s + 1 │ │ ┌─────────────┘ │ ▭ j = 1 │ ▼ │ ┌─▶ ◇ j <= i ──เท็จ──┐ │ │ ▽ พิมพ์ j │ │ └────▭ j = j + 1 │ │ ┌─────────────┘ │ ▽ ขึ้นบรรทัดใหม่ ← ในลูปนอก! │ │ └──── ▭ i = i + 1
เทคนิคที่ใช้ได้กับโจทย์รูปแบบทุกข้อ: ทำตาราง "แถว i ↔ จำนวนที่ต้องพิมพ์" ก่อนเสมอ — ได้สูตรแล้วเขียนลูปได้ทันที ไม่ต้องเดา

STEP 4: เขียนโค้ด — C และ Python

C 
#include <stdio.h>

int main() {
    int n, i, j, s;

    printf("Enter rows: ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++) {       /* แต่ละแถว */

        for (s = 1; s <= n - i; s++)   /* ช่องว่าง */
            printf(" ");

        for (j = 1; j <= i; j++)       /* ตัวเลข */
            printf("%d", j);

        printf("\n");               /* จบแถว */
    }
    return 0;
}
/* C: printf ไม่ขึ้นบรรทัดให้เอง
   จึงพิมพ์ต่อกันได้เลย
   ต้องใส่ \n เองตอนจบแถว */
PYTHON 
n = int(input("Enter rows: "))

for i in range(1, n+1):        # แต่ละแถว

    for s in range(n - i):        # ช่องว่าง
        print(" ", end='')

    for j in range(1, i+1):     # ตัวเลข
        print(j, end='')

    print()                     # จบแถว
# Python: print ขึ้นบรรทัดให้อัตโนมัติ
# จึงต้องใส่ end='' เพื่อ "ไม่ให้ขึ้น"
# แล้วใช้ print() เปล่าตอนจบแถว
# ← ตรงข้ามกับ C พอดี!
เขียนสั้นแบบ Python
for i in range(1, n+1):

    print(" " * (n-i) + nums)

STEP 2–3: จัดการปัญหา "ลำดับกลับด้าน"

STEP 2 — แตกปัญหา

  ① วนหาร 2 เก็บเศษ จนผลลัพธ์เป็น 0
  ② กลับลำดับเศษ
  ③ แสดงผล

  ปัญหา ② แก้ได้ 3 วิธี:

  วิธี A — เก็บใน array แล้ววนย้อน
     bits[count++] = n % 2
     แล้ว for (i=count-1; i>=0; i--)
     ← ใช้ได้ทั้ง C และ Python

  วิธี B — ต่อ string ไว้ "ข้างหน้า"
     result = str(n%2) + result
     ← สั้นที่สุด แต่ทำได้ง่ายใน Python

  วิธี C — ใช้ recursion
     ← สวยแต่เกินระดับนี้
⚠️ เคสขอบสำคัญ: n = 0
  ลูป while (n > 0) ไม่ทำงานเลย
  → ได้ผลลัพธ์ว่าง!
  ต้องเช็คแยก: ถ้า n == 0 พิมพ์ "0"
STEP 3 — ผังงาน (วิธี A)
▱ รับ n │ ◇ n == 0 ──จริง──▶ ▽ "0" ─▶ จบ │ เท็จ ▭ count = 0 ▼ ┌──▶ ◇ n > 0 ──เท็จ──┐ │ ▭ bits[count] │ │ = n % 2 │ │ ▭ count++ │ │ ▭ n = n / 2 │ └─────────┘ │ ┌───────────┘ ▭ i = count-1 ▼ ┌──▶ ◇ i >= 0 ──เท็จ──▶ ⬭ จบ │ ▽ พิมพ์ bits[i] └──── ▭ i = i - 1 ← วนย้อนกลับ!
บทเรียนของโจทย์นี้: เมื่อ "ได้คำตอบกลับด้าน" — เก็บไว้ก่อนแล้วค่อยวนย้อน · pattern นี้ใช้กับโจทย์กลับ string, กลับตัวเลข, แปลงฐานอื่นๆ ได้หมด

STEP 4: เขียนโค้ด — C และ Python

C 
#include <stdio.h>

int main() {
    int n, i, count = 0;
    int bits[32];              /* int 32 บิตพอ */

    printf("Enter number: ");
    scanf("%d", &n);

    if (n == 0) {              /* เคสขอบ! */
        printf("0 in binary = 0\n");
        return 0;
    }

    int original = n;         /* เก็บไว้แสดงผล */

    while (n > 0) {
        bits[count] = n % 2;   /* เก็บเศษ */
        count++;
        n = n / 2;             /* หารต่อ */
    }

    printf("%d in binary = ", original);
    for (i = count - 1; i >= 0; i--)  /* วนย้อน! */
        printf("%d", bits[i]);
    printf("\n");

    return 0;
}
PYTHON 
n = int(input("Enter number: "))
original = n

if n == 0:                    # เคสขอบ!
    print("0 in binary = 0")
else:
    bits = []
    while n > 0:
        bits.append(n % 2)      # เก็บเศษ
        n = n // 2             # ⚠️ // ไม่ใช่ /

    result = ''
    for i in range(len(bits)-1, -1, -1):  # วนย้อน
        result += str(bits[i])

    print(f"{original} in binary = {result}")
เขียนสั้นแบบ Python (วิธี B)
n = int(input())
result = ''
if n == 0:
    result = '0'
while n > 0:
    result = str(n % 2) + result   # ต่อ "ข้างหน้า"
    n //= 2                       # → ไม่ต้องกลับลำดับ!
print(result)
