ตะลุยโจทย์ — ฝึกคิดแบบโปรแกรมเมอร์
// โจทย์ + ตัวอย่างการทำงาน + ผังงาน + เฉลยทั้ง C และ Python
วิชานี้ต่างจากวิชาอื่นตรงไหน: วิชาอื่นสอน "ไวยากรณ์" — วิชานี้สอน "กระบวนการคิด" ปัญหาของคนเขียนโปรแกรมไม่เป็น มักไม่ใช่จำ syntax ไม่ได้ แต่คือ อ่านโจทย์แล้วไม่รู้จะเริ่มตรงไหน
ทุกโจทย์ที่นี่จึงเดินครบ 5 ขั้น: อ่านโจทย์ → แตกปัญหา → ผังงาน → เขียนโค้ด → ทดสอบ และมีเฉลยทั้งภาษา C และ Python วางคู่กัน เพื่อให้เห็นว่า "ตรรกะเหมือนกัน ต่างแค่ไวยากรณ์"
วิธีใช้ให้ได้ผล: อ่านโจทย์กับตัวอย่างการทำงานแล้ว ปิดจอ ลองทำเองก่อน อย่างน้อย 15 นาที ค่อยเปิดดูวิธีคิด — เปิดเฉลยเลยจะได้แค่ "เข้าใจ" แต่ไม่ได้ "ทำเป็น"
STEP 1
อ่านโจทย์
แยกให้ออกว่า input คืออะไร output คืออะไร เงื่อนไขมีอะไรบ้าง
STEP 2
แตกปัญหา
ซอยเป็นขั้นย่อยที่ทำได้ทีละอย่าง + หา pattern ที่ซ้ำ
STEP 3
วาดผังงาน
เขียนลำดับเป็นภาพก่อน — ยังไม่ต้องคิดถึง syntax
STEP 4
เขียนโค้ด
แปลงกล่องในผังงานเป็นบรรทัดโค้ดทีละกล่อง
STEP 5
ทดสอบ
ลองกับตัวอย่างที่โจทย์ให้ + เคสขอบ (0, ติดลบ, ว่าง)
🧗
ชุดโจทย์ — ไล่ระดับจากง่ายไปยาก
แต่ละชุดมี 3 โจทย์ · ทุกโจทย์มีตัวอย่างการทำงาน ผังงาน และเฉลย C + Python
🧠→
เริ่มที่นี่
กระบวนการคิด 5 ขั้น
วิธีอ่านโจทย์ให้แตก, เทคนิคแตกปัญหา, การหา pattern, เคสขอบที่ต้องเช็ค และเทคนิค trace หาบั๊ก
อ่านก่อนลงมือทำโจทย์ — เป็นเครื่องมือที่ใช้ตลอดทั้งวิชา
