บทที่ 6 · เกริ่นนำ
Graph — โหนดเชื่อมกันได้อิสระ
Tree คือ Graph ชนิดพิเศษที่ห้ามมีวงวน (cycle) และแต่ละโหนดมีพ่อได้แค่ 1 คน — Graph ทั่วไปไม่มีกฎนี้ เชื่อมกันได้ตามใจ
คำศัพท์ความหมาย
Vertex (node)จุดในกราฟ
Edgeเส้นเชื่อมระหว่าง 2 vertex
Directededge มีทิศทาง (A→B ไม่ใช่ B→A)
Undirectededge ไม่มีทิศทาง (A-B ไปมาได้)
Weightededge มีค่าน้ำหนัก (เช่น ระยะทาง)
💡 ตัวอย่างในชีวิตจริง
เครือข่ายสาขาธนาคาร, เส้นทางการบิน, เพื่อนใน Facebook (ใครเชื่อมกับใคร), แผนที่ถนน — ทุกอย่างที่ "เชื่อมกันแบบไม่เป็นลำดับชั้น" คือ Graph
UNDIRECTED GRAPH ตัวอย่าง
vertex: A,B,C,D — edge: A-B, A-C, A-D, B-D, C-D
บทที่ 6 · Representation
Adjacency Matrix — ตาราง 2 มิติ
ใช้ตาราง n×n เก็บว่า vertex ไหนเชื่อมกับ vertex ไหน — เช็คว่าเชื่อมกันไหมเร็ว O(1) แต่เปลือง memory ถ้า vertex มาก
นิยามด้วย 2D Array
/* 4 vertex: A=0, B=1, C=2, D=3 */ int adj[4][4] = {0}; void addEdge(int u, int v) { adj[u][v] = 1; adj[v][u] = 1; /* undirected ต้องเซ็ตทั้งคู่ */ } addEdge(0,1); addEdge(0,2); addEdge(0,3); addEdge(1,3); addEdge(2,3); /* เช็คว่า A เชื่อมกับ B ไหม — เร็ว O(1) */ if (adj[0][1]) printf("A-B เชื่อมกัน\n");
Adjacency Matrix — A,B,C,D
ABCD
A0111
B1001
C1001
D1110
⚠️ เปลือง memory ถ้า edge น้อย
vertex 1000 ตัว แต่เชื่อมกันแค่ 10 เส้น — Matrix ยังใช้ 1000×1000 = 1,000,000 ช่อง ทั้งที่ของจริงมีแค่ 20 ช่องที่เป็น 1 (เปลืองมาก)
บทที่ 6 · Representation
Adjacency List — Linked List ของแต่ละ vertex
แต่ละ vertex เก็บ Linked List ของเพื่อนบ้านที่เชื่อมด้วย — ประหยัด memory กว่า Matrix มาก ถ้า edge ไม่หนาแน่น (ใช้ Linked List จากบทที่ 1 ตรงๆ)
นิยามด้วย array of Linked List
struct AdjNode { int vertex; struct AdjNode *next; }; struct AdjNode *adjList[4] = {NULL}; /* 4 vertex */ void addEdge(int u, int v) { struct AdjNode *n1 = (struct AdjNode *)malloc(sizeof(struct AdjNode)); n1->vertex = v; n1->next = adjList[u]; adjList[u] = n1; /* insertHead ของบทที่ 1 */ struct AdjNode *n2 = (struct AdjNode *)malloc(sizeof(struct AdjNode)); n2->vertex = u; n2->next = adjList[v]; adjList[v] = n2; /* undirected ต้องเพิ่มทั้งสองทาง */ }
Adjacency List ของ graph เดิม
adjList[A] → D → C → B → NULL
adjList[B] → D → A → NULL
adjList[C] → D → A → NULL
adjList[D] → C → B → A → NULL
💡 เมื่อไหร่ใช้ Matrix vs List
Matrix: เช็คว่าเชื่อมกันไหมบ่อยๆ, vertex น้อย
List: vertex มาก แต่ edge น้อย (sparse graph) — ใช้บ่อยกว่าในงานจริง
บทที่ 6 · BFS
BFS — Breadth-First Search
เดินทีละ "ชั้น" ก่อน เยี่ยมเพื่อนบ้านตรงทั้งหมดก่อนไปชั้นถัดไป — ใช้ Queue จากบทที่ 4 เป็นเครื่องมือหลัก
BFS ด้วย Queue + visited array
void bfs(int start, int n) { int visited[100] = {0}; int queue[100], front=0, rear=-1; visited[start] = 1; queue[++rear] = start; /* enqueue */ while (front <= rear) { int cur = queue[front++]; /* dequeue */ printf("%d ", cur); struct AdjNode *p = adjList[cur]; while (p != NULL) { if (!visited[p->vertex]) { visited[p->vertex] = 1; queue[++rear] = p->vertex; /* enqueue */ } p = p->next; } } }
⚠️ ทำไมต้องมี visited array
Graph มี cycle (วงวน) ได้ — ถ้าไม่จำว่าเยี่ยมโหนดไหนไปแล้ว จะวนซ้ำไม่จบ (infinite loop) ต่างจาก Tree ที่ไม่มี cycle เลยไม่ต้องกัน
💡 ใช้ BFS ตอนไหน
หาทางที่ "สั้นที่สุด" เมื่อทุก edge มีน้ำหนักเท่ากัน เช่น หาจำนวนสาขาขั้นต่ำที่ต้องผ่านจากสาขา A ไปสาขา B
บทที่ 6 · DFS
DFS — Depth-First Search
เดินลงไปให้ลึกที่สุดก่อน แล้วค่อยถอยมาลองทางอื่น — ใช้ recursion (หรือ Stack จากบทที่ 3) เป็นเครื่องมือหลัก
DFS แบบ recursive
int visited[100] = {0}; void dfs(int v) { visited[v] = 1; printf("%d ", v); struct AdjNode *p = adjList[v]; while (p != NULL) { if (!visited[p->vertex]) dfs(p->vertex); /* เดินลงไปให้ลึกก่อน */ p = p->next; } } /* เรียกใช้ */ dfs(0); /* เริ่มจาก vertex A */
BFSDFS
เครื่องมือQueueStack / Recursion
เดินแบบกว้างก่อน (ทีละชั้น)ลึกก่อน (จนสุดทาง)
ใช้หาทางสั้นที่สุด (unweighted)เช็คว่ามี cycle, เดินครบทุก vertex
💡 DFS แบบ recursive = DFS แบบ Stack
เวลาเรียก function ตัวเอง (recursion) ระบบใช้ "call stack" จัดการให้อัตโนมัติ — DFS ใช้หลักการเดียวกับ Stack บทที่ 3 เป๊ะ
บทที่ 6 · Use Case
🏦 Use Case จริง — เครือข่ายสาขาธนาคาร
ธนาคารมีสาขาเชื่อมต่อกันผ่านระบบโอนเงินภายใน — หาว่าสาขา A โอนเงินไปสาขา B ได้ผ่านกี่สาขา (ทางสั้นที่สุด) ด้วย BFS
โจทย์ระบบธนาคาร
หาเส้นทางสั้นที่สุดระหว่างสาขา
สาขาเชื่อมกันเป็น Graph (มีระบบเชื่อมข้อมูลตรงกัน) — BFS หาว่าต้องผ่านกี่สาขาถึงจะเชื่อมจาก A ไป B
ทำไมใช้ BFS ไม่ใช่ DFS
BFS เดินทีละชั้น การันตีว่าเจอ B ครั้งแรกคือทางที่สั้นที่สุดเสมอ (เมื่อทุก edge น้ำหนักเท่ากัน) ส่วน DFS อาจเดินทางยาวก่อนเจอ
หาระยะทางสั้นที่สุดระหว่างสาขา
int shortestPath(int start, int target, int n) { int visited[100] = {0}, dist[100] = {0}; int queue[100], front=0, rear=-1; visited[start] = 1; queue[++rear] = start; while (front <= rear) { int cur = queue[front++]; if (cur == target) return dist[cur]; struct AdjNode *p = adjList[cur]; while (p != NULL) { if (!visited[p->vertex]) { visited[p->vertex] = 1; dist[p->vertex] = dist[cur] + 1; queue[++rear] = p->vertex; } p = p->next; } } return -1; /* ไม่เชื่อมกันเลย */ }
บทที่ 6 · Think!
คิดก่อน เขียน
Graph รวมทุกอย่างที่เรียนมา — Queue, Stack, recursion ใช้พร้อมกันได้
1. Tree คือ Graph แบบไหนเป็นพิเศษ?
💡 Tree คือ Graph ที่ไม่มี cycle และทุกโหนด (ยกเว้น root) มีพ่อได้แค่ 1 คน
2. ถ้าลืมเช็ค visited ใน BFS/DFS ของ graph ที่มี cycle จะเกิดอะไร?
💡 วนซ้ำไม่จบ (infinite loop) เพราะเดินกลับไปที่ vertex เดิมได้ตลอด
3. graph: A-B, A-C, B-D, C-D — BFS จาก A จะเยี่ยมตามลำดับไหน?
💡 A ก่อน (เริ่ม) แล้วเพื่อนบ้านตรงของ A คือ B, C แล้วค่อยไป D (เพื่อนของ B/C) → A B C D
4. ทำไม Adjacency List ประหยัด memory กว่า Matrix เมื่อ edge น้อย?
💡 List เก็บแค่ edge ที่มีจริงเป็น node ใน Linked List ส่วน Matrix ต้องเก็บทุกคู่ vertex แม้ไม่เชื่อมกัน (ส่วนใหญ่เป็น 0)
5. BFS การันตีทางสั้นที่สุดได้เมื่อไหร่ ถ้า edge มีน้ำหนักไม่เท่ากันยังใช้ได้ไหม?
💡 BFS การันตีทางสั้นที่สุดเฉพาะตอน edge ทุกเส้นน้ำหนักเท่ากัน ถ้าน้ำหนักต่างกันต้องใช้ algorithm อื่น เช่น Dijkstra (เรื่องขั้นสูงกว่านี้)
