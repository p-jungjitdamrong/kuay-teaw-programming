บทที่ 3 · เกริ่นนำ
LIFO — Last In, First Out
Stack เข้าออกได้ที่ปลายเดียว เรียกว่า "top" — ของที่ใส่ทีหลังจะถูกหยิบออกก่อนเสมอ เหมือนกองหนังสือบนโต๊ะ
Operationทำอะไร
push(x)ใส่ x ไว้บนสุด (top)
pop()เอาตัวบนสุดออก และคืนค่ามัน
peek() / top()ดูค่าบนสุด แต่ไม่เอาออก
isEmpty()เช็คว่า stack ว่างไหม
💡 ตัวอย่างในชีวิตจริง
กองจานในร้านก๋วยเตี๋ยว — ล้างจานวางซ้อนกัน หยิบใช้จากบนสุดก่อนเสมอ, ปุ่ม Undo (Ctrl+Z) ในโปรแกรม, ปุ่ม Back ของเบราว์เซอร์
STACK หลัง push(10), push(20), push(30)
← top
10
20
30
pop() จะได้ 30 ก่อน (ตัวที่เข้าหลังสุด)
บทที่ 3 · Implementation
Stack ด้วย Array — ง่ายและเร็ว
ใช้ array + ตัวแปร top เก็บ index บนสุด — push/pop แค่ขยับ top แล้วอ่าน/เขียนค่าที่ index นั้น เร็ว O(1) ทุก operation
นิยาม Stack ด้วย Array
#define MAXSIZE 100 int stack[MAXSIZE]; int top = -1; /* -1 หมายถึง stack ว่าง */ void push(int val) { if (top == MAXSIZE - 1) { printf("Stack overflow!\n"); return; } top++; stack[top] = val; }
pop และ peek
int pop() { if (top == -1) { printf("Stack underflow!\n"); return -1; } return stack[top--]; /* อ่านค่าก่อน แล้วลด top */ } int peek() { if (top == -1) return -1; return stack[top]; /* อ่านอย่างเดียว ไม่ลด top */ } int isEmpty() { return top == -1; }
⚠️ Stack Overflow / Underflow
push เกิน MAXSIZE = overflow, pop ตอน stack ว่าง = underflow ต้องเช็คทุกครั้งก่อนทำ
บทที่ 3 · Implementation
Stack ด้วย Linked List — ไม่จำกัดขนาด
push ที่หัวลิสต์ (insertHead) คือ push ของ stack, pop ที่หัวลิสต์คือ pop ของ stack — ใช้ pattern จากบทที่ 1 ตรงๆ
push = insertHead
struct Node { int data; struct Node *next; }; struct Node *top = NULL; void push(int val) { struct Node *n = (struct Node *)malloc(sizeof(struct Node)); n->data = val; n->next = top; /* ชี้ไปที่ top เดิม */ top = n; /* top ใหม่คือโหนดนี้ */ }
pop = deleteHead + free
int pop() { if (top == NULL) { printf("Stack underflow!\n"); return -1; } struct Node *tmp = top; int val = tmp->data; top = top->next; /* ขยับ top ไปตัวถัดไป */ free(tmp); /* คืน memory โหนดเดิม */ return val; }
💡 เทียบกับ Array
Array เร็วกว่าเล็กน้อยแต่ขนาด fixed, Linked List ไม่จำกัดขนาดแต่ต้อง malloc/free ทุกครั้ง — เลือกตามสถานการณ์
บทที่ 3 · Application
เช็ควงเล็บถูกคู่ไหม — Balanced Parentheses
โจทย์คลาสสิกที่สุดของ Stack — เจอวงเล็บเปิด push เข้า stack, เจอวงเล็บปิด pop ออกมาเทียบว่าคู่กันไหม
isBalanced — เช็คด้วย Stack
int isBalanced(char *expr) { int i; top = -1; /* reset stack */ for (i = 0; expr[i] != '\0'; i++) { if (expr[i] == '(' || expr[i] == '{') push(expr[i]); else if (expr[i] == ')' || expr[i] == '}') { if (isEmpty()) return 0; /* ปิดเกิน */ pop(); } } return isEmpty(); /* ต้องว่างพอดี = คู่ครบ */ }
Trace: "{(a+b)}"
เจอ { → push → stack: [ { ]
เจอ ( → push → stack: [ { ( ]
a, +, b → ไม่ทำอะไร
เจอ ) → pop → stack: [ { ]
เจอ } → pop → stack: [ ]
จบ string, stack ว่าง → balanced ✓
❌ กรณีที่ stack ไม่ว่างตอนจบ
เช่น "((a)" — มี ( เหลือใน stack ตอนจบ string แปลว่าวงเล็บเปิดเกิน ไม่ balanced
บทที่ 3 · Application
คำนวณ Postfix — เครื่องคิดเลขแบบ Stack
Postfix (Reverse Polish) เขียน operator ไว้หลังเลข เช่น "3 4 +" คำนวณง่ายมากด้วย Stack — เจอเลข push, เจอ operator pop 2 ตัวมาคำนวณแล้ว push ผลลัพธ์กลับ
evalPostfix — "3 4 + 2 *" = 14
int evalPostfix(char tokens[][5], int n) { top = -1; for (int i = 0; i < n; i++) { if (isdigit(tokens[i][0])) push(atoi(tokens[i])); else { int b = pop(); /* ตัวขวา pop ออกก่อน */ int a = pop(); /* ตัวซ้าย pop ทีหลัง */ if (tokens[i][0]=='+') push(a+b); if (tokens[i][0]=='*') push(a*b); } } return pop(); /* ผลลัพธ์สุดท้ายอยู่บน stack */ }
Trace: "3 4 + 2 *"
push 3 → stack: [3]
push 4 → stack: [3, 4]
เจอ + → pop 4, pop 3, push 3+4=7 → stack: [7]
push 2 → stack: [7, 2]
เจอ * → pop 2, pop 7, push 7*2=14 → stack: [14]
จบ → ผลลัพธ์ = 14
⚠️ ลำดับ pop สำคัญมากกับ - และ /
pop ตัวแรกได้ b (ตัวขวา/ตัวหลัง), pop ตัวสองได้ a (ตัวซ้าย/ตัวก่อน) ต้องคำนวณ a - b ไม่ใช่ b - a
บทที่ 3 · Use Case
🏦 Use Case จริง — Undo การโอนเงิน
แอปธนาคารต้องยกเลิกธุรกรรมล่าสุดได้ — เก็บประวัติเป็น Stack เพื่อให้ "ตัวล่าสุด" อยู่บนสุดเสมอ แล้ว pop ออกเมื่อกด undo
โจทย์ระบบธนาคาร
Undo ธุรกรรมล่าสุดด้วย Stack
ทุกธุรกรรม push เข้า stack — กดปุ่ม Undo คือ pop ธุรกรรมล่าสุดออกมาแล้วย้อนผลของมัน
ทำไมต้องเป็น Stack ไม่ใช่ Queue
Undo ต้องยกเลิก "รายการล่าสุดก่อนเสมอ" — ตรงกับ LIFO ของ Stack พอดี ถ้าใช้ Queue จะ undo รายการแรกสุดซึ่งผิดความหมาย
ระบบ Undo ธุรกรรม
struct Txn { char type[10]; double amount; }; struct Txn stack[100]; int top = -1; void doTransfer(double amt) { top++; strcpy(stack[top].type, "transfer"); stack[top].amount = amt; printf("โอนเงิน %.2f บาท\n", amt); } void undo() { if (top == -1) { printf("ไม่มีรายการให้ undo\n"); return; } printf("ยกเลิก %s %.2f บาท\n", stack[top].type, stack[top].amount); top--; /* pop ออกจาก stack */ }
บทที่ 3 · Think!
คิดก่อน เขียน
Stack เข้าใจง่ายแต่พลาดบ่อยตรง edge case (overflow/underflow) — ฝึก trace ให้คล่อง
1. push(1), push(2), push(3), pop(), pop() — เหลืออะไรบน stack?
💡 pop เอา 3 ออกก่อน แล้ว pop เอา 2 ออก เหลือแค่ 1 บน stack
2. ทำไม isBalanced ต้องเช็ค isEmpty() ทั้งตอนเจอวงเล็บปิด และตอนจบ string?
💡 เช็คตอนเจอ ) ป้องกันปิดเกิน (pop จาก stack ว่าง), เช็คตอนจบป้องกันเปิดเกิน (มีของเหลือใน stack)
3. evalPostfix ของ "5 1 2 + 4 * + 3 -" ผลลัพธ์คือเท่าไหร่?
💡 1+2=3, 3*4=12, 5+12=17, 17-3=14 — ลอง trace ทีละ token จะได้ 14
4. Stack ด้วย Array push เกิน MAXSIZE จะเกิดอะไร?
💡 Stack overflow — ถ้าไม่เช็คเงื่อนไขก่อน จะเขียนทับ memory นอก array (undefined behavior)
5. ทำไม push ของ Stack แบบ Linked List ใช้ pattern เดียวกับ insertHead ของบทที่ 1?
💡 เพราะ "top" ของ Stack ก็คือ "head" ของ Linked List นั่นเอง — push คือเพิ่มที่หัว, pop คือลบที่หัว
