บทที่ 4 · เกริ่นนำ
FIFO — First In, First Out
Queue เข้าทางหนึ่ง (rear/back) ออกอีกทาง (front) — ของที่เข้าก่อนจะถูกเอาออกก่อนเสมอ ตรงข้ามกับ Stack
Operationทำอะไร
enqueue(x)ใส่ x เข้าทางท้าย (rear)
dequeue()เอาตัวหน้าสุด (front) ออก
peek/front()ดูตัวหน้าสุด แต่ไม่เอาออก
isEmpty()เช็คว่า queue ว่างไหม

บทที่ 4 · Implementation
Queue ด้วย Array — ใช้ 2 ตัวแปร front/rear
ต่างจาก Stack ที่ใช้ index เดียว (top) — Queue ต้องเก็บ 2 ตำแหน่ง เพราะเข้า-ออกคนละด้าน
นิยาม Queue ด้วย Array
#define MAXSIZE 100 int queue[MAXSIZE]; int front = 0, rear = -1, count = 0; void enqueue(int val) { if (count == MAXSIZE) { printf("Queue full!\n"); return; } rear++; queue[rear] = val; count++; }
dequeue
int dequeue() { if (count == 0) { printf("Queue empty!\n"); return -1; } int val = queue[front]; front++; /* เลื่อน front ไปข้างหน้า */ count--; return val; }
❌ ปัญหา: Array แบบนี้ "เปลือง" memory
ทุกครั้งที่ dequeue, front เลื่อนไปข้างหน้าเรื่อยๆ ไม่กลับมาใช้ index เดิม — สุดท้าย rear ชนขอบ array ทั้งที่ของจริงในคิวอาจมีไม่มาก
บทที่ 4 · Circular Queue
Circular Queue — วน index กลับมาใช้ใหม่
ใช้ modulo (%) ให้ index วนกลับมาที่ 0 เมื่อถึงขอบ array — ไม่เปลืองช่องที่ dequeue ไปแล้ว
enqueue / dequeue แบบวน (modulo)
int queue[MAXSIZE]; int front = 0, rear = -1, count = 0; void enqueue(int val) { if (count == MAXSIZE) return; rear = (rear + 1) % MAXSIZE; /* วนกลับ 0 ถ้าเกินขอบ */ queue[rear] = val; count++; } int dequeue() { if (count == 0) return -1; int val = queue[front]; front = (front + 1) % MAXSIZE; /* วนกลับ 0 เช่นกัน */ count--; return val; }
MAXSIZE=5, rear ชน 4 แล้ววนกลับ 0

บทที่ 4 · Implementation
Queue ด้วย Linked List — ไม่จำกัดขนาด
เก็บ front กับ rear pointer — enqueue ต่อท้าย (เหมือน insertTail), dequeue เอาหัวออก (เหมือน deleteHead)
enqueue = insertTail
struct Node { int data; struct Node *next; }; struct Node *front = NULL, *rear = NULL; void enqueue(int val) { struct Node *n = (struct Node *)malloc(sizeof(struct Node)); n->data = val; n->next = NULL; if (rear == NULL) { front = rear = n; return; } rear->next = n; rear = n; }
dequeue = deleteHead + free
int dequeue() { if (front == NULL) { printf("Queue empty!\n"); return -1; } struct Node *tmp = front; int val = tmp->data; front = front->next; if (front == NULL) rear = NULL; /* คิวว่างแล้ว */ free(tmp); return val; }
บทที่ 4 · Deque
Deque — Double-Ended Queue
Deque เข้า-ออกได้ทั้ง 2 ฝั่ง (หน้าและท้าย) — รวมความสามารถของ Stack และ Queue ไว้ในตัวเดียว สร้างจาก Doubly Linked List ของบทที่ 2
Operationทำอะไร
pushFront(x)ใส่ x ที่หน้า
pushBack(x)ใส่ x ที่ท้าย
popFront()เอาตัวหน้าออก
popBack()เอาตัวท้ายออก
💡 Deque = Doubly List ที่เก็บ head + tail
pushFront/popFront ใช้ pattern เดียวกับ insertHead/deleteHead ของบทที่ 1, pushBack/popBack ใช้ pattern เดียวกับ insertTail ของบทที่ 2
pushFront / pushBack ด้วย Doubly List
struct DNode *head=NULL, *tail=NULL; void pushBack(int val) { struct DNode *n = (struct DNode *)malloc(sizeof(struct DNode)); n->data = val; n->next = NULL; if (tail == NULL) { n->prev=NULL; head=tail=n; return; } n->prev = tail; tail->next = n; tail = n; } /* pushFront ก็คือ insertHead ของบทที่ 2 นั่นเอง */
บทที่ 4 · Use Case
🏦 Use Case จริง — คิวรอคิวที่ตู้ ATM
ลูกค้าต่อแถวรอใช้ ATM — มาก่อนได้ใช้ก่อนเสมอ ตรงกับหลัก FIFO ของ Queue พอดี
โจทย์ระบบธนาคาร
จัดคิวลูกค้ารอใช้ ATM
ลูกค้าต่อแถว enqueue เข้าคิว ระบบเรียกคิวถัดไปด้วย dequeue — รับประกันว่ามาก่อนได้ใช้ก่อน
ทำไมต้องเป็น Queue ไม่ใช่ Stack
ถ้าใช้ Stack คนที่มาคิวล่าสุดจะได้ใช้ก่อน (LIFO) ซึ่งไม่ fair — ต้องใช้ Queue (FIFO) เพื่อความเป็นธรรมตามลำดับมาก่อน-หลัง
ระบบคิว ATM
struct Customer { char name[30]; struct Customer *next; }; struct Customer *front=NULL, *rear=NULL; void joinQueue(char *name) { struct Customer *n = (struct Customer *)malloc(sizeof(struct Customer)); strcpy(n->name, name); n->next = NULL; if (rear == NULL) front = rear = n; else { rear->next = n; rear = n; } printf("%s เข้าคิวแล้ว\n", name); } void serveNext() { if (front == NULL) { printf("ไม่มีคิว\n"); return; } printf("เรียก: %s\n", front->name); struct Customer *tmp = front; front = front->next; if (front == NULL) rear = NULL; free(tmp); }
บทที่ 4 · Think!
คิดก่อน เขียน
เทียบ Stack กับ Queue บ่อยๆ จะช่วยให้เข้าใจทั้งสองแน่นขึ้น
1. enqueue(1), enqueue(2), enqueue(3), dequeue() — ได้ค่าอะไร?
💡 1 — เพราะ Queue เป็น FIFO ตัวที่เข้าก่อนสุด (1) จะออกก่อนสุด
2. ทำไม Queue ด้วย Array แบบไม่วน (ไม่ใช้ modulo) จึง "เปลือง" memory?
💡 front เลื่อนไปข้างหน้าเรื่อยๆ ไม่ย้อนกลับมาใช้ index เดิม สุดท้าย rear ชนขอบ array ทั้งที่ช่องด้านหน้ายังว่างอยู่
3. ใน Circular Queue ทำไม front==rear เพียงอย่างเดียวบอกไม่ได้ว่า queue ว่างหรือเต็ม?
💡 ทั้งสองกรณีทำให้ front กับ rear เท่ากันได้ ต้องใช้ตัวแปร count แยกแยะ
4. Deque ต่างจาก Queue ปกติยังไง?
💡 Queue ปกติเข้าทางเดียว (rear) ออกทางเดียว (front) แต่ Deque เข้า-ออกได้ทั้งสองฝั่ง
5. ทำไม dequeue ของ Linked List ต้องเช็ค if (front==NULL) rear=NULL;?
💡 ถ้า dequeue โหนดสุดท้ายออก front จะเป็น NULL แต่ rear ยังชี้ไปที่โหนดที่ free ไปแล้ว (dangling pointer) ต้องเคลียร์ rear ด้วย

บทที่ 4 · สรุป
เก่ง Queue แล้ว!
เข้าใจ FIFO, Circular Queue และ Deque — ขั้นต่อไปคือ Binary Tree ที่ไม่ใช่โครงสร้างเชิงเส้นแล้ว
1

2
Circular Queue — ใช้ modulo วน indexไม่เปลือง memory เหมือน array ตรงๆ
3
Linked List Queue — enqueue=insertTailไม่จำกัดขนาด
4
Deque — เข้าออกได้ 2 ฝั่งรวม Stack+Queue ในตัวเดียว
