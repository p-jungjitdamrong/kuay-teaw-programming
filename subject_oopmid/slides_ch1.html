ติวบทที่ 1 · ทฤษฎี

Java คืออะไร — ตอบตามสไลด์อาจารย์

ประวัติ + จุดขาย (ปรนัยสายจำ)
พัฒนาโดย: Sun Microsystems (1991)
แรงบันดาลใจ: platform-independent
  สำหรับ embedded systems
  → ภายหลังปรับใช้กับ www

จุดขายที่สไลด์ list ไว้:
• ง่ายที่จะเรียนและเขียน
• Pure object-oriented
• Portable (เขียนครั้งเดียว รันได้ทุกที่)
• Multithreading, networking, security
• Versatile: desktop / server /
  browser / embedded
Java = มากกว่าภาษา → "Platform"
Java Platform ประกอบด้วย:

① ภาษา Java (ตัว syntax)

② JVM — Java Virtual Machine
   "เครื่องสมมติ" ที่ทำงานเหมือน
   คอมพิวเตอร์จริง (จัดการชุดคำสั่ง
   และหน่วยความจำ)

③ Java API — library สำเร็จรูป
   เช่น Lists, Maps, Queues,
   Image I/O, เสียง

← สามส่วนนี้คือคำตอบข้อ
  "Java platform ประกอบด้วยอะไร"
จุดที่นิยมถาม: "ทำไม Java จึง platform-independent?" → เพราะ compile เป็น bytecode (ไม่ใช่ machine code) แล้วให้ JVM ของแต่ละเครื่องเป็นตัวแปลอีกที — โค้ดเดียวรันได้ทุก OS ที่มี JVM
ติวบทที่ 1 · หัวใจทฤษฎี

เส้นทางของโค้ด: .java → .class → รัน

flow ที่ต้องวาดได้
HelloWorld.java   (source code)
      │
      │  javac  ← compiler
      ▼
HelloWorld.class  (bytecode)
      │
      │  java   ← เรียก JVM มาแปล
      ▼            (interpreter)
ผลลัพธ์บนหน้าจอ

/* bytecode "เหมือนกันทุกเครื่อง"
   JVM "ต่างกันตามเครื่อง"
   ← ประโยคนี้คือคำตอบหลายข้อ */
ข้อเสียที่สไลด์เขียนไว้ (ถามได้)
/* "interpreted bytecode ทำงาน
   ช้ากว่า machine code
   โดยเฉพาะเมื่อโค้ดซับซ้อน"

   ← ข้อเสียของแนวทาง JVM
   แลกกับความ portable

   เทียบ C: compile ตรงเป็น
   machine code → เร็วกว่า
   แต่ต้อง compile ใหม่ทุก platform */

คำสั่งที่ใช้จริง (Lab 1):
javac HelloWorld.java  → ได้ .class
java  HelloWorld       → รัน
java -jar app.jar      → รันไฟล์ jar
เขียนตอบสั้นๆ ให้ครบ: javac = compiler แปลง .java → .class (bytecode) · java = loader เรียก JVM รัน bytecode — สลับหน้าที่สองตัวนี้คือจุดหลอกอันดับหนึ่งของบท
ติวบทที่ 1 · แยกศัพท์

JVM ⊂ JRE ⊂ JDK — สามวงกลมซ้อนกัน

นิยามตามสไลด์
JVM  = เครื่องสมมติที่รัน bytecode

JRE  = JVM + Java API
       "ใช้สำหรับ รัน โปรแกรม"
       (รัน .class หรือ .jar)

JDK  = JRE + เครื่องมือพัฒนา:
       java    (loader)
       javac   (compiler)
       jar     (archiver)
       javadoc (documentation)
       "ใช้สำหรับ พัฒนา โปรแกรม"
Java Editions (สไลด์มีตาราง)
Java SE  Standard Edition
         → พื้นฐาน applications
Java EE  Enterprise Edition
         → เพิ่ม libraries ฝั่ง server
Java ME  Micro Edition
         → VM เล็กสำหรับ embedded
Java Cards → smart card

/* วิธีจำ: SE มาตรฐาน ·
   EE องค์กร(server) ·
   ME จิ๋ว(ฝังตัว) · Card บัตร */
ข้อสอบสายนี้ตอบด้วยสูตรเดียว: "อยากแค่รันโปรแกรม Java ต้องมีอะไร" → JRE · "อยากเขียนโปรแกรม Java ต้องมีอะไร" → JDK · "ตัวที่รัน bytecode จริงๆ คือ" → JVM
ติวบทที่ 1 · โครงโปรแกรม

โครง main — เขียนได้หลับตา + อธิบายได้ทุกคำ

class HelloWorldApp {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
แต่ละคำแปลว่าอะไร (ถามได้ทุกคำ)
public  → JVM เรียกจากภายนอกได้
static  → เรียกได้โดยไม่ต้อง new object
          (JVM ยังไม่มี object ตอนเริ่ม!)
void    → ไม่คืนค่า
main    → ชื่อ "จุดเข้าโปรแกรม"
          (entry point) — สะกดต้องเป๊ะ
String[] args → รับ argument
          จาก command line
เกร็ดจากสไลด์
/* สไลด์เน้น:
   "Function ใน object-oriented
    program เรียกว่า method"
   ← ศัพท์ต้องใช้คำว่า method

   ไฟล์ .java 1 ไฟล์
   ชื่อไฟล์ต้องตรงกับชื่อ
   public class ในไฟล์
   HelloWorldApp.java
   ↔ class HelloWorldApp */
ข้อเขียนสายเปิด: "จงเขียนโปรแกรม Java แสดงข้อความ..." — โครง 4 บรรทัดนี้คือคะแนนฟรี ฝึกเขียนจนไม่ต้องคิด (พิมพ์ผิดตรง String[] args กันเยอะ)

ติวบทที่ 1 · เฉลย Lab1 ข้อ 3

เฉลย: พื้นที่ผิวปริซึมสามเหลี่ยมด้านเท่า

คิดสูตรก่อนเขียนโค้ด
พื้นที่ผิว = หน้าตัด 2 หน้า + ผิวข้าง 3 ด้าน

หน้าตัด (สามเหลี่ยมด้านเท่า):
  A = (√3/4) × ด้าน²   ← โจทย์ให้สูตร
ผิวข้าง: สี่เหลี่ยม 3 แผ่น
  = 3 × ด้าน × ยาว

Surface = 2·(√3/4)·a² + 3·a·L

เช็คตัวอย่าง 1: a=5, L=7.8
  2×(√3/4)×25 = 21.65
  3×5×7.8     = 117.00
  รวม         = 138.65 ✓ ตรงโจทย์
โค้ดเต็ม
import java.util.Scanner;

public class Prism {
  public static void main(String[] a) {
    Scanner sc = new Scanner(System.in);

    System.out.print("Enter triangle side: ");
    double side = sc.nextDouble();
    System.out.print("Enter prism length: ");
    double len = sc.nextDouble();

    double area =
        2 * (Math.sqrt(3)/4) * side * side
      + 3 * side * len;

    System.out.printf(
      "Surface area of prism is %.2f%n", area);
  }
}
/* a=2.25, L=6   → 44.88  ✓
   a=10.5, L=10.5 → 426.23 ✓ */
บทเรียนจากข้อนี้: โจทย์เลขในวิชานี้ให้สูตรมาเสมอ — งานจริงคือ ① แปลงสูตรเป็นนิพจน์ Java ให้ถูกลำดับ ② จัดทศนิยมตามตัวอย่าง — เช็คกับตัวอย่างที่โจทย์ให้ทุกครั้งก่อนส่ง
ติวบทที่ 1 · เฉลย Lab1 ข้อ 4

เฉลย: พิกัดอยู่จตุภาคใด (quadrant)

แยกเคสก่อน — ลำดับสำคัญ!
เคสพิเศษเช็คก่อนเสมอ:
① x==0 && y==0 → origin
② x==0         → y-intercept
   (จุดบนแกน y เช่น (0,5))
③ y==0         → x-intercept
   (จุดบนแกน x เช่น (-2,0))

แล้วค่อยแยก 4 จตุภาค:
Q1: x>0, y>0     Q2: x<0, y>0
Q3: x<0, y<0     Q4: x>0, y<0

/* ถ้าเช็ค Q1-Q4 ก่อน
   (0,5) จะไม่เข้าเงื่อนไขไหนเลย
   → เคสพิเศษต้องมาก่อน! */
โค้ดเต็ม
import java.util.Scanner;

public class Quadrant {
  public static void main(String[] a) {
    Scanner sc = new Scanner(System.in);
    int x = sc.nextInt();
    int y = sc.nextInt();
    String ans;

    if (x == 0 && y == 0) ans = "origin";
    else if (x == 0) ans = "y-intercept";
    else if (y == 0) ans = "x-intercept";
    else if (x > 0 && y > 0) ans = "Q1";
    else if (x < 0 && y > 0) ans = "Q2";
    else if (x < 0 && y < 0) ans = "Q3";
    else ans = "Q4";

    System.out.printf(
      "coordinates(%d,%d) = %s%n", x, y, ans);
  }
}
หลักที่ใช้ได้ทุกโจทย์ if-else: เคสแคบ/พิเศษต้องเช็คก่อนเคสกว้าง — origin ⊂ intercept ⊂ quadrant · เรียงผิดลำดับ = ผลผิดโดย compile ผ่าน (bug เงียบ)
