ติวบทที่ 5 · โครงสร้าง

Class Diagram — กล่อง 3 ชั้น + สัญลักษณ์

┌─────────────────────────────┐ │ Student │ ← ① ชื่อคลาส ├─────────────────────────────┤ │ - id : String │ ← ② attribute │ - name : String │ (field) │ - test : int │ ├─────────────────────────────┤ │ + Student(String, String) │ ← ③ method │ + getID() : String │ │ + calGPA(t,m,f) : double │ └─────────────────────────────┘
อ่านสัญลักษณ์ให้ครบ
-  หน้าชื่อ = private
+  หน้าชื่อ = public
#  หน้าชื่อ = protected

ชื่อ : ชนิด      ← attribute
  - id : String
  แปลว่า private String id;

ชื่อ(args) : ชนิดคืน  ← method
  + getID() : String
  แปลว่า public String getID()

/* สไลด์บอก: diagram "สร้างจาก
   มุมมองนักพัฒนา นำไปเขียน
   โปรแกรมได้โดยตรง" */
ลำดับการสร้าง (สไลด์ให้ 4 ขั้น — เรียงได้): ① กำหนดคลาสในระบบ → ② กำหนด attribute → ③ กำหนด method → ④ กำหนดความสัมพันธ์ระหว่างคลาส
ติวบทที่ 5 · แปลงเป็นโค้ด

Diagram → โค้ด: ตัวอย่าง Student ในสไลด์

// จาก diagram หน้าที่แล้ว แปลงตรงตัว:
public class Student {
    private String id;         // - id : String
    private String name;       // - name : String
    private int test;          // - test : int
    private int mid;
    private int finals;

    public Student(String id, String name) {   // + Student(String, String)
        this.id = id;
        this.name = name;
    }
    public String getID()   { return id; }     // + getID() : String
    public String getName() { return name; }
    public double calGPA(int test, int mid, int finals) {
        return ...;                             // + calGPA(...) : double
    }
}
กติกาแปลง 1:1 — ทุกบรรทัดใน diagram ต้องมีในโค้ด ครบทั้ง modifier (−→private), ชนิด, ลำดับ parameter · ข้อสอบตรวจแบบจับคู่ ขาดบรรทัดไหนหักบรรทัดนั้น · โจทย์กลับทาง (โค้ด→diagram) ก็ใช้กติกาเดียวกัน

ตามสไลด์ + ประเภทที่ต้องรู้
/* สไลด์: "ระบบไม่ได้มีคลาสเดียว
   แต่มีหลายคลาสที่ทำหน้าที่ต่างกัน
   ประสานกันผ่าน ความสัมพันธ์" */

คลาส X สัมพันธ์กับ Y เมื่อ:
• X เรียกใช้ method ของ Y
• X มี Y เป็น field (has-a)
• X รับ Y เป็น parameter
• X เป็นชนิดเดียวกับ Y (is-a → บท 6)

ระดับความผูกพัน (จาก lab 5):
Association  ใช้ชั่วคราว (parameter)
Aggregation  มีเป็นของ รับจากข้างนอก
Composition  new เองข้างใน ตายด้วยกัน
