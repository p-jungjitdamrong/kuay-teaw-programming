Cheat Sheet · ศัพท์

ศัพท์ OOP ทุกคำของ Midterm ในหน้าเดียว

ศัพท์ความหมายสั้นที่สุดที่ยังถูก
Classพิมพ์เขียว (blueprint) ของวัตถุ — โรงงานผลิตวัตถุ
Objectสิ่งที่มีตัวตน มีข้อมูล (field) + พฤติกรรม (method) — สร้างด้วย new
Constructorชื่อ = คลาส ไม่มี return type · เรียกอัตโนมัติตอน new · เขียนเองแล้ว default หาย
Encapsulationหลักข้อ 1 — ห่อหุ้มข้อมูล (private) มี method เป็นเปลือก (public)
Inheritanceหลักข้อ 2 — แม่ (super) ถ่ายทอดให้ลูก (sub) · ทดสอบด้วย is-a
Overrideลูกเขียนทับ method แม่ — หัว method เหมือนเป๊ะ
Overloadชื่อซ้ำในคลาสเดียวกัน ต่าง parameter (constructor ก็ overload ได้)
Garbage Collectorเก็บวัตถุ unreachable (ไม่มี reference ชี้) คืน memory อัตโนมัติ
bytecode / JVM.java —javac→ .class —JVM→ รัน · bytecode เหมือนกันทุกเครื่อง
JRE / JDKJRE = JVM+API (รัน) · JDK = JRE+เครื่องมือ (พัฒนา)
วิธีใช้: ปิดตาราง แล้วอธิบายแต่ละคำด้วยปากเปล่า — คำไหนติด กลับไปอ่านบทนั้น

Cheat Sheet · ห้ามพลาด

10 จุดหลอกเสียคะแนนฟรี (ข้อ 1–5)

① javac กับ java สลับหน้าที่
   javac HelloWorld.java (compile) → java HelloWorld (รัน — ไม่มีนามสกุล!)

② array ประกาศเฉยๆ ยังใช้ไม่ได้
   int[] a; a[0]=1; ❌ — ต้อง a = new int[5]; ก่อน ("ไม่มีอาเรย์เกิดขึ้นจริง")

③ length คู่หลอก
   array.length (ไม่มีวงเล็บ) · String.length() (มีวงเล็บ) — สลับ = compile error

④ String immutable
   s.replace(...) เฉยๆ s ไม่เปลี่ยน — ต้อง s = s.replace(...)

⑤ == vs equals
   == เทียบ reference (ชี้ก้อนเดียวกัน?) · equals เทียบเนื้อหา
   new String("abc") สองครั้ง → == false, equals true — วาดกล่องก่อนตอบเสมอ
Cheat Sheet · ห้ามพลาด

10 จุดหลอกเสียคะแนนฟรี (ข้อ 6–10)

⑥ default ≠ public
   ไม่เขียน modifier = จำกัดใน package เดียวกัน ไม่ใช่เปิดหมด

⑦ เขียน constructor เองแล้ว default constructor หาย
   มี Book(String, double) แล้ว new Book() จะ error — อยากได้ต้องเขียนเพิ่ม

⑧ super(...) ต้องบรรทัดแรก
   และถ้าแม่ไม่มี constructor ว่าง ลูกไม่เรียก super(...) = compile error

⑨ is-a มีทิศเดียว
   Student is a Person ✓ · Person is a Student ✗ — ข้อ T/F ชอบกลับทิศ

⑩ Override ≠ Overload
   Override: ลูกทับแม่ หัวเหมือนเป๊ะ · Overload: คลาสเดียวกัน ชื่อซ้ำ ต่าง parameter
คืนก่อนสอบอ่านหน้านี้กับหน้าก่อนรอบเดียว — 10 ข้อนี้ครอบคลุมจุดที่นักศึกษาพลาดบ่อยที่สุดของบท 1–6
Cheat Sheet · โค้ดท่องจำ

โครงโค้ด 3 ท่า — เขียนได้จากความจำ

// ① โครงโปรแกรม + main
public class App {
    public static void main(String[] args) {
        System.out.println("...");
    }
}

// ② คลาส encapsulation เต็มรูป
public class Book {
    private String name;
    public Book(String name) {
        this.name = name;
    }
    public String getName() { return name; }
    public void setName(String name) {
        this.name = name;
    }
}
// ③ inheritance + super + override
public class Student extends Person {
    private int year;

    public Student(String f, String l,
                   int a, int y) {
        super(f, l, a);   // บรรทัดแรก!
        year = y;
    }
    public void printInfo() {  // Override
        super.printInfo();     // reuse แม่
        System.out.println(year);
    }
}
ทดสอบ: ปิดจอ เขียนทั้ง 3 ท่าลงกระดาษใน 10 นาที — ผ่าน = ข้อเขียนโค้ดพร้อม · โจทย์เลข (ปริซึม/จตุภาค) ทวนที่ติวบทที่ 1

Cheat Sheet · ข้อสุดท้าย

ข้อรวบยอด — ผสมหลายบทในข้อเดียว

public class A {
    public A(int x) { }        // มี constructor รับค่าตัวเดียว
}
public class B extends A {
    public B() { }              // constructor ว่าง ไม่เรียก super
}
A compile ผ่านปกติ
B compile error ที่ B()
C รันแล้ว exception
D compile error ที่ A
// ไล่เหตุการณ์: B() ไม่เรียก super → Java เติม super() ให้
// → หา A() ว่างๆ ใน A → ไม่มี! (A เขียน A(int) เอง default เลยหาย)
// → compile error
// วิธีแก้: public B() { super(0); }  หรือเพิ่ม public A() {} ใน A
