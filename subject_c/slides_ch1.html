บทที่ 1 · แนวคิดหลัก
C คืออะไร? ทำงานยังไง?
ภาษา C เขียนแล้วต้อง compile ก่อน — computer ไม่อ่านภาษาคนได้โดยตรง
🔑 ทำไมต้องเรียน C?
C อยู่เบื้องหลัง OS, embedded systems, และ compiler ทุกตัว เข้าใจ C = เข้าใจว่า computer ทำงานยังไงจริงๆ
1
เขียน code ในไฟล์ .cเช่น hello.c ด้วย editor ใดก็ได้
2
Compile ด้วย gcc hello.c -o helloแปลงเป็น machine code ที่ CPU เข้าใจได้
3
Run ด้วย ./helloโปรแกรมทำงานจริงๆ เห็นผลลัพธ์
hello.c — โปรแกรมแรก
#include <stdio.h> /* บอกว่าใช้ stdio */ int main() { /* จุดเริ่มโปรแกรม */ printf("Hello!\n"); /* พิมพ์ข้อความ */ return 0; /* จบสำเร็จ */ }
⚠️ สิ่งที่ขาดไม่ได้
ทุกโปรแกรม C ต้องมี main() — เป็น entry point ที่ OS จะเรียกก่อนเสมอ
บทที่ 1 · Variables
ตัวแปร คือ "กล่องเก็บของ"
ก่อนใช้ตัวแปรใน C ต้องประกาศ (declare) ก่อนเสมอ — บอกว่ากล่องใบนี้เก็บของประเภทอะไร
Typeเก็บอะไรขนาดตัวอย่าง

floatทศนิยม (~7 หลัก)4 bytesfloat gpa = 3.5;

บทที่ 1 · Input / Output
printf แสดงผล · scanf รับค่า
สองฟังก์ชันนี้ใช้บ่อยที่สุดใน C ทั้งคู่อยู่ใน <stdio.h>
Format Specifiers — สำคัญมาก!
%d — int    %f — float
%lf — double    %c — char
%s — string    %% — พิมพ์ %

%.2f — ทศนิยม 2 ตำแหน่ง
%5d — กว้าง 5 ช่อง จัดขวา
⚠️ scanf ต้องใช้ &
&n = "ตำแหน่งใน memory ของ n" ถ้าลืม & โปรแกรม crash ทันที
ตัวอย่างครบ
#include <stdio.h> int main() { int age; float gpa; printf("Enter age: "); scanf("%d", &age); /* ต้องมี & */ printf("Enter GPA: "); scanf("%f", &gpa); printf("Age=%d GPA=%.2f\n", age, gpa); return 0; }
Output (ถ้าใส่ 20 และ 3.5): Age=20 GPA=3.50
บทที่ 1 · Operators
Operators — สัญลักษณ์คำนวณ
C มี operator หลายประเภท ที่สำคัญคือ arithmetic, comparison, logical และ assignment
Operatorความหมายตัวอย่าง
+ - * /บวก ลบ คูณ หาร10 / 3 = 3 (int!)
%เศษหาร (modulo)10 % 3 = 1
== != < >เปรียบเทียบx == 5 → 0 หรือ 1
&& ‖AND / ORx>0 && x<10
!NOT!0 = 1
++ --เพิ่ม/ลด 1x++ / --x
+= -=สะสมx += 5 = x = x+5
จุดสำคัญ — Integer Division
/* ⚠️ int หาร int = int เสมอ */ int a = 10, b = 3; printf("%d", a / b); /* = 3 ไม่ใช่ 3.33 */
/* ✅ cast ให้เป็น float ก่อน */ printf("%.2f", (float)a / b); /* = 3.33 */
Pre vs Post Increment
int x = 5; printf("%d", x++); /* พิมพ์ 5 แล้ว x=6 */ printf("%d", ++x); /* x=7 แล้วพิมพ์ 7 */
🎯 กฎ Operator Precedence
* / % ก่อน → + -
ถ้าไม่แน่ใจ ใส่วงเล็บ () ดีที่สุด
บทที่ 1 · Constants & Comments
Constants — ค่าที่เปลี่ยนไม่ได้
ใช้ const หรือ #define เพื่อป้องกันการเปลี่ยนค่าโดยไม่ตั้งใจ และทำให้ code อ่านง่ายขึ้น
2 วิธีประกาศค่าคงที่
/* วิธีที่ 1: const variable */ const float PI = 3.14159; const int MAX = 100; /* วิธีที่ 2: preprocessor define */ #define TAX_RATE 0.07 #define BANK_NAME "KTB" /* ลองแก้ค่า const จะ error! */ PI = 3.0; /* ❌ error: const */
Comments — อธิบาย code
// Single-line comment /* Multi-line comment อธิบายได้หลายบรรทัด */ /* ✅ comment ที่ดี: อธิบาย "ทำไม" */ score += 10; /* bonus for first login */ /* ❌ comment ที่ไม่มีประโยชน์ */ x = x + 1; /* บวก 1 ให้ x */
ต่างกันยังไง? const vs #define
const — มี type, compiler ตรวจสอบ error ได้

#define — แทนที่ตัวอักษรก่อน compile ไม่มี type, เร็วกว่าเล็กน้อย

ใน C สมัยใหม่แนะนำใช้ const เพราะปลอดภัยกว่า
🏦 Use Case — ธนาคาร
อัตราดอกเบี้ยคงที่
ระบบสินเชื่อ KTB ใช้ const float INTEREST_RATE = 0.05 แทน 0.05 กระจายอยู่ใน code — ถ้าอัตราเปลี่ยนแก้ที่เดียวได้เลย
ถ้าเขียน #define MAX 100 แล้วเขียน MAX = 50; จะเกิดอะไรขึ้น? ทำไม?
💡 #define ไม่ใช่ตัวแปร — มันแค่แทนที่ข้อความก่อน compile
บทที่ 1 · Type Conversion
Type Conversion — แปลงชนิดข้อมูล
C แปลงชนิดข้อมูลได้ 2 แบบ — อัตโนมัติ (implicit) และแบบบังคับ (explicit cast) ต้องระวัง implicit เพราะทำให้เกิด bug ที่หาไม่เจอ
Implicit — C แปลงให้อัตโนมัติ
int i = 5; float f = i; /* int → float = 5.0 ✅ */ float x = 3.9; int n = x; /* float → int = 3 ⚠️ ตัดทศนิยม! */ int a = 10, b = 3; float r = a / b; /* = 3.0 ⚠️ หารก่อน แล้วค่อยแปลง */
Explicit Cast — บังคับแปลง
int a = 10, b = 3; /* cast ก่อนหาร */ float r = (float)a / b; /* = 3.33 ✅ */ /* char ↔ int ใช้ได้เลย */ char c = 'A'; printf("%d", c); /* = 65 (ASCII) */
⚠️ Bug ที่เจอบ่อย
int a=7, b=2;
float r = a/b;

คิดว่าจะได้ 3.5 แต่ได้ 3.0

เพราะ C หาร int/int ก่อน = 3
แล้วค่อย assign ให้ float = 3.0

แก้ด้วย: float r = (float)a/b;
ASCII Table — ควรรู้
'A' = 65   'Z' = 90
'a' = 97   'z' = 122
'0' = 48   '9' = 57

ดังนั้น 'A' + 1 = 'B' ใช้ได้เลย!
บทที่ 1 · Use Case
🏦 Use Case จริง — ระบบธนาคาร
เนื้อหาบทที่ 1 ทั้งหมดประกอบกันสร้างโปรแกรมจริงได้แล้ว
🎯 โจทย์ระบบจริง
คำนวณดอกเบี้ยเงินฝาก
ระบบรับยอดเงินต้น อัตราดอกเบี้ยต่อปี และจำนวนปี แล้วคำนวณดอกเบี้ยและยอดรวม

สูตร: ดอกเบี้ย = เงินต้น × อัตรา × ปี
ต้องใช้อะไรจากบทที่ 1
✅ double เพราะเงินต้องละเอียด
✅ scanf รับยอดเงินและอัตรา
✅ Arithmetic operators คำนวณ
✅ const สำหรับ rate คงที่
✅ printf("%.2f") แสดงผล
โปรแกรมเต็ม
#include <stdio.h> int main() { double principal, rate, years; double interest, total; printf("เงินต้น (บาท): "); scanf("%lf", &principal); printf("อัตราดอกเบี้ย (%%/ปี): "); scanf("%lf", &rate); printf("จำนวนปี: "); scanf("%lf", &years); interest = principal * (rate/100) * years; total = principal + interest; printf("\n=== สรุป ===\n"); printf("ดอกเบี้ย : %.2f บาท\n", interest); printf("ยอดรวม : %.2f บาท\n", total); return 0; }
บทที่ 1 · Think!
คิดก่อน เขียน
อ่านแต่ละโจทย์แล้วตอบในใจก่อนกด เฉลย — ฝึก logic ก่อนพิมพ์ code จริง
1. ผลลัพธ์ของ printf("%d", 17 % 5); คือเท่าไหร่?
💡 % คือเศษจากการหาร — 17 ÷ 5 = 3 เศษ ?
2. ถ้าประกาศ int x = 3.9; ค่าของ x จะเป็นเท่าไหร่? ทำไม?
💡 int ไม่มีทศนิยม — จะเกิด implicit conversion
3. printf("%d", 5 == 5); จะพิมพ์อะไร?
💡 ใน C ผลของ comparison คือ 0 (false) หรือ 1 (true)
4. จะใช้ type อะไรเก็บ: เลขบัตรประชาชน 13 หลัก?
💡 int เก็บได้ ~2 billion — 13 หลักเกินแน่นอน ลองคิด long long หรือ string
5. ถ้า int a=5; printf("%d", a++); แล้ว printf("%d", a); อีกครั้ง จะได้ค่าอะไรทั้งสอง?
💡 post-increment ใช้ค่าเดิมก่อน แล้วค่อยเพิ่ม
บทที่ 1 · โจทย์ฝึก
โจทย์ เติมคำ
เติมส่วนที่หายไปให้ code ทำงานถูกต้อง — ลองคิดก่อนกด Check
โจทย์ 1 — Format Specifier
ต้องการพิมพ์ตัวเลข 3.14 จาก float pi = 3.14159; ให้มีทศนิยม 2 ตำแหน่ง
เติม format specifier ที่ถูกต้องใน printf("___", pi);
โจทย์ 2 — scanf
ต้องการรับค่า int จากผู้ใช้ไปเก็บในตัวแปร age
เติมส่วนที่ขาดหายใน scanf("%d", ___age);
โจทย์ 3 — Integer Division
ต้องการให้ result มีค่า 2.5 จาก int a=5, b=2;
เติมให้ถูก: float result = ___ a / b;
บทที่ 1 · โจทย์ Trace
โจทย์ อ่าน code ทายผลลัพธ์
