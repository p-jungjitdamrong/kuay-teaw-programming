⬤ Easy
#01OUTPUT
Positive / Negative / Zero
SOLUTION CODE
#include <stdio.h> int main() { int n; printf("Enter number: "); scanf("%d", &n); if (n > 0) printf("Positive\n"); else if (n < 0) printf("Negative\n"); else printf("Zero\n"); return 0; }
🔑 Key Concept: if → else if → else  |  ตรวจ 3 กรณี ด้วยเงื่อนไข 2 ข้อ ที่เหลือ else รับทั้งหมด
🇹🇭 อธิบายทีละส่วน
①
ประกาศตัวแปร & รับค่า
int n; ประกาศตัวแปรจำนวนเต็ม แล้ว scanf("%d", &n) รับค่าจาก keyboard อย่าลืม & หน้า n เพื่อบอกตำแหน่ง memory
②
ตรวจ Positive ก่อน
if (n > 0) ถ้า n มากกว่า 0 พิมพ์ Positive แล้วข้ามไปเลย ไม่ตรวจส่วนที่เหลือ
③
else if สำหรับ Negative
เมื่อผ่าน if แรกมาแล้ว แปลว่า n ≤ 0 แน่ๆ จึงตรวจแค่ n < 0 ไม่ต้องเขียน n < 0 && n != 0
④
else รับกรณีที่เหลือ
ผ่านมาถึง else ได้ แปลว่า n ไม่ใช่ >0 และไม่ใช่ <0 เหลือแค่ 0 เพียงค่าเดียว
#02OUTPUT
Even [E] / Odd [O]
SOLUTION CODE
#include <stdio.h> int main() { int i; for (i = 1; i <= 10; i++) { if (i % 2 == 0) printf("[E] %d\n", i); else printf("[O] %d\n", i); } return 0; }
🔑 Key Concept: % (modulo)  |  เศษจากการหาร — ถ้า i % 2 == 0 คือหาร 2 ลงตัว = เลขคู่
🇹🇭 อธิบายทีละส่วน
①
for loop ตั้งแต่ 1 ถึง 10
i = 1 คือค่าเริ่มต้น, i <= 10 คือเงื่อนไข (รวม 10), i++ คือเพิ่มทีละ 1 ทุกรอบ
②
ตรวจเลขคู่ด้วย modulo
i % 2 คือเศษเมื่อหาร 2 ถ้าเศษ = 0 แปลว่าหารลงตัว = เลขคู่ → พิมพ์ [E] ถ้าไม่ใช่ → พิมพ์ [O]
③
\n คืออะไร?
\n ใน printf คือ newline ขึ้นบรรทัดใหม่ ถ้าไม่ใส่ทุกตัวเลขจะพิมพ์ติดกันเป็นแถวเดียว
#03OUTPUT
Star Triangle
SOLUTION CODE
#include <stdio.h> int main() { int n, i, j; printf("Enter n: "); scanf("%d", &n); for (i = 1; i <= n; i++) { /* วนทีละแถว */ for (j = 1; j <= i; j++) { /* พิมพ์ดาว i ดวง */ printf("*"); } printf("\n"); /* ขึ้นบรรทัดใหม่หลังจบแต่ละแถว */ } return 0; }
🔑 Key Concept: Nested Loop  |  loop ซ้อน loop — loop นอก = แถว, loop ใน = จำนวนดาวในแถวนั้น
🇹🇭 อธิบายทีละส่วน
①
Loop นอก (i) = แถว
i วิ่งจาก 1 ถึง n แต่ละค่าของ i คือหมายเลขแถว เช่น i=1 คือแถว 1, i=2 คือแถว 2
②
Loop ใน (j) = ดาวในแถวนั้น
j วิ่งจาก 1 ถึง i (ไม่ใช่ n) ทำให้แถวที่ i มีดาว i ดวงพอดี เช่น i=3 → j วิ่ง 1,2,3 → พิมพ์ ***
③
\n อยู่นอก loop ใน
printf("\n") อยู่หลัง loop ใน (แต่อยู่ใน loop นอก) เพื่อขึ้นบรรทัดหลังพิมพ์ดาวแต่ละแถวเสร็จ
④
Trace n=3
i=1: j วิ่ง 1→1 พิมพ์ * แล้ว \n
i=2: j วิ่ง 1→2 พิมพ์ ** แล้ว \n
i=3: j วิ่ง 1→3 พิมพ์ *** แล้ว \n

#04SYSTEM
Discount Calculator
SOLUTION CODE
#include <stdio.h> int main() { int price, disc = 0, final_price; printf("Enter price: "); scanf("%d", &price); if (price >= 1000) disc = 20; else if (price >= 500) disc = 10; else if (price >= 100) disc = 5; /* ถ้าต่ำกว่า 100 disc ยังเป็น 0 (ค่า default ที่ตั้งไว้) */ final_price = price - (price * disc / 100); printf("Original price : %d\n", price); printf("Discount : %d%%\n", disc); printf("You pay : %d\n", final_price); return 0; }
🔑 Key Concept: if-else if จากสูงลงต่ำ  |  ต้องตรวจ >= 1000 ก่อนเสมอ มิฉะนั้น 1200 จะติด >= 500 แทน
🇹🇭 อธิบายทีละส่วน
①
ตั้งค่า disc = 0 ตั้งแต่แรก
กำหนดค่า default ไว้เลย ถ้า price < 100 ไม่มี if ไหนทำงาน disc ก็ยังเป็น 0 อยู่ ไม่ต้องเขียน else แยกต่างหาก
②
ลำดับ if สำคัญมาก
ต้องตรวจจาก >= 1000 ก่อนเสมอ เพราะ 1200 >= 500 ก็เป็น true เช่นกัน ถ้าตรวจ >= 500 ก่อน จะได้ disc=10 ผิด
③
คำนวณราคาหลังลด
price * disc / 100 คือจำนวนเงินที่ลด เช่น 1200 * 20 / 100 = 240 แล้ว final = 1200 - 240 = 960
④
%% ใน printf
ต้องการพิมพ์ % จริงๆ ต้องเขียน %% เพราะ % ตัวเดียวคือ format specifier
#05SYSTEM
Grade Checker
SOLUTION CODE
#include <stdio.h> int main() { int score; printf("Enter score: "); scanf("%d", &score); if (score < 0 || score > 100) { printf("Invalid score\n"); } else if (score >= 90) printf("Grade: A\n"); else if (score >= 80) printf("Grade: B\n"); else if (score >= 70) printf("Grade: C\n"); else if (score >= 60) printf("Grade: D\n"); else printf("Grade: F\n"); return 0; }
🔑 Key Concept: || (Logical OR)  |  ตรวจ out-of-range ด้วย score < 0 || score > 100 ก่อนเสมอ
🇹🇭 อธิบายทีละส่วน
①
ตรวจ Invalid ก่อน
score < 0 || score > 100 — || คือ OR ถ้าอย่างใดอย่างหนึ่งเป็น true ทั้งหมดเป็น true ตรวจก่อนเพื่อกำจัดค่าผิดปกติทิ้ง
②
ไม่ต้องเขียน range ซ้อน
ไม่จำเป็นต้องเขียน score >= 80 && score <= 89 เพราะ else if ทำงานก็ต่อเมื่อ if ข้างบนไม่ผ่านแล้ว ดังนั้น else if (score >= 80) ก็หมายถึง 80–89 อัตโนมัติ
③
else รับ F ทั้งหมด
ถ้าผ่านมาถึง else แปลว่า score อยู่ระหว่าง 0–59 แน่ๆ (เพราะ Invalid และ A-D ถูก filter ออกไปแล้ว)

#06OUTPUT
FizzBuzz
SOLUTION CODE
#include <stdio.h> int main() { int n, i; printf("Enter n: "); scanf("%d", &n); for (i = 1; i <= n; i++) { if (i % 15 == 0) printf("FizzBuzz\n"); else if (i % 3 == 0) printf("Fizz\n"); else if (i % 5 == 0) printf("Buzz\n"); else printf("%d\n", i); } return 0; }
🔑 Key Concept: ลำดับเงื่อนไข  |  % 15 ต้องอยู่บนสุดเสมอ เพราะตัวที่หาร 15 ได้ก็หาร 3 และ 5 ได้ด้วย
🇹🇭 อธิบายทีละส่วน
①
ทำไม % 15 ต้องก่อน
เลข 15 หาร 3 ลงตัว และหาร 5 ลงตัวด้วย ถ้าตรวจ % 3 ก่อน → พิมพ์ Fizz แล้วข้ามไปเลย ไม่มีโอกาสพิมพ์ FizzBuzz อีก
②
else รับตัวเลขธรรมดา
ถ้าไม่หาร 15, 3, หรือ 5 ลงตัว ก็พิมพ์ตัวเลข i ออกมาตรงๆ ด้วย %d
③
Trace เลข 15
15 % 15 = 0 → เงื่อนไขแรกผ่าน → พิมพ์ FizzBuzz → ข้าม else if ทั้งหมด ✓
#07SYSTEM
Electricity Bill Calculator
SOLUTION CODE
#include <stdio.h> int main() { int units; float cost; printf("Enter units: "); scanf("%d", &units); if (units <= 100) { cost = units * 3.0; } else if (units <= 200) { cost = 100 * 3.0 + (units - 100) * 4.0; } else { cost = 100 * 3.0 + 100 * 4.0 + (units - 200) * 5.0; } printf("Units used : %d\n", units); printf("Total cost : %.2f baht\n", cost); return 0; }
🔑 Key Concept: Tiered / Progressive Rate  |  คิดแยกแต่ละช่วง ไม่ใช่คูณอัตราเดียวทั้งหมด
🇹🇭 อธิบายทีละส่วน
①
ใช้ float เพราะมีทศนิยม
float cost รองรับเลขทศนิยม และ %.2f ใน printf พิมพ์ทศนิยม 2 ตำแหน่ง เช่น 270.00
②
Tier 2: units - 100
ใช้ 150 หน่วย → 100 หน่วยแรกคิด tier 1, อีก 150-100=50 หน่วยคิด tier 2 จึงต้องลบ 100 ออกก่อนคูณ 4.0
③
Trace 250 หน่วย
100×3.0 = 300 → บวก 100×4.0 = 400 → บวก (250-200)×5.0 = 250 → รวม 950 ✓
#08OUTPUT
Multiplication Table
SOLUTION CODE
#include <stdio.h> int main() { int n, i, j; printf("Enter n: "); scanf("%d", &n); for (i = 1; i <= n; i++) { /* แถว */ for (j = 1; j <= n; j++) { /* คอลัมน์ */ printf("%3d", i * j); /* กว้าง 3 ช่อง จัดชิดขวา */ } printf("\n"); } return 0; }
🔑 Key Concept: %3d format  |  จองพื้นที่ 3 ช่อง จัดชิดขวา ทำให้คอลัมน์ตรงกันทุกแถว
🇹🇭 อธิบายทีละส่วน
①
Nested loop ทั้งคู่วิ่งถึง n
ต่างจากโจทย์ดาวที่ loop ในวิ่งถึง i ตรงนี้ทั้ง loop นอก (i) และ loop ใน (j) วิ่งถึง n เพราะต้องการตาราง n×n สมมาตร
②
%3d คืออะไร
%3d แปลว่า พิมพ์ integer โดยจองพื้นที่ 3 ช่อง ถ้าตัวเลขสั้นกว่าจะเติม space หน้า เช่น 1 → "  1", 12 → " 12", 100 → "100"
③
i * j คือค่าในตาราง
แถวที่ i คอลัมน์ที่ j ค่าในช่องนั้นคือ i×j เช่น แถว 3 คอลัมน์ 4 = 3×4 = 12

#09SYSTEM
Simple ATM
SOLUTION CODE
#include <stdio.h> #include <string.h> /* สำหรับ strcmp() */ int main() { int balance = 5000; int amt; char cmd[20]; /* เก็บคำสั่งที่พิมพ์ */ while (1) { /* loop ไม่มีสิ้นสุด หยุดด้วย break */ printf("> "); scanf("%s", cmd); if (strcmp(cmd, "quit") == 0) { printf("Thank you. Goodbye!\n"); break; } else if (strcmp(cmd, "balance") == 0) { printf("Balance: %d baht\n", balance); } else if (strcmp(cmd, "deposit") == 0) { scanf("%d", &amt); balance += amt; printf("Deposited: %d baht\n", amt); printf("Balance: %d baht\n", balance); } else if (strcmp(cmd, "withdraw") == 0) { scanf("%d", &amt); if (amt > balance) printf("Insufficient funds. Balance: %d baht\n", balance); else { balance -= amt; printf("Withdrew: %d baht\n", amt); printf("Balance: %d baht\n", balance); } } } return 0; }
🔑 Key Concept: while(1) + break  |  loop ไม่มีสิ้นสุด ใช้ break หยุดเมื่อได้รับ quit + strcmp() เปรียบเทียบ string
🇹🇭 อธิบายทีละส่วน
①
while(1) คืออะไร
เงื่อนไข 1 = true ตลอดเวลา ทำให้ loop ทำงานไม่หยุด จนกว่าจะ break ออก เหมาะสำหรับ menu-driven program ที่ไม่รู้ล่วงหน้าว่าจะรับกี่ครั้ง
②
strcmp() เปรียบเทียบ string
ใน C ห้าม cmd == "quit" โดยตรง (เป็นการเปรียบเทียบ address) ต้องใช้ strcmp(cmd, "quit") == 0 แทน ต้อง include <string.h>
③
deposit/withdraw อ่าน scanf ต่อ
หลัง scanf อ่าน cmd แล้ว ถ้าเป็น deposit/withdraw ก็ scanf ต่ออีกครั้งเพื่ออ่านตัวเลขจำนวนเงิน
④
ตรวจ Insufficient funds
if (amt > balance) ถ้าจะถอนมากกว่าที่มี ให้แจ้งและ ไม่ ลด balance ถ้าโอเคค่อย balance -= amt
#10SYSTEM
🍜 ก๋วยเตี๋ยวเรือ Order System
SOLUTION CODE
#include <stdio.h> int main() { /* ราคาแต่ละเมนู index 0 ไม่ใช้ */ int price[] = {0, 45, 50, 55, 10}; char *name[] = {"", "Kuay Teaw Ruea", "Kuay Teaw Tom Yum", "Khao Moo Daeng", "Nam Plao" }; int qty[] = {0, 0, 0, 0, 0}; /* จำนวนที่สั่ง */ int choice, q, i; printf("=== Welcome to Kuay Teaw Ruea ===\n"); printf("Select item (0 to finish):\n"); while (1) { printf("> "); scanf("%d", &choice); if (choice == 0) break; if (choice < 1 || choice > 4) { printf("Invalid item.\n"); continue; } printf("Quantity: "); scanf("%d", &q); qty[choice] += q; } /* คำนวณ subtotal และจำนวนรวม */ int subtotal = 0, total_qty = 0; for (i = 1; i <= 4; i++) { subtotal += qty[i] * price[i]; total_qty += qty[i]; } int disc = (total_qty >= 3) ? subtotal / 10 : 0; int total = subtotal - disc; /* พิมพ์ใบเสร็จ */ printf("\n======= RECEIPT =======\n"); for (i = 1; i <= 4; i++) { if (qty[i] > 0) printf("%-18s x%d %4d\n", name[i], qty[i], qty[i]*price[i]); } printf("-----------------------\n"); printf("Subtotal : %d\n", subtotal); if (disc > 0) printf("Discount (10%%) : %d\n", disc); printf("Total : %d\n", total); printf("=======================\n"); printf("Thank you! Come again.\n"); return 0; }
🔑 Key Concept: Array + while(1) + ternary operator  |  รวม concept หลายอย่างในโปรแกรมเดียว
🇹🇭 อธิบายทีละส่วน
①
ใช้ Array เก็บเมนูและจำนวน
price[] เก็บราคา, name[] เก็บชื่อ, qty[] เก็บจำนวนที่สั่ง ทั้งหมด index 1–4 ตรงกับเมนู 1–4 index 0 ไม่ใช้ (เว้นว่างไว้)
②
qty[choice] += q
ถ้าสั่งเมนูเดิมซ้ำ ก็บวกเพิ่มเข้าไปในช่อง array ของเมนูนั้น เช่น สั่ง เมนู 1 อีกครั้ง qty[1] ก็เพิ่มขึ้น
③
Ternary operator สำหรับส่วนลด
(total_qty >= 3) ? subtotal/10 : 0 — ถ้าสั่ง >= 3 ชิ้น disc = subtotal/10 (10%) มิฉะนั้น disc = 0
④
%-18s จัดชิดซ้าย
%-18s คือพิมพ์ string จองพื้นที่ 18 ช่อง จัดชิดซ้าย (- คือซ้าย) ทำให้ชื่อเมนูเรียงกันเป็นระเบียบ
⑤
แสดงส่วนลดเฉพาะถ้ามี
if (disc > 0) ก่อนพิมพ์บรรทัด Discount ถ้าไม่มีส่วนลดก็ไม่ต้องแสดงบรรทัดนั้น
