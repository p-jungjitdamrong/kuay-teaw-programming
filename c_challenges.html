Positive / Negative / Zero
Write a program that reads one integer and prints whether it is Positive, Negative, or Zero.
EXAMPLE INPUT / OUTPUT
Input: 5 Output: Positive Input: -3 Output: Negative Input: 0 Output: Zero
🇹🇭 แนวคิด

ใช้ if-else if-else ตรวจ 3 กรณี: มากกว่า 0, น้อยกว่า 0, และเท่ากับ 0

ลำดับสำคัญ — ตรวจ > 0 ก่อน ถ้าไม่ใช่ค่อยตรวจ < 0 ที่เหลือคือ 0

if (n > 0) printf("Positive"); else if (n < 0) printf("Negative"); else printf("Zero");
#02 OUTPUT ✓ Done
Even [E] / Odd [O]
Print numbers 1–10. Put [E] before even numbers and [O] before odd numbers.
EXPECTED OUTPUT
[O] 1 [E] 2 [O] 3 [E] 4 [O] 5 [E] 6 [O] 7 [E] 8 [O] 9 [E] 10
🇹🇭 แนวคิด

ใช้ for loop วน i=1 ถึง 10 แล้วตรวจ i % 2 == 0 ว่าเป็นเลขคู่ไหม

% คือ modulo (เศษหาร) — ถ้าเศษเป็น 0 แสดงว่าหาร 2 ลงตัว = เลขคู่

for (i = 1; i <= 10; i++) { if (i % 2 == 0) printf("[E] %d\n", i); else printf("[O] %d\n", i); }

Discount Calculator
Read a product price and calculate the discount based on the following rules.
DISCOUNT RULES
price >= 1000→ 20% discount
price >= 500 → 10% discount
price >= 100 → 5% discount
price < 100 → no discount
EXAMPLE INPUT / OUTPUT
Input: 1200 Original price : 1200 Discount : 20% You pay : 960 Input: 450 Original price : 450 Discount : 10% You pay : 405 Input: 80 Original price : 80 Discount : 0% You pay : 80
🇹🇭 แนวคิด

ใช้ if-else if ตรวจจากราคาสูงลงมา (ตรวจ >= 1000 ก่อนเสมอ) เพราะถ้าตรวจ >= 100 ก่อน ราคา 1000 ก็จะผ่านเงื่อนไขนั้นด้วย

คำนวณราคาหลังลด: final = price - (price * discount / 100)

int disc = 0; if (price >= 1000) disc = 20; else if (price >= 500) disc = 10; else if (price >= 100) disc = 5; int final = price - (price * disc / 100);

if (score < 0 || score > 100) printf("Invalid score"); else if (score >= 90) printf("Grade: A"); else if (score >= 80) printf("Grade: B"); else if (score >= 70) printf("Grade: C"); else if (score >= 60) printf("Grade: D"); else printf("Grade: F");

otherwise → print the number
EXAMPLE — Input: 15

for (i = 1; i <= n; i++) { if (i % 15 == 0) printf("FizzBuzz\n"); else if (i % 3 == 0) printf("Fizz\n"); else if (i % 5 == 0) printf("Buzz\n"); else printf("%d\n", i); }

Electricity Bill Calculator
Read the number of electricity units used and calculate the bill using a tiered rate system.
RATE (tiered — not flat)
1–100 units → 3.00 baht/unit
101–200 units→ 4.00 baht/unit
201+ units → 5.00 baht/unit
EXAMPLE INPUT / OUTPUT
Input: 90 Units used : 90 Total cost : 270.00 baht Input: 150 Units used : 150 Total cost : 500.00 baht Input: 250 Units used : 250 Total cost : 950.00 baht (100×3) + (100×4) + (50×5) = 300+400+250 = 950
🇹🇭 แนวคิด

คำนวณแบบขั้นบันได ไม่ใช่ flat rate — คือต้องคิดแยกแต่ละ tier ตัวอย่างเช่น 250 หน่วย:

100 หน่วยแรก × 3 + 100 หน่วยถัดมา × 4 + 50 หน่วยที่เหลือ × 5

float cost = 0; if (units <= 100) { cost = units * 3.0; } else if (units <= 200) { cost = 100*3.0 + (units-100)*4.0; } else { cost = 100*3.0 + 100*4.0 + (units-200)*5.0; } printf("Total cost : %.2f baht\n", cost);

#09 SYSTEM ✓ Done
Simple ATM
Starting balance is 5000 baht. Read commands in a loop until the user types quit.
COMMANDS
balance → show current balance
deposit <amt> → add money
withdraw <amt> → subtract money (check if enough)
quit → exit the program
EXAMPLE SESSION
> balance Balance: 5000 baht > deposit 1000 Deposited: 1000 baht Balance: 6000 baht > withdraw 2000 Withdrew: 2000 baht Balance: 4000 baht > withdraw 9000 Insufficient funds. Balance: 4000 baht > quit Thank you. Goodbye!
🇹🇭 แนวคิด

ใช้ while(1) loop ไม่มีที่สิ้นสุด แล้ว break เมื่อ input เป็น "quit"

ใช้ scanf("%s", cmd) อ่าน command แล้ว strcmp(cmd, "balance") เปรียบเทียบ string — ต้อง include <string.h>

สำหรับ deposit/withdraw ใช้ scanf("%s %d", cmd, &amt) อ่านพร้อมกัน

#include <stdio.h> #include <string.h> int main() { int balance = 5000, amt; char cmd[20]; while (1) { printf("> "); scanf("%s", cmd); if (strcmp(cmd, "quit") == 0) { printf("Thank you. Goodbye!\n"); break; } else if (strcmp(cmd, "balance") == 0) { printf("Balance: %d baht\n", balance); } else if (strcmp(cmd, "deposit") == 0) { scanf("%d", &amt); balance += amt; printf("Deposited: %d baht\nBalance: %d baht\n", amt, balance); } else if (strcmp(cmd, "withdraw") == 0) { scanf("%d", &amt); if (amt > balance) printf("Insufficient funds. Balance: %d baht\n", balance); else { balance -= amt; printf("Withdrew: %d baht\nBalance: %d baht\n", amt, balance); } } } return 0; }
